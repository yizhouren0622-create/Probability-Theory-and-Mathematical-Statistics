原创 P14-01第 14.1 节 · 进阶

宽平稳是否足够

一离散过程各时刻独立，偶数时刻等概率取 ±1，奇数时刻为标准正态。判断宽平稳与严平稳，并给理由。

给我一点提示
提示 1

先算一阶二阶矩。

提示 2

不同时刻独立且均值为零。

提示 3

比较一个时刻的分布形状。

带我一步一步做

第 1 / 4 步

  1. 各时刻均值为 0、方差为 1。

  2. 不同时间相关为 0，同一时间相关为 1，因此相关只依赖时差是否为 0。

  3. 满足宽平稳定义。

  4. 偶数时刻分布离散、奇数时刻分布连续，平移一步改变边际分布，所以不严平稳。

查看完整解答与检验

  1. 各时刻均值为 0、方差为 1。

  2. 不同时间相关为 0，同一时间相关为 1，因此相关只依赖时差是否为 0。

  3. 满足宽平稳定义。

  4. 偶数时刻分布离散、奇数时刻分布连续，平移一步改变边际分布，所以不严平稳。

答案

宽平稳，但不严平稳。

检验与提醒

所有变量正态的高斯过程不能用这个反例。

原创 P14-02第 14.2 节 · 进阶

平稳却无法平均掉的随机性

X(t)=A，EA=0,Var(A)=4。求 X¯T 与其均方误差，判断是否均值均方各态历经。

给我一点提示
提示 1

一条轨迹是固定的水平线。

提示 2

对时间积分不会改变这条线的高度。

提示 3

误差是否随 T 下降？

带我一步一步做

第 1 / 4 步

  1. X¯T=T−1∫0TAdt=A。

  2. 总体均值为 0。

  3. E(X¯T−0)2=EA2=4，不随 T 改变。

  4. 所以虽为严平稳过程，仍不具均值均方各态历经性。

查看完整解答与检验

  1. X¯T=T−1∫0TAdt=A。

  2. 总体均值为 0。

  3. E(X¯T−0)2=EA2=4，不随 T 改变。

  4. 所以虽为严平稳过程，仍不具均值均方各态历经性。

答案

时间平均为 A，均方误差恒为 4，不各态历经。

检验与提醒

每条轨迹都能平均出自己的 A，却不能识别总体均值 0。

原创 P14-03第 14.3 节 · 进阶

排除不可能的相关函数

有人提出宽平稳实过程的相关函数满足 R(0)=1,R(1)=1.2。是否可能？另判断 R(1)=−0.4 是否仅因此就不可能。

给我一点提示
提示 1

使用绝对值上界。

提示 2

相关函数允许负值。

提示 3

通过一个必要条件并不等于全部验证。

带我一步一步做

第 1 / 4 步

  1. 必要条件为 |R(1)|≤R(0)。

  2. 1.2>1，因此第一种不可能。

  3. 若 R(1)=−0.4，则绝对值 0.4≤1，不违反此条件。

  4. 但要证明整个候选函数合法，仍须核对任意有限时刻的非负定性等要求。

查看完整解答与检验

  1. 必要条件为 |R(1)|≤R(0)。

  2. 1.2>1，因此第一种不可能。

  3. 若 R(1)=−0.4，则绝对值 0.4≤1，不违反此条件。

  4. 但要证明整个候选函数合法，仍须核对任意有限时刻的非负定性等要求。

答案

第一种不可能；负的 R(1) 本身不是矛盾，但不足以证明整体合法。

检验与提醒

相关系数的范围也是 [−1,1]，但这里 R 尚未标准化。

原创 P14-04第 14.4 节 · 进阶

谱密度的归一化

角频率约定下，R(τ)=3e−2|τ|。求谱密度，并检验其积分对应的总功率。

给我一点提示
提示 1

用指数相关的已推导公式。

提示 2

a=2，σ²=3。

提示 3

积分 1/(a²+ω²) 为 π/a。

带我一步一步做

第 1 / 4 步

  1. 代入得到 S(ω)=2·2·3/(4+ω2)=12/(4+ω2)。

  2. 函数非负且为偶函数，符合必要性质。

  3. ∫−∞∞S(ω)dω=12π/2=6π。

  4. 总功率为 (1/(2π))6π=3=R(0)。

查看完整解答与检验

  1. 代入得到 S(ω)=2·2·3/(4+ω2)=12/(4+ω2)。

  2. 函数非负且为偶函数，符合必要性质。

  3. ∫−∞∞S(ω)dω=12π/2=6π。

  4. 总功率为 (1/(2π))6π=3=R(0)。

答案

S(ω)=12/(4+ω2)，总功率为 3。

检验与提醒

若漏掉反变换中的 1/(2π)，就不能恢复 R(0)。
