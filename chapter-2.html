随机变量

2.1Random variable理解后再记忆

随机变量：给结果贴上数值

先用一句话理解

随机变量不是一个神秘的未知数，而是一条把试验结果变成数字的规则。

X=X(ω) 是定义在样本空间上的实值函数。事件 {X≤x} 表示所有使函数值不大于 x 的试验结果。

X:Ω⟶R
使用条件

X 表示随机变量，x 表示具体数值。并非每个结果都必须映射为不同数字。

展开推导 / 为什么成立

连续抛两次硬币的四个结果，经“正面次数”映射为 2、1、1、0。随机性来自抽到哪个样本点，映射规则本身固定。求 X 的分布就是把映射到同一个数的样本点概率加起来。

做一道简单例题

例： 公平独立抛两次硬币，X 为正面数，则 P(X=0)=1/4,P(X=1)=1/2,P(X=2)=1/4。其中 X=1 合并了 HT、TH 两种结果。

容易出错的地方

不要把随机变量的三个取值误当成三个等可能基本结果。

SECTION 2.2

离散型随机变量及其分布律

2.2Probability mass function理解后再记忆

分布律：每个值配一个概率

先用一句话理解

离散型变量的概率集中在有限个或可列个点上，一张表就能说明它落在哪些点。

分布律同时列出取值和概率。每项非负，所有项相加为 1；求某事件的概率时，对满足条件的取值求和。

P(X=xk)=pk,pk≥0,∑kpk=1
使用条件

取值不重复，概率不得遗漏。非负性与归一性都要检查。

展开推导 / 为什么成立

事件 {X=xk} 彼此互斥，并覆盖样本空间，因此概率之和为 1。反过来，一组非负且总和为 1 的数可以作为一个离散分布。

做一道简单例题

例： X 取 0、1、2，概率分别为 c、2c、3c。由 6c=1 得 c=1/6，P(X≥1)=2c+3c=5/6。

容易出错的地方

只检查和为 1 不够，还要排除负概率。

试一题：P2-02 →
2.2Bernoulli & binomial理解后再记忆

0–1 分布与二项分布

先用一句话理解

一次成功与否用 0–1 分布，多次独立重复中的成功次数用二项分布。

X~B(n,p) 表示 n 次独立、同成功率试验中的成功数。n=1 即 0–1 分布。

P(X=k)=(nk)pk(1−p)n−k,k=0,1,…,n
使用条件

n 为正整数，0≤p≤1；每次只有成功/失败两类，独立且 p 不变。

展开推导 / 为什么成立

每个具体成功序列的概率为 pk(1−p)n−k，成功位置有 (nk) 种。由二项式定理，总概率为 (p+1−p)n=1。

做一道简单例题

例： X~B(4,1/2)，P(X=2)=6/16=3/8。如果从含两个次品的十件产品中不放回抽四件，则次品数并不服从 B(4,0.2)。

容易出错的地方

辨认随机变量：如果问“直到首次成功的次数”，试验次数不固定，不是二项分布。

试一题：P2-03 →
2.2Poisson distribution理解后再记忆

泊松分布：一段时间里的次数

先用一句话理解

泊松分布描述计数；参数 λ 控制概率质量主要集中在哪些次数附近。

泊松分布的取值是所有非负整数。二项分布中 n 大、p 小且 np 适中时，可以考虑泊松近似，λ=np。

P(X=k)=e−λλkk!,k=0,1,…,λ>0
使用条件

题目给出泊松模型时可直接使用；从实际计数建立模型需要额外假设。“计数”不自动等于“泊松”。

展开推导 / 为什么成立

非负显然。利用指数级数，∑k=0∞e−λλk/k!=e−λeλ=1。在 p=λ/n、n 趋于无穷时，二项概率对每个固定 k 趋于上式。

做一道简单例题

例： 每分钟呼叫数服从参数 2 的泊松分布，一分钟至少两次的概率是 1−P(X=0)−P(X=1)=1−3e−2≈0.5940。

容易出错的地方

λ 与观察时段对应。在齐次泊松过程假设下时长翻倍 λ 才翻倍，不能仅凭某一个时段的分布推出整个过程性质。

SECTION 2.3

随机变量的分布函数

2.3Cumulative distribution function理解后再记忆

分布函数：把左边概率累计起来

先用一句话理解

把一条竖线从左向右推，分布函数就是竖线左侧（含竖线）的全部概率。

分布函数适用于离散、连续及混合分布。它单调不减、右连续，左端极限为 0，右端极限为 1。

F(x)=P(X≤x),P(a<X≤b)=F(b)−F(a)
使用条件

a<b。区间的开闭端点对离散型变量尤其重要。

展开推导 / 为什么成立

若 x1<x2，则 {X≤x1}⊆{X≤x2}，所以 F 不减。事件 {X≤x+1/n} 递减到 {X≤x}，概率的连续性给出右连续。把 {X≤b} 拆成 {X≤a} 和 {a<X≤b} 得区间公式。

做一道简单例题

例： X 取 0、1、2，概率 1/4、1/2、1/4。F 在 x<0 为 0；0≤x<1 为 1/4；1≤x<2 为 3/4；x≥2 为 1。注意 F(1)=3/4。

容易出错的地方

F 在跳跃点取跳跃后的值，不是跳跃前的值。

2.3Jumps & endpoints理解后再记忆

跳跃高度就是单点概率

先用一句话理解

分布函数在一个点突然长高了多少，那个点就装了多少概率。

记 F(a−)=limx↑aF(x)=P(X<a)。区间包含左端点时，需要使用左极限。

P(X=a)=F(a)−F(a−),P(a≤X≤b)=F(b)−F(a−)
使用条件

任何分布都适用。只有已知端点概率为零时，才能随意交换区间开闭。

展开推导 / 为什么成立

{X≤a} 是 {X<a} 与 {X=a} 的不交并，故两者之差给出单点概率。类似地，P(a<X<b)=F(b−)−F(a)。

做一道简单例题

例： 上例中 P(1≤X≤2)=F(2)−F(1−)=1−1/4=3/4；P(1<X≤2)=1−3/4=1/4。只改变一个等号，结果可能完全不同。

容易出错的地方

分布函数连续只说明无单点质量；严格说来，连续的分布函数未必存在概率密度。本课程常见连续型分布指能由密度积分表示的分布。

试一题：P2-07 →

SECTION 2.4

连续型随机变量及其概率密度

2.4Probability density function理解后再记忆

密度不是概率，面积才是

先用一句话理解

密度像概率堆积的高度；一个区间的概率是这个区间下方的面积。

连续型随机变量若有密度 f，则分布函数是 f 从负无穷到 x 的积分。密度非负、总积分为 1。

F(x)=∫−∞xf(t)dt,P(a<X≤b)=∫abf(x)dx
使用条件

f≥0（几乎处处），∫−∞∞f=1。在 f 连续的点有 F′(x)=f(x)。

展开推导 / 为什么成立

区间概率是分布函数之差，将两个积分相减得到区间积分。单点区间长度为零，因此 P(X=a)=0。f 的单个点值不影响积分；密度可大于 1。

做一道简单例题

例： f(x)=2x（0<x<1），其余为 0。总积分为 1；F(x) 在 (0,1) 为 x2；P(X>1/2)=1−(1/2)2=3/4。

容易出错的地方

求 F 必须写出支撑区间外的 0 和 1。不要把 f(a) 当成 P(X=a)。

试一题：P2-08 →
2.4Uniform distribution理解后再记忆

均匀分布：等长区间等概率

先用一句话理解

在固定区间内，没有哪个位置更受偏爱。

X~U(a,b) 时，区间内部的密度恒定为 1/(b−a)。

f(x)={1b−a,a<x<b0,其他
使用条件

a<b，随机变量在该区间均匀分布；区间端点密度取值不影响概率。

展开推导 / 为什么成立

设内部密度为常数 c，则归一性要求 c(b−a)=1，故 c=1/(b−a)。分布函数在内部是 (x−a)/(b−a)，区间外分别为 0 和 1。

做一道简单例题

例： 等车时间 X 在 0 到 10 分钟均匀，P(3<X<7)=4/10=0.4。已等了 3 分钟仍未来，P(X>7∣X>3)=3/7，并不等于 P(X>4)=0.6。

容易出错的地方

均匀分布没有一般的无记忆性；平移条件不能随意消去。

试一题：P2-10 →
2.4Exponential distribution理解后再记忆

指数分布与无记忆性

先用一句话理解

指数分布常用来表示等待时间；在这个模型里，已经等多久不改变剩余等待的分布。

使用速率参数 λ：f(x)=λe−λx（x>0），生存概率 P(X>x)=e−λx（x≥0）。

F(x)={0,x<01−e−λx,x≥0
使用条件

λ>0。有些教材使用尺度参数 θ=1/λ，必须先统一参数含义。

展开推导 / 为什么成立

对 s,t≥0，P(X>s+t∣X>s)=e−λ(s+t)/e−λs=e−λt=P(X>t)。分母为正，条件概率有定义。

做一道简单例题

例： 等待时间 X 服从速率 0.2 的指数分布，已等待 5 分钟，继续至少等 3 分钟的概率为 e−0.6≈0.5488。

容易出错的地方

无记忆性是模型性质，并非所有设备寿命或等待时间都满足。

试一题：P2-11 →
2.4Normal distribution理解后再记忆

正态分布：先标准化，再查 Φ

先用一句话理解

把位置移到 0，再按尺度缩放，所有正态分布都可以用同一张表计算。

X~N(μ,σ2)，标准化变量 Z=(X−μ)/σ~N(0,1)。记标准正态分布函数为 Φ。

P(a<X≤b)=Φ(b−μσ)−Φ(a−μσ)
使用条件

σ>0。N(μ,σ2) 的第二个参数是方差，标准化分母是标准差 σ。

展开推导 / 为什么成立

由 a<X≤b 等价于 (a−μ)/σ<Z≤(b−μ)/σ，再用分布函数差。标准正态密度关于 0 对称，故 Φ(−z)=1−Φ(z)。

做一道简单例题

例： X~N(10,4)，σ=2。P(8<X<12)=Φ(1)−Φ(−1)=2Φ(1)−1≈0.6827。

容易出错的地方

标准化除以 2，而不是除以 4；查表前先确认表给的是左侧累计概率还是 0 到 z 的面积。

试一题：P2-12 →

SECTION 2.5

随机变量的函数的分布

2.5Transformation of discrete variables理解后再记忆

离散变换：合并相同的新取值

先用一句话理解

先把每个旧取值代入函数，再把落到同一个新取值的概率合并。

若 Y=g(X)，对每一个可能的 y，累加所有满足 g(xk)=y 的概率。

P(Y=y)=∑k:g(xk)=yP(X=xk)
使用条件

g 不必单调；变换后的取值要去重。

展开推导 / 为什么成立

事件 {Y=y} 是所有 {X=xk}（满足 g(xk)=y）的互斥并，所以概率相加。

做一道简单例题

例： X 取 −1、0、1，概率为 0.2、0.3、0.5。Y=X2 取 0 和 1，概率为 0.3、0.7。不能把两个 Y=1 当成不同取值。

容易出错的地方

变换分布律后要再检查总概率为 1。

试一题：P2-14 →
2.5CDF method理解后再记忆

连续变换：分布函数法永远先行

先用一句话理解

直接问“新变量不超过 y”意味着旧变量落在哪里，再算那个区间的概率。

先写 FY(y)=P(g(X)≤y)，分段确定事件，得到分布函数后再求导。它尤其适合非单调函数。

FY(y)=P(g(X)≤y)
使用条件

先判断 Y 的取值范围。只有确实存在密度时才将 FY 求导当作密度。

展开推导 / 为什么成立

以 Y=X2 为例，y<0 时概率为 0；y≥0 时事件变为 −y≤X≤y。对有密度的 X，可写为 FX(y)−FX(−y)；如果 X 含单点质量，下端需使用左极限。

做一道简单例题

例： X~U(−1,1)，Y=X2。当 0≤y<1，FY(y)=2y/2=y；y<0 时为 0，y≥1 时为 1。因此 fY(y)=1/(2y)（0<y<1）。

容易出错的地方

不能只取正根。密度在 0 附近趋于无穷不违背要求，只要可积且总积分为 1。

试一题：P2-15 →
2.5Change of variables理解后再记忆

单调变换：别漏掉导数绝对值

先用一句话理解

变换会拉伸或压缩横轴，概率面积要守恒，因此密度要乘上反函数变化的速度。

若 g 在 X 的支撑区间内严格单调，逆函数 x=h(y) 可微，则新密度是旧密度乘上反函数导数的绝对值。

fY(y)=fX(h(y))|h′(y)|
使用条件

只在变换后的支撑区间使用公式，区间外为零；要求相应的可微变换条件。非单调时需按各逆分支求和或使用分布函数法。

展开推导 / 为什么成立

单调递增时 FY(y)=FX(h(y))，链式法则给出密度。单调递减时不等号反向，分布函数变为 1−FX(h(y))（对连续型 X），导数多一个负号，两种情况统一为绝对值。

做一道简单例题

例： X~U(0,1)，Y=−lnX。逆函数 X=e−y，|h′(y)|=e−y，且 y>0。所以 fY(y)=e−y，Y 服从速率 1 的指数分布。

容易出错的地方

对 Y=aX+b（a≠0）应乘 1/|a|，而不是乘 |a|。
