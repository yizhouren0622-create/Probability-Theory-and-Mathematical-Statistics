先认清问题，再选择公式。

基础薄弱也没关系。从下面的符号与四个问题开始。

一张题目，先问自己四件事

  1. 一次试验到底做什么？
    写清有无放回、顺序是否重要、是否固定次数。
  2. 问题中的“且、或、已知”是什么事件？
    把自然语言翻译为交、并、补和条件概率。
  3. 可用哪条模型假设？
    等可能、独立、均匀、正态都要有依据，不能由“随机”自行推出。
  4. 结果是否合理？
    概率在 0 到 1 之间；分布律总和与密度积分均为 1。

符号小词典

主题写法怎样读
事件

A∪B / A∩B

A 或 B / A 且 B（交集有时简记 AB）
条件

P(A∣B)

已知 B 发生，A 发生的概率
组合

(nk)

从 n 个不同对象中不计顺序地选 k 个
分布律

P(X=x)

离散变量在 x 处的概率
累计

F(x)=P(X≤x)

截至 x（包含 x）的全部概率
密度

f(x)

概率堆积的高度；区间概率用积分

三个先修小练习

组合数：为什么从 5 个选 2 个是 10？

先按顺序选有 5·4=20 种。但每一对被按两个顺序数了两遍，所以 (52)=20/2=10。检验：直接列 12、13、14、15、23、24、25、34、35、45。

积分：如何算区间下方的面积？

试算 ∫012xdx。原函数为 x2，代上限再减下限，得 12−02=1。把上限换成 t，面积为 t2（0≤t≤1），这也是一个分布函数的内部表达式。

解不等式：平方如何反解？

当 y≥0，x2≤y 等价于 −y≤x≤y，不是只有 x≤y。如果已知 x 非负，才可以只保留 0≤x≤y。
