原创 P5-01第 5.1 节 · 巩固

切比雪夫给出样本量

独立同分布测量均值 μ、方差 9。用切比雪夫不等式保证 P(|X¯−μ|<0.5)≥0.9，至少取多少次？

给我一点提示
提示 1

平均值的方差为 9/n。

提示 2

补事件概率应不超过 0.1。

提示 3

保守保证与最小真实样本量不同。

带我一步一步做

第 1 / 4 步

  1. D(X¯)=9/n。

  2. P(|X¯−μ|≥0.5)≤9/(0.25n)=36/n。

  3. 令 36/n≤0.1。

  4. 解得整数 n≥360。

查看完整解答与检验

  1. D(X¯)=9/n。

  2. P(|X¯−μ|≥0.5)≤9/(0.25n)=36/n。

  3. 令 36/n≤0.1。

  4. 解得整数 n≥360。

答案

切比雪夫保证取 n=360 即可。

检验与提醒

这只是由该不等式得到的充分样本量。

原创 P5-02第 5.1 节 · 巩固

频率的保守保证

独立重复进行成功概率 p 未知的试验，要求成功频率偏离 p 小于 0.1 的概率至少为 0.95。用伯努利及切比雪夫结果给出统一充分样本量。

给我一点提示
提示 1

伯努利方差为 p(1−p)。

提示 2

对所有 p，其最大值为 1/4。

提示 3

令上界不超过 0.05。

带我一步一步做

第 1 / 4 步

  1. D(Nn/n)=p(1−p)/n。

  2. p(1−p)≤1/4。

  3. P(|Nn/n−p|≥0.1)≤25/n。

  4. 25/n≤0.05 得 n≥500。

查看完整解答与检验

  1. D(Nn/n)=p(1−p)/n。

  2. p(1−p)≤1/4。

  3. P(|Nn/n−p|≥0.1)≤25/n。

  4. 25/n≤0.05 得 n≥500。

答案

n=500 是不依赖 p 的充分值。

检验与提醒

最坏方差在 p=1/2 处取得。

原创 P5-03第 5.2 节 · 巩固

和与平均的标准化

独立同分布的 100 个变量均值 2、方差 9，用中心极限定理近似求 P(170≤∑Xi≤230)。

给我一点提示
提示 1

先求和的均值和方差。

提示 2

标准差不是 900。

提示 3

转换为标准正态的对称区间。

带我一步一步做

第 1 / 4 步

  1. 和的均值为 100×2=200。

  2. 和的方差为 100×9=900，标准差 30。

  3. 边界标准化为 (170−200)/30=−1 与 1。

  4. 近似概率为 Φ(1)−Φ(−1)≈0.6827。

查看完整解答与检验

  1. 和的均值为 100×2=200。

  2. 和的方差为 100×9=900，标准差 30。

  3. 边界标准化为 (170−200)/30=−1 与 1。

  4. 近似概率为 Φ(1)−Φ(−1)≈0.6827。

答案

约 0.6827（渐近近似）。

检验与提醒

原分布形态未知，不能把这个近似当作误差已有保证的精确值。

原创 P5-04第 5.1 节 · 提高

同一个尾概率的两种上界

X~Pois(2)。分别用马尔可夫不等式和切比雪夫不等式给 P(X≥5) 一个上界，再求其精确值，比较松紧。

给我一点提示
提示 1

X 非负，均值为 2，可直接应用马尔可夫不等式。

提示 2

泊松分布方差也是 2；X≥5 时 |X−2|≥3。

提示 3

精确值可由 1 减去 P(X≤4) 得到。

带我一步一步做

第 1 / 4 步

  1. E(X)=2，故 P(X≥5)≤E(X)/5=0.4。

  2. D(X)=2，且 {X≥5}⊆{|X−2|≥3}，故切比雪夫给出 P(X≥5)≤2/9≈0.2222。

  3. P(X≥5)=1−e−2∑k=042k/k!≈0.052653。

  4. 两个上界均有效，切比雪夫在本题更紧；它们都不等于精确值。

查看完整解答与检验

  1. E(X)=2，故 P(X≥5)≤E(X)/5=0.4。

  2. D(X)=2，且 {X≥5}⊆{|X−2|≥3}，故切比雪夫给出 P(X≥5)≤2/9≈0.2222。

  3. P(X≥5)=1−e−2∑k=042k/k!≈0.052653。

  4. 两个上界均有效，切比雪夫在本题更紧；它们都不等于精确值。

答案

马尔可夫上界 0.4，切比雪夫上界 2/9，精确概率约 0.052653。

检验与提醒

比较上界前先确认随机变量非负以及所用均值、方差正确。

原创 P5-05第 5.2 节 · 提高

半格修正的数值作用

B~Bin(36,0.5)。求 P(B≤21) 的精确和式，并分别给出不修正与连续性修正的正态近似，比较误差。

给我一点提示
提示 1

先求二项分布的均值与标准差。

提示 2

不修正用边界 21；修正后用边界 21.5。

提示 3

精确和式从 k=0 加到 21。

带我一步一步做

第 1 / 4 步

  1. E(B)=36(0.5)=18，D(B)=36(0.5)(0.5)=3。

  2. P(B≤21)=2−36∑k=021(36k)≈0.878508。

  3. 不修正时为 Φ((21−18)/3)=Φ(1)≈0.841345。

  4. 修正后为 Φ((21.5−18)/3)=Φ(7/6)≈0.878327，两者绝对误差约为 0.037163 和 0.000180。

查看完整解答与检验

  1. E(B)=36(0.5)=18，D(B)=36(0.5)(0.5)=3。

  2. P(B≤21)=2−36∑k=021(36k)≈0.878508。

  3. 不修正时为 Φ((21−18)/3)=Φ(1)≈0.841345。

  4. 修正后为 Φ((21.5−18)/3)=Φ(7/6)≈0.878327，两者绝对误差约为 0.037163 和 0.000180。

答案

精确值约 0.878508；不修正约 0.841345；修正后约 0.878327。

检验与提醒

本例修正显著改善结果，但不代表它对所有 n、p 和尾部事件都同样准确。

原创 P5-06第 5.1 节 · 巩固

没有有限方差，平均数还能收敛吗

独立同分布的 Xi 具有密度 f(x)=32x−5/2（x≥1，其余为 0）。验证密度归一化，计算均值、判断方差是否有限，说明样本平均的大数定律和本章 CLT 能否应用；给出 M≥1 时截断尾期望 E[X1{X>M}]。

给我一点提示
提示 1

分别积分 f、xf、x²f。

提示 2

X 非负，一阶绝对矩就是均值。

提示 3

辛钦与此处 CLT 的矩条件不同。

带我一步一步做

第 1 / 5 步

  1. ∫1∞32x−5/2dx=1，故非负密度归一化。

  2. E(X)=32∫1∞x−3/2dx=3，一阶绝对矩有限。

  3. E(X2)=32∫1∞x−1/2dx=∞，没有有限方差。

  4. 辛钦大数定律可用，故 X¯n→P3。有限正方差版本 CLT 的条件不满足，不能套用该标准化公式。

  5. 当 M≥1，尾期望为 32∫M∞x−3/2dx=3/M→0，这正是截断证明需要控制的尾项。

查看完整解答与检验

  1. ∫1∞32x−5/2dx=1，故非负密度归一化。

  2. E(X)=32∫1∞x−3/2dx=3，一阶绝对矩有限。

  3. E(X2)=32∫1∞x−1/2dx=∞，没有有限方差。

  4. 辛钦大数定律可用，故 X¯n→P3。有限正方差版本 CLT 的条件不满足，不能套用该标准化公式。

  5. 当 M≥1，尾期望为 32∫M∞x−3/2dx=3/M→0，这正是截断证明需要控制的尾项。

答案

密度积分为 1，均值 3，二阶矩无限。平均数依概率收敛到 3；本章有限方差 CLT 不能直接使用。截断尾期望为 3/M。

检验与提醒

“某条 CLT 的条件不满足”不等于已经证明不存在任何其他极限定理；本题只判断给定定理是否能用。

原创 P5-07第 5.2 节 · 应用

不同成功率的计数怎样近似

Xᵢ 相互独立，奇数 i 时为 Bernoulli(.2)，偶数 i 时为 Bernoulli(.5)。证明李雅普诺夫条件。取 n=200，求总和 S 的均值和方差，并用连续性修正的正态近似估计 P(S≤80)。它是否二项分布？

给我一点提示
提示 1

中心化后 |Xᵢ−pᵢ|≤1，所以三阶绝对矩≤二阶矩。

提示 2

200 次中各有 100 个两种参数。

提示 3

对整数计数用 80.5 作上边界，标准差为 √41。

带我一步一步做

第 1 / 5 步

  1. 每项方差至少 .16，故 Bₙ²≥.16n→∞。三阶绝对矩总和≤Bₙ²，所以 Lₙ(1)≤1/Bₙ→0。

  2. n=200 时，ES=100×.2+100×.5=70；Var(S)=100×.16+100×.25=41。

  3. 独立非同分布 CLT 给 S 近似 N(70,41)。连续性修正后，P(S≤80)≈Φ(10.5/41)≈0.9495。

  4. 各次成功率不同，因此不是 Bin(200,p) 的标准同参数二项模型；均值虽可写 200×.35，方差却不是 200×.35×.65=45.5。

  5. 本题用条件证明渐近可行，再做有限样本近似；仅凭 CLT 不能保证此 n 的绝对误差小于某个指定数值。

查看完整解答与检验

  1. 每项方差至少 .16，故 Bₙ²≥.16n→∞。三阶绝对矩总和≤Bₙ²，所以 Lₙ(1)≤1/Bₙ→0。

  2. n=200 时，ES=100×.2+100×.5=70；Var(S)=100×.16+100×.25=41。

  3. 独立非同分布 CLT 给 S 近似 N(70,41)。连续性修正后，P(S≤80)≈Φ(10.5/41)≈0.9495。

  4. 各次成功率不同，因此不是 Bin(200,p) 的标准同参数二项模型；均值虽可写 200×.35，方差却不是 200×.35×.65=45.5。

  5. 本题用条件证明渐近可行，再做有限样本近似；仅凭 CLT 不能保证此 n 的绝对误差小于某个指定数值。

答案

Lₙ(1)≤1/Bₙ→0；n=200 时均值 70、方差 41，修正近似约 0.9495；不是同参数二项分布。

检验与提醒

把 p 平均后直接套二项分布，会保留均值却算错方差；先逐项累加方差。

原创 P5-08第 5.2 节 · 反例

正态极限不能只查均值和方差

设 Xᵢ=2ⁱ⁻¹εᵢ，εᵢ 独立等概率 ±1。列出 n=3 的总和分布，算其均值、方差，再证明任意 n 的标准化和绝对值小于 √3，据此排除标准正态极限。

给我一点提示
提示 1

将三个符号组合穷举为八种。

提示 2

独立方差为 1+4+16。

提示 3

在正态分布的连续点 x=2 比较累计概率。

带我一步一步做

第 1 / 4 步

  1. n=3 的八个等概率结果为 −7、−5、−3、−1、1、3、5、7。对称性给均值 0，平方平均为 21。

  2. 一般 n 时，总方差 Bₙ²=Σᵢ₌₁ⁿ4ⁱ⁻¹=(4ⁿ−1)/3；最大总和为 2ⁿ−1。

  3. 最大标准化平方为 (2ⁿ−1)²/Bₙ²=3(2ⁿ−1)/(2ⁿ+1)<3。

  4. 所以任意 n 都有 Fₙ(2)=1，而 Φ(2)≈0.97725<1。依分布趋于标准正态要求在该点收敛到 Φ(2)，出现矛盾。

查看完整解答与检验

  1. n=3 的八个等概率结果为 −7、−5、−3、−1、1、3、5、7。对称性给均值 0，平方平均为 21。

  2. 一般 n 时，总方差 Bₙ²=Σᵢ₌₁ⁿ4ⁱ⁻¹=(4ⁿ−1)/3；最大总和为 2ⁿ−1。

  3. 最大标准化平方为 (2ⁿ−1)²/Bₙ²=3(2ⁿ−1)/(2ⁿ+1)<3。

  4. 所以任意 n 都有 Fₙ(2)=1，而 Φ(2)≈0.97725<1。依分布趋于标准正态要求在该点收敛到 Φ(2)，出现矛盾。

答案

n=3 八个对称奇数各占 1/8，均值 0、方差 21；统一标准化支撑在 (−√3,√3)，因此不可能趋于 N(0,1)。

检验与提醒

证明不成立不能只说“不同分布”；不少非同分布和也满足 CLT。这里给出一个明确的分布函数矛盾。
