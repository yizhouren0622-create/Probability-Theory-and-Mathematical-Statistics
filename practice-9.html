原创 P9-01第 9.1 节 · 进阶

从平方和到检验量

三组样本量均为 4，ST=52,SE=16。求组间平方和、三个自由度与 F 值；可否仅凭 F 值宣布某两组不同？

给我一点提示
提示 1

先用平方和分解。

提示 2

总样本量是 12。

提示 3

整体检验与两两比较的结论不同。

带我一步一步做

第 1 / 5 步

  1. N=12,a=3。

  2. SA=ST−SE=36。

  3. 总、组间、组内自由度分别为 11,2,9。

  4. F=(36/2)/(16/9)=10.125；需结合 F(2,9) 的上尾临界值或 p 值作整体判断。

  5. 即使拒绝 H0，也只能说至少一组均值不同；具体比较需要相应对比和多重比较控制。

查看完整解答与检验

  1. N=12,a=3。

  2. SA=ST−SE=36。

  3. 总、组间、组内自由度分别为 11,2,9。

  4. F=(36/2)/(16/9)=10.125；需结合 F(2,9) 的上尾临界值或 p 值作整体判断。

  5. 即使拒绝 H0，也只能说至少一组均值不同；具体比较需要相应对比和多重比较控制。

答案

SA=36，自由度 11,2,9，F=10.125；不能直接确定哪两组不同。

检验与提醒

平方和与自由度均可相加核对。

原创 P9-02第 9.2 节 · 进阶

没有重复时发生了什么

2×2 实验每格只有一次观测，拟合包括两主效应及交互的模型。求模型参数数与残差自由度；若想作加性模型检验，还必须加什么假设？

给我一点提示
提示 1

总观测数为 4。

提示 2

参数维数为截距、A、B、AB 自由度之和。

提示 3

交互与误差不能用同一份剩余变异分别估计。

带我一步一步做

第 1 / 4 步

  1. 共有 4 个观测。

  2. 完整模型参数维数为 1+1+1+1=4。

  3. 因此残差自由度 4−4=0，不能由残差估计误差方差。

  4. 假定交互作用为零后拟合加性模型，残差自由度为 1；其有效性依赖该附加假设及独立正态等方差假设。

查看完整解答与检验

  1. 共有 4 个观测。

  2. 完整模型参数维数为 1+1+1+1=4。

  3. 因此残差自由度 4−4=0，不能由残差估计误差方差。

  4. 假定交互作用为零后拟合加性模型，残差自由度为 1；其有效性依赖该附加假设及独立正态等方差假设。

答案

完整模型残差自由度为 0；加性检验需另假定无交互作用。

检验与提醒

加性模型所称误差若实际含交互，其 F 参照分布通常不再成立。

原创 P9-04第 9.4 节 · 进阶

嵌套模型的部分 F 检验

同一批 30 个观测，完整模型有 5 个参数且 SSEF=50，约束模型有 3 个参数且 SSER=66。计算 F 及自由度。

给我一点提示
提示 1

参数数包括截距。

提示 2

独立约束数是维数差。

提示 3

分母使用完整模型残差均方。

带我一步一步做

第 1 / 4 步

  1. p=5,n=30，误差自由度 25。

  2. q=5−3=2。

  3. 增量均方为 (66−50)/2=8。

  4. 残差均方 50/25=2，故 F=4，原假设下服从 F(2,25)。

正交设计中的岭收缩

中心化设计 XTX=4I，OLS 系数为 (3,−2)。取 λ=4，求岭估计；能否保证其均方误差一定更小？

给我一点提示
提示 1

特征方向收缩因子为 d/(d+λ)。

提示 2

两个方向在本题中相同。

提示 3

别忘记偏差平方。

带我一步一步做

第 1 / 4 步

  1. 两个特征值均为 d=4。

  2. 收缩因子 4/(4+4)=1/2。

  3. 岭估计为 (1.5,−1)。

  4. 其方差减少，但引入依赖真实系数的偏差；不能仅凭收缩判断总均方误差必然下降。

查看完整解答与检验

  1. 两个特征值均为 d=4。

  2. 收缩因子 4/(4+4)=1/2。

原创 P9-07第 9.1 节 · 进阶

三组均值的预定对比

三组各有三个独立正态观测：A 为 (1,2,3)，B 为 (4,5,6)，C 为 (2,3,4)。假设共同误差方差相等。比较 B 组均值与 A、C 两组均值的平均差，求对比估计、标准误、t 值和自由度。

给我一点提示
提示 1

把目标写成 L=μB−(μA+μC)/2。

提示 2

分别算三组均值与组内平方和，合并为 MSE。

提示 3

方差乘数是 ∑ci2/ni，分母自由度为 N−a。

带我一步一步做

第 1 / 4 步

  1. c=(−1/2,1,−1/2)，系数和为 0；三组均值 (2,5,3)，故 L^=5−(2+3)/2=2.5。

  2. 每组组内平方和为 2，SE=6；N−a=9−3=6，MSE=6/6=1。

  3. ∑ci2/ni=(1/4+1+1/4)/3=1/2，估计标准误为 1/2≈0.7071。

  4. t=2.5/1/2=12.5≈3.5355，自由度 6。若拿它检验 L=0，须按预定双侧或单侧方向选临界值。

查看完整解答与检验

  1. c=(−1/2,1,−1/2)，系数和为 0；三组均值 (2,5,3)，故 L^=5−(2+3)/2=2.5。

  2. 每组组内平方和为 2，SE=6；N−a=9−3=6，MSE=6/6=1。

  3. ∑ci2/ni=(1/4+1+1/4)/3=1/2，估计标准误为 1/2≈0.7071。

  4. t=2.5/1/2=12.5≈3.5355，自由度 6。若拿它检验 L=0，须按预定双侧或单侧方向选临界值。

答案

L^=2.5，SE=1/2，t≈3.5355，自由度 6。

检验与提醒

该对比的 t2=12.5，而三组整体 ANOVA 的 F=7；不要把一个特定方向的检验与所有方向的整体检验混为一谈。

原创 P9-08第 9.3 节 · 进阶

同一条回归线的 R² 与 F=t²

用数据 (x,y)=(0,1),(1,2),(2,2) 拟合含截距的一元直线。已知 Sxx=2、Sxy=1，求 Syy、SSR、SSE、R2，并验证检验斜率为零时 F=t2。

给我一点提示
提示 1

先算 y¯=5/3 与 Syy=∑(yi−y¯)2。

提示 2

用 SSR=Sxy2/Sxx，再由平方和分解求 SSE。

提示 3

MSE=SSE/(n−2)，F=SSR/MSE；斜率标准误是 MSE/Sxx。

带我一步一步做

第 1 / 4 步

  1. y¯=5/3，故 Syy=(−2/3)2+(1/3)2+(1/3)2=2/3。

  2. SSR=Sxy2/Sxx=1/2，SSE=Syy−SSR=2/3−1/2=1/6。

  3. R2=SSR/Syy=3/4；样本相关系数平方 r2=Sxy2/(SxxSyy)=3/4。

  4. MSE=(1/6)/(3−2)=1/6，F=(1/2)/(1/6)=3；斜率 β^1=1/2，t=(1/2)/(1/6)/2=3，所以 t2=3。

查看完整解答与检验

  1. y¯=5/3，故 Syy=(−2/3)2+(1/3)2+(1/3)2=2/3。

  2. SSR=Sxy2/Sxx=1/2，SSE=Syy−SSR=2/3−1/2=1/6。

  3. R2=SSR/Syy=3/4；样本相关系数平方 r2=Sxy2/(SxxSyy)=3/4。

  4. MSE=(1/6)/(3−2)=1/6，F=(1/2)/(1/6)=3；斜率 β^1=1/2，t=(1/2)/(1/6)/2=3，所以 t2=3。

答案

Syy=2/3、SSR=1/2、SSE=1/6、R2=3/4，F=t2=3。

检验与提醒

误差自由度仅为 1；高样本内 R² 不意味着检验已显著或预测有保证。

原创 P9-09第 9.4 节 · 推导

两个无偏斜率估计的精度

模型 Yi=β0+β1xi+εi，设计 x=(0,1,2)，误差均值 0、协方差 σ2I。比较 (Y3−Y1)/2 和 Y2−Y1：证明无偏，求方差，写出系数差向量，并解释为何不需要正态假设。

给我一点提示
提示 1

用设计点差异计算两个估计的均值。

提示 2

不相关误差的线性组合方差等于 σ² 乘系数平方和。

提示 3

系数差应同时与常数列及 x 列正交。

带我一步一步做

第 1 / 5 步

  1. 两个均值分别为 [(β0+2β1)−β0]/2=β1 和 (β0+β1)−β0=β1，均无偏。

  2. 最小二乘斜率的系数向量为 c=(−1/2,0,1/2)，故方差为 σ2(1/4+1/4)=σ2/2。

  3. 另一个系数向量为 a=(−1,1,0)，方差为 σ2(1+1)=2σ2。

  4. d=a−c=(−1/2,1,−1/2)，它的分量和为 0，与 x 的内积也为 0；因此它处在设计列空间的正交补。

  5. σ2‖d‖2=3σ2/2，恰为方差之差。以上仅使用均值、协方差和无偏约束；没有使用正态密度。

查看完整解答与检验

  1. 两个均值分别为 [(β0+2β1)−β0]/2=β1 和 (β0+β1)−β0=β1，均无偏。

  2. 最小二乘斜率的系数向量为 c=(−1/2,0,1/2)，故方差为 σ2(1/4+1/4)=σ2/2。

  3. 另一个系数向量为 a=(−1,1,0)，方差为 σ2(1+1)=2σ2。

  4. d=a−c=(−1/2,1,−1/2)，它的分量和为 0，与 x 的内积也为 0；因此它处在设计列空间的正交补。

  5. σ2‖d‖2=3σ2/2，恰为方差之差。以上仅使用均值、协方差和无偏约束；没有使用正态密度。

答案

两者均无偏；方差依次为 σ2/2、2σ2，差为 3σ2/2；d=(−1/2,1,−1/2)。

检验与提醒

误差不相关足够用于本题方差比较；若要进一步使用精确 t 检验，则还需要对应的正态条件。

原创 P9-10第 9.4 节 · 综合

从设计秩到残差分布

四个设计点 x=(−1,0,1,2)，观测 y=(0,1,1,4)，按含截距正态直线回归拟合。求估计系数、残差、s² 和斜率为 0 的 t 统计量；说明 SSE/σ² 的分布与残差之间是否互相独立。

给我一点提示
提示 1

先算均值及中心化交叉乘积。

提示 2

残差方差估计的分母是 n−p。

提示 3

估计量与残差独立，不等于各个残差互相独立。

带我一步一步做

第 1 / 5 步

  1. x¯=1/2、y¯=3/2、Sxx=5、Sxy=6，故斜率 6/5、截距 9/10。

  2. 拟合值为 (−0.3,0.9,2.1,3.3)，残差为 (0.3,0.1,−1.1,0.7)，总和与和 x 的内积均为 0。

  3. SSE=1.8，n−p=2，因此 s²=0.9。

  4. 斜率标准误为 s/Sxx=0.18，t 统计量为 1.2/0.18=22，零假设下服从 t(2)。

  5. SSE/σ²∼χ²(2)，并与估计系数独立；但残差向量有协方差 σ²(I−H)，各分量通常相关。此设计 h₁₂=0.4，故 Cov(e₁,e₂)=−0.4σ²。

查看完整解答与检验

  1. x¯=1/2、y¯=3/2、Sxx=5、Sxy=6，故斜率 6/5、截距 9/10。

  2. 拟合值为 (−0.3,0.9,2.1,3.3)，残差为 (0.3,0.1,−1.1,0.7)，总和与和 x 的内积均为 0。

  3. SSE=1.8，n−p=2，因此 s²=0.9。

  4. 斜率标准误为 s/Sxx=0.18，t 统计量为 1.2/0.18=22，零假设下服从 t(2)。

  5. SSE/σ²∼χ²(2)，并与估计系数独立；但残差向量有协方差 σ²(I−H)，各分量通常相关。此设计 h₁₂=0.4，故 Cov(e₁,e₂)=−0.4σ²。

答案

截距 0.9、斜率 1.2；SSE=1.8、s²=0.9；t=2√2、自由度 2；SSE/σ²∼χ²(2)，残差分量不独立。

检验与提醒

用残差的两条正规方程检查计算。即使误差本身独立，拟合后残差也会因共享估计系数而相关。
