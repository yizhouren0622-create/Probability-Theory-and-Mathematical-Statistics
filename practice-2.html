原创 P2-01第 2.1 节 · 基础

把结果映射成得分

抛一枚公平骰子，点数为偶数得 2 分，奇数得 −1 分。写出得分 X 的分布律并求 P(X>0)。

给我一点提示
提示 1

先找 X 的不同取值。

提示 2

每个得分对应三个点数。

提示 3

正分只对应 X=2。

带我一步一步做

第 1 / 4 步

  1. X 的取值为 −1、2。

  2. 奇数 1、3、5 对应 −1，概率为 1/2。

  3. 偶数 2、4、6 对应 2，概率为 1/2。

  4. P(X>0)=P(X=2)=1/2。

查看完整解答与检验

  1. X 的取值为 −1、2。

  2. 奇数 1、3、5 对应 −1，概率为 1/2。

  3. 偶数 2、4、6 对应 2，概率为 1/2。

  4. P(X>0)=P(X=2)=1/2。

答案

P(X=−1)=P(X=2)=1/2；P(X>0)=1/2。

检验与提醒

随机变量取值可为负，概率不能为负。

原创 P2-29第 2.2 节 · 推导

两个峰值不是计算误差

分别求 Bin(9,0.3)、Bin(8,0.3)、Bin(5,0.5) 的众数，用相邻项之比解释并列峰；再比较它们的期望。

给我一点提示
提示 1

先算 (n+1)p，区分整数与非整数。

提示 2

比值等于 1 时，相邻两项相等。

提示 3

期望是 np，不必为整数。

带我一步一步做

第 1 / 4 步

  1. Bin(9,.3) 的 a=3，众数为 2、3。具体比值 p₃/p₂=(7/3)×(.3/.7)=1。

  2. Bin(8,.3) 的 a=2.7，众数为 2；p₂/p₁>1 而 p₃/p₂<1。

  3. Bin(5,.5) 的 a=3，众数为 2、3；这也符合关于 2.5 对称的形状。

  4. 对应期望分别为 2.7、2.4、2.5，都不必等于任一众数。众数是单点概率最大处，期望是所有取值的概率加权平均。

查看完整解答与检验

  1. Bin(9,.3) 的 a=3，众数为 2、3。具体比值 p₃/p₂=(7/3)×(.3/.7)=1。

  2. Bin(8,.3) 的 a=2.7，众数为 2；p₂/p₁>1 而 p₃/p₂<1。

  3. Bin(5,.5) 的 a=3，众数为 2、3；这也符合关于 2.5 对称的形状。

  4. 对应期望分别为 2.7、2.4、2.5，都不必等于任一众数。众数是单点概率最大处，期望是所有取值的概率加权平均。

答案

众数依次为 {2,3}、{2}、{2,3}；期望依次为 2.7、2.4、2.5。

检验与提醒

(n+1)p 为整数时，需要检查相邻两个值，不要遗漏较小的 a−1。

原创 P2-28第 2.3 节 · 证明

混合分布的广义逆

分布由 1/4 概率的常量 0 与 3/4 概率的 U(1,3) 混合组成。写出 F、广义逆 Q，求下 25%、50%、90% 分位点，并判断 F(X) 是否均匀。解释 Q(1/4) 为什么不是 1。

给我一点提示
提示 1

0 处先跳到 1/4，0 到 1 之间累计值保持不变。

提示 2

u>1/4 时反解 1/4+(3/8)(x−1)=u。

提示 3

广义逆取最左达到该累计水平的位置。

带我一步一步做

第 1 / 5 步

  1. F(x)=0（x<0）；1/4（0≤x≤1）；1/4+(3/8)(x−1)（1<x<3）；1（x≥3）。

  2. Q(u)=0（0<u≤1/4）；1+(8/3)(u−1/4)（1/4<u<1）。端点 u=1/4 取 0，因为 F 在 0 已经达到该水平。

  3. 三个分位点依次为 0、5/3、41/15；中间的平坦区不会使 Q(1/4) 随意取成 1。

  4. 原子 X=0 发生概率 1/4，此时 F(X)=1/4，故 F(X) 在 1/4 有正的点质量，不可能服从连续均匀分布。

  5. 另一方面，对 U∼U(0,1)，Q 将长度 1/4 的区间压到 0，将其余部分线性映到 (1,3)，恰好产生指定混合分布。

查看完整解答与检验

  1. F(x)=0（x<0）；1/4（0≤x≤1）；1/4+(3/8)(x−1)（1<x<3）；1（x≥3）。

  2. Q(u)=0（0<u≤1/4）；1+(8/3)(u−1/4)（1/4<u<1）。端点 u=1/4 取 0，因为 F 在 0 已经达到该水平。

  3. 三个分位点依次为 0、5/3、41/15；中间的平坦区不会使 Q(1/4) 随意取成 1。

  4. 原子 X=0 发生概率 1/4，此时 F(X)=1/4，故 F(X) 在 1/4 有正的点质量，不可能服从连续均匀分布。

  5. 另一方面，对 U∼U(0,1)，Q 将长度 1/4 的区间压到 0，将其余部分线性映到 (1,3)，恰好产生指定混合分布。

答案

F 先在 0 跳到 1/4，再于 (1,3) 线性增到 1；Q 按上述两段；分位点 0、5/3、41/15；F(X) 不均匀。

检验与提醒

只在 u>1/4 时使用线性反解；否则会漏掉原子，得到错误的纯连续分布。

原创 P2-30第 2.4 节 · 证明

同一个尾概率，在两种时间域中识别不同参数

X 是几乎必然有限的严格正等待时间，对全部实数时刻无记忆，且 P(X>2)=.36；G 是正整数等待，对全部整数时刻无记忆，且 P(G>2)=.36。分别求参数、均值与 P(X>5|X>3)、P(G>5|G>3)，并说明只有 P(X>2)=.36 为什么不能单独识别分布。

给我一点提示
提示 1

实数时间的生存函数必须是 e⁻λt。

提示 2

几何尾序列是 qᵐ。

提示 3

两种情形都用所需剩余时长 5−3=2。

带我一步一步做

第 1 / 4 步

  1. 连续时间由特征定理有 exp(−2λ)=.36，故 λ=−log(.6)≈.510826，均值 1/λ≈1.95762。

  2. 离散时间 q²=.36，q=.6，成功概率 p=.4，均值 1/p=2.5次。

  3. 条件剩余长度均为2，因此两个条件概率都为.36。

  4. 单条尾概率只能约束一处 CDF，许多不同分布都能满足；本题借助的是全部时刻的无记忆性，不能反过来由一处数据验证该性质。

查看完整解答与检验

  1. 连续时间由特征定理有 exp(−2λ)=.36，故 λ=−log(.6)≈.510826，均值 1/λ≈1.95762。

  2. 离散时间 q²=.36，q=.6，成功概率 p=.4，均值 1/p=2.5次。

  3. 条件剩余长度均为2，因此两个条件概率都为.36。

  4. 单条尾概率只能约束一处 CDF，许多不同分布都能满足；本题借助的是全部时刻的无记忆性，不能反过来由一处数据验证该性质。

答案

连续率 λ=−log(.6)，均值≈1.95762；几何成功率 .4，均值2.5；两个条件概率均.36。

检验与提醒

连续率参数的单位是每单位时间，几何 p 是每次试验成功概率；两个数字和均值不应互换。

原创 P2-31第 2.4 节 · 推导

从高斯积分到正态四阶矩

先用二维极坐标说明标准正态密度为何要除以 √(2π)，再用 φ′=−zφ 推出 E(Z⁴)=3。最后对 X∼N(2,9) 求 E[(X−2)⁴]、E(X⁴) 和 Var(X²)。

给我一点提示
提示 1

先把一维积分平方。

提示 2

m₄=3m₂，而 m₂=m₀=1。

提示 3

展开 (2+3Z)⁴；原点矩与中心矩不同。

带我一步一步做

第 1 / 5 步

  1. 令 I=∫exp(−x²/2)dx。I² 化为平面积分，极坐标给2π∫₀∞r exp(−r²/2)dr=2π；I>0，所以 I=√(2π)。

  2. 分部积分并令边界消失得 mₖ=(k−1)mₖ₋₂，m₀=1，故 m₂=1、m₄=3。

  3. 中心四阶矩 E[(X−2)⁴]=3⁴E(Z⁴)=81×3=243。

  4. E(X⁴)=2⁴+6×2²×9+3×9²=475，E(X²)=2²+9=13。

  5. Var(X²)=E(X⁴)−[E(X²)]²=475−169=306。

查看完整解答与检验

  1. 令 I=∫exp(−x²/2)dx。I² 化为平面积分，极坐标给2π∫₀∞r exp(−r²/2)dr=2π；I>0，所以 I=√(2π)。

  2. 分部积分并令边界消失得 mₖ=(k−1)mₖ₋₂，m₀=1，故 m₂=1、m₄=3。

  3. 中心四阶矩 E[(X−2)⁴]=3⁴E(Z⁴)=81×3=243。

  4. E(X⁴)=2⁴+6×2²×9+3×9²=475，E(X²)=2²+9=13。

  5. Var(X²)=E(X⁴)−[E(X²)]²=475−169=306。

答案

归一化积分 √(2π)；标准正态四阶矩3；本例中心四阶矩243、原点四阶矩475、Var(X²)=306。

检验与提醒

写出分部积分时所需的绝对矩可积和尾部边界消失，不能只凭密度对称就跳过存在性。
