SECTION 10.1

非参数bootstrap方法

非参数 bootstrap：把经验分布当作临时总体
10.1Nonparametric bootstrap理解后再记忆

非参数 bootstrap：把经验分布当作临时总体

先用一句话理解

从已观测样本中有放回地重抽样，模拟“再做一次抽样”。

经验分布 Fn(x)=n−1∑iI(Xi≤x) 在每个观测位置放质量 1/n（重复值合并质量）。给定原样本，从 Fn 独立抽取 n 个值得到 bootstrap 样本；重复 B 次，分别计算 Tb*。条件分布中常比较 T*−θ^ 与真实抽样中 θ^−θ。偏差估计为 T¯*−θ^，标准误估计为 bootstrap 统计量的样本标准差。百分位区间取 T* 的两端经验分位数，但并非所有统计量都具有良好覆盖率。

se^boot=1B−1∑b=1B(Tb*−T¯*)2
使用条件

普通逐点重抽样适用于独立同分布抽样及相应规则性条件。相关时间序列通常需要区组等方法；样本极值、边界参数等可能使普通 bootstrap 失效。B 增大只减少模拟误差，不能修复抽样偏差。

方法依据与可核验的推导

以样本均值为可直接核验的例子。给定数据，E*(Xi*)=X¯，Var*(Xi*)=n−1∑(Xi−X¯)2。重抽样独立，所以 E*(X¯*)=X¯ 且 Var*(X¯*)=n−2∑(Xi−X¯)2。这说明 bootstrap 在均值问题中怎样用经验离差代替未知总体方差；一般统计量的一致性需要另外证明，不能由此例一概推出。

做一道简单例题

数据为 (0,2)，抽 2 个并允许重复，四个等可能有序样本产生均值 0,1,1,2，bootstrap 均值为 1、条件方差为 1/2。

容易出错的地方

不放回抽 n 个只是打乱原样本，均值完全不变，不能估计其抽样标准误。

SECTION 10.2

参数bootstrap方法

参数 bootstrap：先拟合模型，再模拟样本
10.2Parametric bootstrap理解后再记忆

参数 bootstrap：先拟合模型，再模拟样本

先用一句话理解

重抽样的对象变为拟合出来的概率模型，而不是经验分布。

假设数据来自参数族 Fθ，先用原样本估计 θ^，每次从 Fθ^ 独立生成 n 个值，并按原流程重新拟合、重新计算统计量。它可用于标准误、偏差、置信区间及复杂估计量的抽样分布近似。与非参数方法相比，它加入分布族假设，能生成未在原样本出现的数值，也更依赖模型正确性。

X1*,…,Xn*∣X~iidFθ^
使用条件

拟合模型应能合理描述数据，样本量与重新拟合流程必须保持对应；固定估计参数用于生成样本，不代表重抽样内不再估计参数。

方法依据与可核验的推导

若 Xi~Poisson(λ)，MLE 为 λ^=X¯。参数 bootstrap 生成独立 Poisson(X¯) 样本，故重估量 λ^*=X¯* 的条件均值为 X¯、条件方差为 X¯/n。真实估计方差为 λ/n；此处以一致估计量替换未知 λ，直接揭示近似机制。这是该模型下的推导，不是任意参数族、任意统计量的万能保证。

做一道简单例题

泊松样本 n=25、样本均值 4 时，bootstrap 估计均值的理论条件标准差为 4/25=0.4；实际有限 B 的模拟值应在其附近波动。

容易出错的地方

只对原数据加任意正态噪声不自动成为合法的参数 bootstrap；噪声模型必须和抽样模型一致。

SECTION 10.3

bootstrap假设检验方法举例

bootstrap 检验：必须在原假设下生成参照分布
10.3Bootstrap hypothesis testing理解后再记忆

bootstrap 检验：必须在原假设下生成参照分布

先用一句话理解

检验问的是“原假设为真时，这么极端的数据多常见”，所以模拟模型必须满足原假设。

检验 H0:μ=μ0 时，可在适当的独立同分布均值模型下先中心化数据为 Zi=Xi−X¯+μ0，再从这些值有放回重抽样。采用学生化统计量 T=(X¯−μ0)/(S/n)，每次重抽样都重新计算 Tb*。双侧比较通常使用绝对值尾部 |Tb*|≥|Tobs|；参数模型检验则需用原假设约束下拟合的参数生成数据。

有限 B 可报告带加一修正的模拟尾部比例 (1+∑I)/(B+1)，避免模拟中零次命中被写成“概率为零”。这是一般 bootstrap 情形的近似 p 值，不自动成为精确水平检验。

p^=1+∑b=1BI(|Tb*|≥|Tobs|)B+1
使用条件

均值中心化方法需要适合均值推断的 iid 样本与有限非零方差；不能把这一变换原封不动用于任意非线性原假设。若重抽样标准差为 0，应诊断数据退化并调整方法，而非静默删去失败样本。

方法依据与可核验的推导

中心化数据的经验均值为 n−1∑(Xi−X¯+μ0)=μ0，所以它满足待检验的均值约束，同时保留样本内部的中心离差。普通未中心化重抽样却以 X¯ 为中心，不能直接充当 H0 的尾部参照。每次重新学生化让统计量以自身精度计量偏差。条件于拟合的零假设模型，各重复独立，尾部命中数近似按二项模拟波动，未修正比例的模拟标准误约为 p(1−p)/B。

做一道简单例题

B=999 时有 39 次不小于观测绝对统计量，则修正比例为 40/1000=0.04。它同时有模型近似误差与 Monte Carlo 误差，不能因三位小数就认为结论精确。

容易出错的地方

把普通重抽样均值落在 0 一侧的比例直接叫“双侧 p 值”，既可能没满足 H0，也可能选错尾部。
