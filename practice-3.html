提示 1

先写清随机变量的取值范围及题设条件。

提示 2

从对应知识卡的定义出发，列出求和、积分或分解式。

提示 3

检查边界，并用总概率为 1 或另一种算法检验。

带我一步一步做

第 1 / 4 步

  1. 补事件为三个变量都至少为 1/4，连续情形等号不影响概率。

  2. 各变量超过 1/4 的概率为 3/4，独立给出 (3/4)3。

  3. 所求为 1−27/64=37/64。

  4. FL(z)=1−(1−z)3 在 (0,1) 上求导，得到 3(1−z)2，区间外密度为 0。

查看完整解答与检验

原创 P3-10第 3.1 节 · 进阶

三角形上均匀取点：边缘、条件与面积

(X,Y) 在三角形 D={0<x<y<1} 上均匀分布。求 fX(x)、fY∣X=x(y)、P(Y>2X)，并判断 X 与 Y 是否独立。

给我一点提示
提示 1

先算三角形面积，得到联合密度。

提示 2

固定 x，允许的 y 从 x 到 1。

提示 3

Y>2X 的区域只存在于 0<x<1/2。

带我一步一步做

第 1 / 4 步

  1. 三角形面积为 1/2，故 f(x,y)=2（在 D 内）。

  2. 固定 0<x<1，截面长 1−x，所以 fX(x)=2(1−x)；区间外为 0。

  3. 条件密度为 fY∣X=x(y)=2/[2(1−x)]=1/(1−x)，支持为 x<y<1。

  4. P(Y>2X)=2∫01/2∫2x1dydx=1/2。条件支持依赖 x，故不独立。

查看完整解答与检验

  1. 三角形面积为 1/2，故 f(x,y)=2（在 D 内）。

  2. 固定 0<x<1，截面长 1−x，所以 fX(x)=2(1−x)；区间外为 0。

  3. 条件密度为 fY∣X=x(y)=2/[2(1−x)]=1/(1−x)，支持为 x<y<1。

  4. P(Y>2X)=2∫01/2∫2x1dydx=1/2。条件支持依赖 x，故不独立。

答案

fX(x)=2(1−x)（0<x<1）；fY∣X=x(y)=1/(1−x)（x<y<1）；P(Y>2X)=1/2；不独立。

检验与提醒

边缘积分 ∫012(1−x)dx=1；对每个有效 x，条件密度在 (x,1) 上积分也是 1。
