原创 P11-01第 11.1 节 · 基础

有效样本量与 R 方差

向量 c(2,4,NA,6) 去除 NA 后，求有效样本量、mean 与 var 应返回的理论值。说明为什么不能将 NA 自动换成 0。

给我一点提示
提示 1

NA 不代表观测值零。

提示 2

三个有效值均值是 4。

提示 3

R var 使用 n−1。

带我一步一步做

第 1 / 4 步

  1. 有效样本量 n=3。

  2. 均值为 (2+4+6)/3=4。

  3. 离差平方和为 4+0+4=8，样本方差 8/(3−1)=4。

  4. 将缺失替成零相当于添加一个并未实际观察到的数值，改变估计目标及均值方差。

查看完整解答与检验

  1. 有效样本量 n=3。

  2. 均值为 (2+4+6)/3=4。

  3. 离差平方和为 4+0+4=8，样本方差 8/(3−1)=4。

  4. 将缺失替成零相当于添加一个并未实际观察到的数值，改变估计目标及均值方差。

答案

n=3，mean=4，var=4；NA 不等于 0。

检验与提醒

方差的单位是原数据单位的平方。

原创 P11-02第 11.2 节 · 基础

围栏不是须端

给定下、上铰链为 10、14，数据范围内最大的不越界观测为 19，另有观测 25。求上围栏、上须端，并判断 25 是否被标记。

给我一点提示
提示 1

箱宽为 4。

提示 2

上围栏是上铰链加 1.5 倍箱宽。

提示 3

须端要落在实际观测上。

带我一步一步做

第 1 / 4 步

  1. 箱宽为 14−10=4。

  2. 上围栏为 14+1.5×4=20。

  3. 最大的不越界观测是 19，因此上须端为 19。

  4. 25>20，被标为潜在离群点。

查看完整解答与检验

  1. 箱宽为 14−10=4。

  2. 上围栏为 14+1.5×4=20。

  3. 最大的不越界观测是 19，因此上须端为 19。

  4. 25>20，被标为潜在离群点。

答案

上围栏 20，上须端 19，25 被标记。

检验与提醒

标记不等于应删除。

原创 P11-03第 11.3 节 · 进阶

配对 t 统计量

5 对观测的差值为 (1,−1,1,1,2)。求均值、样本方差与检验差值总体均值为 0 的 t 统计量和自由度。

给我一点提示
提示 1

先对差值求和。

提示 2

离差平方和为 4.8。

提示 3

分母是差值标准差除以根号 5。

带我一步一步做

第 1 / 4 步

  1. D¯=4/5=0.8。

  2. 离差平方和 4.8，SD2=4.8/4=1.2。

  3. 标准误为 1.2/5=0.24。

  4. t=0.8/0.24≈1.633，正态差值模型下自由度为 4。

查看完整解答与检验

  1. D¯=4/5=0.8。

  2. 离差平方和 4.8，SD2=4.8/4=1.2。

  3. 标准误为 1.2/5=0.24。

  4. t=0.8/0.24≈1.633，正态差值模型下自由度为 4。

答案

D¯=0.8,SD2=1.2,t≈1.633,df=4。

检验与提醒

自由度按配对数减一，而不是两组总观测数减二。

原创 P11-04第 11.4 节 · 进阶

数值编码还是因素

三个处理水平标为 1、2、3，每组 5 个观测。含截距时，y~A 将 A 当数值与将 A 当 factor，分别有几个参数和残差自由度？

给我一点提示
提示 1

总样本量 15。

提示 2

数值模型只有截距和斜率。

提示 3

三水平因素需要两个对比列。

带我一步一步做

第 1 / 4 步

  1. 数值 A 模型有截距和一个斜率，共 2 个参数。

  2. 因此其残差自由度为 15−2=13。

  3. factor(A) 模型有截距加两个对比，共 3 个参数。

  4. 因此其残差自由度为 15−3=12；它允许三个均值不共线。

查看完整解答与检验

  1. 数值 A 模型有截距和一个斜率，共 2 个参数。

  2. 因此其残差自由度为 15−2=13。

  3. factor(A) 模型有截距加两个对比，共 3 个参数。

  4. 因此其残差自由度为 15−3=12；它允许三个均值不共线。

答案

数值模型：2 参数、13 残差自由度；因素模型：3 参数、12 残差自由度。

检验与提醒

因素模型包含所有线性趋势，也允许非线性组均值差异。

原创 P11-05第 11.5 节 · 基础

选择正确的 predict 目标

要回答“同条件下一批产品的平均重量”与“下一件产品的重量可能落在哪”，应分别选择哪种区间？为什么第二种更宽？

给我一点提示
提示 1

区分条件均值与单个随机结果。

提示 2

两者都含参数估计误差。

提示 3

单个新结果还含新噪声。

带我一步一步做

第 1 / 4 步

  1. 平均重量目标是条件均值，选择 interval="confidence"。

  2. 下一件产品目标是新观测，选择 interval="prediction"。

  3. 两类区间都有回归系数估计带来的不确定性。

  4. 预测区间额外包含新个体误差的方差 σ²，因此在相同覆盖率与模型条件下更宽。

查看完整解答与检验

  1. 平均重量目标是条件均值，选择 interval="confidence"。

  2. 下一件产品目标是新观测，选择 interval="prediction"。

  3. 两类区间都有回归系数估计带来的不确定性。

  4. 预测区间额外包含新个体误差的方差 σ²，因此在相同覆盖率与模型条件下更宽。

答案

分别使用 confidence 与 prediction；后者增加新个体噪声。

检验与提醒

这里不是未来有限批次样本均值的预测区间；那个目标还需给出批次数。

原创 P11-06第 11.6 节 · 进阶

发现重抽样代码中的零标准误

数据 (1,3,5,7)，代码每次 sample.int(4,4,replace=FALSE) 后计算均值，得到 sd(tb)=0。说明原因、修正方式，并给出正确 bootstrap 标准差的理论值。

给我一点提示
提示 1

不放回抽满样本只是排列。

提示 2

bootstrap 默认应允许观测重复出现。

提示 3

均值 4，离差平方和 20。

带我一步一步做

第 1 / 4 步

  1. 每次只是同四个数重新排序，均值始终是 4。

  2. 将 replace 改为 TRUE，使每次抽样独立有放回。

  3. 条件方差 20/42=1.25。

  4. 条件标准差为 1.25≈1.118，有限次数模拟只应接近它。

查看完整解答与检验

  1. 每次只是同四个数重新排序，均值始终是 4。

  2. 将 replace 改为 TRUE，使每次抽样独立有放回。

  3. 条件方差 20/42=1.25。

  4. 条件标准差为 1.25≈1.118，有限次数模拟只应接近它。

答案

需有放回抽样；理论标准差 1.25≈1.118。

检验与提醒

模拟标准差不是原样本标准差，二者对应不同随机量。
