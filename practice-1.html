原创 P1-01第 1.1 节 · 基础

同一试验，两种记录

连续独立抛两次公平硬币。分别列出“记录每次正反面”与“记录正面次数”的可能结果，并给出各自概率。

给我一点提示
提示 1

先区分顺序。

提示 2

列出 HH、HT、TH、TT。

提示 3

正面次数为 1 对应两个底层结果。

带我一步一步做

第 1 / 4 步

  1. 记 H 为正面、T 为反面，样本空间为 {HH,HT,TH,TT}。

  2. 独立且公平，所以每个序列概率为 1/4。

  3. 令 X 为正面次数，HH 对应 2，HT、TH 对应 1，TT 对应 0。

  4. 合并相同取值，得到次数 0、1、2 的概率为 1/4,1/2,1/4。

查看完整解答与检验

  1. 记 H 为正面、T 为反面，样本空间为 {HH,HT,TH,TT}。

  2. 独立且公平，所以每个序列概率为 1/4。

  3. 令 X 为正面次数，HH 对应 2，HT、TH 对应 1，TT 对应 0。

  4. 合并相同取值，得到次数 0、1、2 的概率为 1/4,1/2,1/4。

答案

序列各为 1/4；次数分布为 (1/4,1/2,1/4)。

检验与提醒

概率和为 1；中间取值的概率是两端的两倍。

原创 P1-02第 1.2 节 · 基础

三个事件，恰好两个

用 A、B、C 表示三个部件故障。用事件运算表示“恰好两个部件故障”和“至多一个部件故障”。

给我一点提示
提示 1

恰好两个要列出哪两个。

提示 2

AB 还包含 C 也发生的情况。

提示 3

至多一个是至少两个的补。

带我一步一步做

第 1 / 4 步

  1. 只有 A、B 故障写为 ABC―。

  2. 另两种情况分别为 AB―C、A―BC。

  3. 恰好两个为三种情况的并，它们两两互斥。

  4. 至少两个为 AB∪AC∪BC，取补得到至多一个。

查看完整解答与检验

  1. 只有 A、B 故障写为 ABC―。

  2. 另两种情况分别为 AB―C、A―BC。

  3. 恰好两个为三种情况的并，它们两两互斥。

  4. 至少两个为 AB∪AC∪BC，取补得到至多一个。

答案

恰好两个：ABC―∪AB―C∪A―BC；至多一个：AB∪AC∪BC―。

检验与提醒

代入三个都故障的样本点，两种事件都不应包含它。

原创 P1-03第 1.2 节 · 基础

样本空间会不会少一半

掷两枚可区分的公平骰子，求点数之和等于 5 的概率。

给我一点提示
提示 1

使用有序对。

提示 2

总共有 62 个结果。

提示 3

找出和为 5 的四个有序对。

带我一步一步做

第 1 / 4 步

  1. 样本空间为 (i,j)，1≤i,j≤6。

  2. 共有 36 个等可能结果。

  3. 有利结果为 (1,4)、(2,3)、(3,2)、(4,1)。

  4. 概率为 4/36=1/9。

查看完整解答与检验

  1. 样本空间为 (i,j)，1≤i,j≤6。

  2. 共有 36 个等可能结果。

  3. 有利结果为 (1,4)、(2,3)、(3,2)、(4,1)。

  4. 概率为 4/36=1/9。

答案

1/9。

检验与提醒

如果把 (1,4) 与 (4,1) 合并，却仍用 36 作分母，就会漏算。

原创 P1-04第 1.3 节 · 基础

至少一个与恰好一个

已知 P(A)=0.55，P(B)=0.4，P(AB)=0.2。求至少一个发生、恰好一个发生及都不发生的概率。

给我一点提示
提示 1

至少一个用并。

提示 2

恰好一个需去掉交集。

提示 3

都不发生取并的补。

带我一步一步做

第 1 / 4 步

  1. 加法公式给出 P(A∪B)=0.55+0.4−0.2=0.75。

  2. 并中包含二者都发生，再减 0.2 得恰好一个为 0.55。

  3. 都不发生为 1−0.75=0.25。

  4. 三种互斥情形“都不、恰一、都发生”的和为 0.25+0.55+0.2=1。

查看完整解答与检验

  1. 加法公式给出 P(A∪B)=0.55+0.4−0.2=0.75。

  2. 并中包含二者都发生，再减 0.2 得恰好一个为 0.55。

  3. 都不发生为 1−0.75=0.25。

  4. 三种互斥情形“都不、恰一、都发生”的和为 0.25+0.55+0.2=1。

答案

0.75, 0.55, 0.25。

检验与提醒

三种互斥情形总概率为 1。

原创 P1-05第 1.3 节 · 进阶

交集概率的可能范围

只知道 P(A)=0.7,P(B)=0.6，求 P(AB) 的可能范围。

给我一点提示
提示 1

交集不大于任一事件。

提示 2

并的概率不能超过 1。

提示 3

将加法公式变为不等式。

第 1 / 4 步

  1. 由包含关系，P(AB)≤min(0.7,0.6)=0.6。

  2. 由 P(A∪B)=1.3−P(AB)≤1，得 P(AB)≥0.3。

  3. 两个条件合并为 0.3≤P(AB)≤0.6。

  1. 由包含关系，P(AB)≤min(0.7,0.6)=0.6。

  2. 由 P(A∪B)=1.3−P(AB)≤1，得 P(AB)≥0.3。

  3. 两个条件合并为 0.3≤P(AB)≤0.6。

  4. 两个端点都可由适当的重叠情况实现。

答案

[0.3,0.6]。

检验与提醒

不要擅自假定独立而只给出 0.42。

原创 P1-07第 1.4 节 · 进阶

生日重复的补事件

假设每个人的生日独立、均匀分布在 365 天内，不计闰年。求 4 人中至少两人同生日的概率（给出精确表达式）。

提示 1

直接分类很繁琐。

提示 2

补事件是四人生日全不同。

提示 3

依次安排，可用天数逐次减少。

带我一步一步做

第 1 / 4 步

  1. 总的生日组合数为 3654。

  2. 四人全不同时，依次有 365、364、363、362 个选择。

  3. 全不同概率为 365·364·363·362/3654。

  4. 用 1 减去上式得到至少两人相同的概率。

查看完整解答与检验

  1. 总的生日组合数为 3654。

  2. 四人全不同时，依次有 365、364、363、362 个选择。

  3. 全不同概率为 365·364·363·362/3654。

  4. 用 1 减去上式得到至少两人相同的概率。

答案

1−364·363·3623653。

检验与提醒

“至少两人同生日”包含三人或四人同生日，无需再额外相加。

原创 P1-08第 1.4 节 · 基础

相约见面

两人独立、均匀地在 0 到 60 分钟之间到达，各自最多等待 20 分钟。求能见面的概率。

给我一点提示
提示 1

画边长 60 的正方形。

提示 2

见面条件是 |x−y|≤20。

提示 3

减去两个直角三角形。

带我一步一步做

第 1 / 4 步

  1. 用 x、y 表示到达时刻，联合模型为正方形上的均匀分布。

  2. 不见面区域是 y>x+20 和 x>y+20。

  3. 每个三角形直角边为 40，总面积为 402。

  4. 见面概率 1−402/602=5/9。

查看完整解答与检验

  1. 用 x、y 表示到达时刻，联合模型为正方形上的均匀分布。

  2. 不见面区域是 y>x+20 和 x>y+20。

  3. 每个三角形直角边为 40，总面积为 402。

  4. 见面概率 1−402/602=5/9。

答案

5/9。

检验与提醒

等待时间为 0 时概率应为 0，为 60 时应为 1；通式 1−(1−t/60)2 满足这两点。

原创 P1-09第 1.5 节 · 基础

已知至少一个是正面

独立抛两次公平硬币，已知至少一次为正面，求两次都是正面的概率。

给我一点提示
提示 1

条件排除了 TT。

提示 2

条件样本空间有三个等可能结果。

提示 3

第 1 / 4 步

  1. 记 A 为两次都是正面，B 为至少一次正面，A⊂B。

  2. P(A)=1/4，P(B)=3/4。

  3. P(A∣B)=P(A)/P(B)。

  4. 得到 (1/4)/(3/4)=1/3。

查看完整解答与检验

  1. 记 A 为两次都是正面，B 为至少一次正面，A⊂B。

  2. P(A)=1/4，P(B)=3/4。

  3. P(A∣B)=P(A)/P(B)。

  4. 得到 (1/4)/(3/4)=1/3。

答案

1/3。

检验与提醒

与“已知第一次是正面”不同，后者答案为 1/2。

三条生产线

三条生产线产量占比为 0.5、0.3、0.2，次品率为 0.01、0.02、0.04。随机抽一件，求次品概率。

提示 2

三条路径相加。

  3. 其余贡献分别为 0.006 与 0.008。

0.019，即 1.9%。

原创 P1-13第 1.6 节 · 基础

是否独立，算一次就知道

掷一枚公平骰子，A 为偶数，B 为不大于 4。判断 A 与 B 是否独立，是否互斥。

给我一点提示
提示 1

列出两个集合。

提示 2

交集是 2 与 4。

提示 3

比较交集概率与概率乘积。

带我一步一步做

第 1 / 4 步

  1. A={2,4,6},B={1,2,3,4}。

  2. P(A)=1/2,P(B)=2/3。

  3. P(AB)=2/6=1/3=P(A)P(B)，所以独立。

  4. 交集非空，因此不互斥。

查看完整解答与检验

  1. A={2,4,6},B={1,2,3,4}。

  2. P(A)=1/2,P(B)=2/3。

  3. P(AB)=2/6=1/3=P(A)P(B)，所以独立。

  4. 交集非空，因此不互斥。

答案

独立，但不互斥。

检验与提醒

独立与互斥并不是同义词，也不是简单的反义词。

原创 P1-14第 1.6 节 · 进阶

两两独立不够

独立抛两次公平硬币。A 为第一次正面，B 为第二次正面，C 为两次结果相同。证明两两独立但不相互独立。

给我一点提示
提示 1

每个事件概率都是 1/2。

提示 2

任意两个交集都只有 HH。

提示 3

三者交集也只有 HH。

带我一步一步做

第 1 / 4 步

  1. A={HH,HT},B={HH,TH},C={HH,TT}。

  2. 每个事件概率为 1/2。

  3. 任意两个交集概率都为 1/4=(1/2)2，故两两独立。

  4. 三者交集概率为 1/4，不等于 (1/2)3=1/8，故不相互独立。

查看完整解答与检验

  1. A={HH,HT},B={HH,TH},C={HH,TT}。

  2. 每个事件概率为 1/2。

  3. 任意两个交集概率都为 1/4=(1/2)2，故两两独立。

  4. 三者交集概率为 1/4，不等于 (1/2)3=1/8，故不相互独立。

答案

两两独立；不相互独立。

检验与提醒

检验三个事件相互独立必须检查三重交，不能只检查两两交。

原创 P1-15第 1.6 节 · 基础

至少成功一次需要几次

每次独立试验成功率 0.2。至少做多少次，才能使至少成功一次的概率不低于 0.9？

给我一点提示
提示 1

零次成功的概率为 0.8n。

提示 2

要求 0.8n≤0.1。

提示 3

除以负的对数时不等号反向。

带我一步一步做

第 1 / 4 步

  1. 写出 1−0.8n≥0.9。

  2. 化为 0.8n≤0.1。

  3. 取对数得到 n≥ln(0.1)/ln(0.8)≈10.319。

  4. n 是整数，向上取整得 11。

查看完整解答与检验

  1. 写出 1−0.8n≥0.9。

  2. 化为 0.8n≤0.1。

  3. 取对数得到 n≥ln(0.1)/ln(0.8)≈10.319。

  4. n 是整数，向上取整得 11。

答案

至少 11 次。
