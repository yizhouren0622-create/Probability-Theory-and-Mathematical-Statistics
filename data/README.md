# 内容维护

`course.json` 按章、节、知识卡组织。`exercises.json` 是原创训练题，编号 P 开头，不对应教材题号。`exams.json` 使用独立题目。

新增章节时追加章节对象，无需修改页面模板。知识卡必须填写白话解释、数学表述、公式、条件、推导、例题、易错点；练习必须填写三级提示、分步解答、答案和检验。修改后运行 `python build.py` 与 `python validate.py`，一并提交生成页面。

source-audit.json 仅记录实际读取的指定教材页码和核对主题。目录核实、外部讲义交叉检查和指定正文核对分别记录，不能互相替代。新增记录必须说明版本、公开来源、页码、阅读范围与尚未验证的部分。

模拟卷索引由 build.py 自动加入 examId、examMinutes，页面据此校验可恢复的计时数据。新增试卷使用新 id 和题号，保留已发布试卷的 id、题号和分值。

r-verification.json 记录第十一章六段代码的实际执行环境、代码哈希和数值输出。修改 R 代码后必须重跑 scripts/check-r-examples.py；数值运行通过不代表图像外观、注释中的包调用或指定教材正文已核对。
