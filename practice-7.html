原创 P7-01第 7.1 节 · 巩固

均匀分布的矩估计

假设样本来自 U(0,θ)，观测为 2、4、6、8，求 θ 的一阶矩估计。

给我一点提示
提示 1

总体均值为 θ/2。

提示 2

计算样本均值。

提示 3

把总体均值替换成样本均值。

带我一步一步做

第 1 / 4 步

  1. E(X)=θ/2。

  2. x¯=(2+4+6+8)/4=5。

  3. 矩方程为 θ/2=5。

  4. 解得 θ^=10，大于最大观测 8，支持约束满足。

查看完整解答与检验

  1. E(X)=θ/2。

  2. x¯=(2+4+6+8)/4=5。

  3. 矩方程为 θ/2=5。

  4. 解得 θ^=10，大于最大观测 8，支持约束满足。

答案

θ^=10。

检验与提醒

这是矩估计，不是同一模型的最大似然估计 8。

原创 P7-02第 7.1 节 · 巩固

边界上的最大似然

假设样本来自 U(0,θ)，观测为 2、4、6、8，求最大似然估计并说明为何不能令导数等于 0。

给我一点提示
提示 1

先写 θ 必须不小于最大观测。

提示 2

可行区间内似然与 θ⁻⁴ 成正比。

提示 3

单调函数最大值在边界。

带我一步一步做

第 1 / 4 步

  1. 若 θ<8，至少一个观测不在支持集内，似然为 0。

  2. θ≥8 时，L(θ)=θ−4。

  3. 它随 θ 严格递减，内部没有驻点。

  4. 可行左端点 θ=8 给出最大值。

查看完整解答与检验

  1. 若 θ<8，至少一个观测不在支持集内，似然为 0。

  2. θ≥8 时，L(θ)=θ−4。

  3. 它随 θ 严格递减，内部没有驻点。

  4. 可行左端点 θ=8 给出最大值。

答案

θ^=8。

检验与提醒

边界估计与矩估计 10 不同，二者解决的优化问题不同。

原创 P7-03第 7.2 节 · 巩固

累计试验时间

6 个独立指数寿命个体试验到 T=5，失效时间为 1、2、4，其余仍存活。求率参数 λ 的最大似然估计。

给我一点提示
提示 1

未失效 3 个，每个贡献 5 单位时间。

提示 2

总时长是失效时长加未失效时长。

提示 3

失效数除以总时长。

带我一步一步做

第 1 / 4 步

  1. 失效数 r=3，存活数 3。

  2. W=1+2+4+3×5=22。

  3. ℓ(λ)=3logλ−22λ+C。

  4. 解 3/λ−22=0，得 λ^=3/22，二阶导数负。

查看完整解答与检验

  1. 失效数 r=3，存活数 3。

  2. W=1+2+4+3×5=22。

  3. ℓ(λ)=3logλ−22λ+C。

  4. 解 3/λ−22=0，得 λ^=3/22，二阶导数负。

答案

λ^=3/22，均值参数估计为 22/3。

检验与提醒

量纲：率是“每单位时间”，总寿命估计必须纳入未失效个体。

原创 P7-04第 7.3 节 · 巩固

无偏不等于最小误差

估计 θ 的两个估计量 A、B 满足 E(A)=θ、D(A)=4，E(B)=θ+1、D(B)=2。比较其 MSE。

给我一点提示
提示 1

A 的偏差为 0。

提示 2

B 的偏差为 1，要平方。

提示 3

比较 4 和 2+1。

带我一步一步做

第 1 / 4 步

  1. A 无偏，MSE 为 4+02=4。

  2. B 有偏差 1。

  3. B 的 MSE 为 2+12=3。

  4. 按平方误差标准，B 优于 A，尽管 B 有偏。

查看完整解答与检验

  1. A 无偏，MSE 为 4+02=4。

  2. B 有偏差 1。

  3. B 的 MSE 为 2+12=3。

  4. 按平方误差标准，B 优于 A，尽管 B 有偏。

答案

MSE(A)=4,MSE(B)=3，B 更小。

检验与提醒

有偏与否不能代替完整的风险比较。

原创 P7-05第 7.4 节 · 巩固

由正态枢轴求区间

正态总体标准差已知为 3，n=36，样本均值 12。用 z₀.₉₇₅=1.96 求均值的 95% 置信区间。

给我一点提示
提示 1

标准误为 3/√36。

提示 2

半宽为 1.96 乘标准误。

提示 3

中心为样本均值。

带我一步一步做

第 1 / 4 步

  1. 标准误为 3/6=0.5。

  2. 半宽为 1.96imes0.5=0.98。

  3. 下限 12−0.98=11.02。

  4. 上限 12+0.98=12.98。

查看完整解答与检验

  1. 标准误为 3/6=0.5。

  2. 半宽为 1.96imes0.5=0.98。

  3. 下限 12−0.98=11.02。

  4. 上限 12+0.98=12.98。

答案

[11.02,12.98]。

检验与提醒

区间中心为 12，总宽度为 1.96。

原创 P7-06第 7.5 节 · 巩固

卡方区间分位数的方向

正态样本 n=5，s²=2；已知 χ²(4) 的下侧 0.025、0.975 分位数分别为 0.484、11.143。求 σ² 的 95% 置信区间。

给我一点提示
提示 1

分子为 (n−1)s²。

提示 2

下限除以较大的分位数。

提示 3

上限除以较小分位数。

带我一步一步做

第 1 / 4 步

  1. 分子为 4×2=8。

  2. 卡方概率事件为 0.484≤8/σ2≤11.143。

  3. 反演得 8/11.143≤σ2≤8/0.484。

  4. 数值约为 [0.718,16.529]。

查看完整解答与检验

  1. 分子为 4×2=8。

  2. 卡方概率事件为 0.484≤8/σ2≤11.143。

  3. 反演得 8/11.143≤σ2≤8/0.484。

  4. 数值约为 [0.718,16.529]。

答案

约 [0.718,16.529]。

检验与提醒

方差非负且区间很不对称，反映小样本的较大不确定性。

  3. 半宽约为 1.96×0.02165=0.04244。

原创 P7-09第 7.8 节 · 巩固

Beta–伯努利更新

成功概率 p 的先验为 Beta(2,3)，独立试验 5 次成功 4 次。求后验及平方损失下的估计。

给我一点提示
提示 1

成功数加到第一个参数。

提示 2

失败数加到第二个参数。

提示 3

Beta(a,b) 均值为 a/(a+b)。

带我一步一步做

第 1 / 4 步

  1. 成功数 4，失败数 1。

  2. 后验第一参数为 2+4=6。

  3. 后验第二参数为 3+1=4。

  4. 后验为 Beta(6,4)，贝叶斯估计为 6/(6+4)=0.6。

  2. 后验第一参数为 2+4=6。

  3. 后验第二参数为 3+1=4。

  4. 后验为 Beta(6,4)，贝叶斯估计为 6/(6+4)=0.6。

答案

Beta(6,4)，估计为 0.6。

检验与提醒

原创 P7-10第 7.3 节 · 进阶

两种正态方差估计的平方损失

正态独立样本量 n=5，真方差 σ2=4。比较 S2=Q/4 与 T=Q/5 对 σ2 的偏差、方差和 MSE；说明结论的适用范围。

给我一点提示
提示 1

先用 Q/σ2~χ42 求 E(Q) 和 D(Q)。

提示 2

用缩放关系分别求 S2、T 的均值与方差。

提示 3

偏差平方加方差，切勿只比较方差。

带我一步一步做

第 1 / 4 步

  1. E(Q)=4σ2=16，D(Q)=8σ4=128。

  2. S2=Q/4 无偏，D(S2)=128/16=8，故 MSE 为 8。

  3. E(T)=16/5=3.2，偏差 −0.8；D(T)=128/25=5.12。

  4. MSE(T)=5.12+(−0.8)2=5.76<8。此比较依赖正态模型和平方损失。

查看完整解答与检验

  1. E(Q)=4σ2=16，D(Q)=8σ4=128。

  2. S2=Q/4 无偏，D(S2)=128/16=8，故 MSE 为 8。

  3. E(T)=16/5=3.2，偏差 −0.8；D(T)=128/25=5.12。

  4. MSE(T)=5.12+(−0.8)2=5.76<8。此比较依赖正态模型和平方损失。

答案

S2：偏差 0、方差/MSE 8；T：偏差 −0.8、方差 5.12、MSE 5.76。

检验与提醒

不能把这一次参数设置下的 MSE 比较概括成所有模型或所有损失函数的排序。

原创 P7-11第 7.3 节 · 拓展

伯努利参数的信息下界

独立观察 n=20 个 Bernoulli(p) 变量，p=0.3。求估计 p 的正则无偏估计量的 Cramér–Rao 方差下界，并核对 X¯ 是否达到。

给我一点提示
提示 1

写出 R=∑Xi 的对数似然并求导。

提示 2

利用 D(R)=np(1−p) 求得分的方差。

提示 3

估计目标 g(p)=p，所以 g′(p)=1。

带我一步一步做

第 1 / 4 步

  1. ℓ(p)=Rlogp+(20−R)log(1−p)，故 U=(R−20p)/[p(1−p)]。

  2. I20=D(U)=20/[p(1−p)]；代 p=.3 得 20/.21≈95.2381。

  3. 因 g′(p)=1，方差下界为 1/I20=.21/20=.0105。

  4. E(X¯)=p，D(X¯)=p(1−p)/20=.0105，正好达到该下界。

查看完整解答与检验

  1. ℓ(p)=Rlogp+(20−R)log(1−p)，故 U=(R−20p)/[p(1−p)]。

  2. I20=D(U)=20/[p(1−p)]；代 p=.3 得 20/.21≈95.2381。

  3. 因 g′(p)=1，方差下界为 1/I20=.21/20=.0105。

  4. E(X¯)=p，D(X¯)=p(1−p)/20=.0105，正好达到该下界。

答案

I20≈95.2381，下界 0.0105；X¯ 无偏且方差 0.0105，达到下界。

检验与提醒

p=.3 是内点，伯努利支持集 {0,1} 与 p 无关；不能把此正则证明直接用于支持随参数变化的均匀分布。
