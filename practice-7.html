给我一点提示

原创 P7-10第 7.3 节 · 进阶

两种正态方差估计的平方损失

正态独立样本量 n=5，真方差 σ2=4。比较 S2=Q/4 与 T=Q/5 对 σ2 的偏差、方差和 MSE；说明结论的适用范围。

给我一点提示
提示 1

先用 Q/σ2~χ42 求 E(Q) 和 D(Q)。

提示 2

用缩放关系分别求 S2、T 的均值与方差。

提示 3

偏差平方加方差，切勿只比较方差。

带我一步一步做

第 1 / 4 步

  1. E(Q)=4σ2=16，D(Q)=8σ4=128。

  2. S2=Q/4 无偏，D(S2)=128/16=8，故 MSE 为 8。

  3. E(T)=16/5=3.2，偏差 −0.8；D(T)=128/25=5.12。

  4. MSE(T)=5.12+(−0.8)2=5.76<8。此比较依赖正态模型和平方损失。

查看完整解答与检验

  1. E(Q)=4σ2=16，D(Q)=8σ4=128。

  2. S2=Q/4 无偏，D(S2)=128/16=8，故 MSE 为 8。

  3. E(T)=16/5=3.2，偏差 −0.8；D(T)=128/25=5.12。

S2：偏差 0、方差/MSE 8；T：偏差 −0.8、方差 5.12、MSE 5.76。

原创 P7-11第 7.3 节 · 拓展

伯努利参数的信息下界

独立观察 n=20 个 Bernoulli(p) 变量，p=0.3。求估计 p 的正则无偏估计量的 Cramér–Rao 方差下界，并核对 X¯ 是否达到。

给我一点提示
提示 1

写出 R=∑Xi 的对数似然并求导。

提示 2

利用 D(R)=np(1−p) 求得分的方差。

提示 3

估计目标 g(p)=p，所以 g′(p)=1。

带我一步一步做

第 1 / 4 步

  1. ℓ(p)=Rlogp+(20−R)log(1−p)，故 U=(R−20p)/[p(1−p)]。

  2. I20=D(U)=20/[p(1−p)]；代 p=.3 得 20/.21≈95.2381。

  3. 因 g′(p)=1，方差下界为 1/I20=.21/20=.0105。

  4. E(X¯)=p，D(X¯)=p(1−p)/20=.0105，正好达到该下界。

查看完整解答与检验

  1. ℓ(p)=Rlogp+(20−R)log(1−p)，故 U=(R−20p)/[p(1−p)]。

  2. I20=D(U)=20/[p(1−p)]；代 p=.3 得 20/.21≈95.2381。

  3. 因 g′(p)=1，方差下界为 1/I20=.21/20=.0105。

  4. E(X¯)=p，D(X¯)=p(1−p)/20=.0105，正好达到该下界。

答案

I20≈95.2381，下界 0.0105；X¯ 无偏且方差 0.0105，达到下界。

检验与提醒

p=.3 是内点，伯努利支持集 {0,1} 与 p 无关；不能把此正则证明直接用于支持随参数变化的均匀分布。

两种方差分母与一个不存在的最大点

正态样本观测为 (2,4,6,8)，均值和方差均未知。求两个参数的 MLE 与无偏样本方差；若观测变为 (5,5,5,5)，在 σ²>0 的参数空间内是否仍存在 MLE？

提示 2

提示 3

Q=0 时检查方差趋于零的似然。

第 1 / 5 步

  1. x¯=5，Q=9+1+1+9=20。

  2. 均值 MLE 为 5，方差 MLE 为 Q/n=5。

  3. 无偏样本方差为 Q/(n−1)=20/3，不等于方差 MLE。

  4. 全为 5 时 Q=0，令 μ=5，则 L∝(σ2)−2。

  5. 当 σ²↓0，似然无界上升，所以在 σ²>0 内无最大点；σ²=0 不在所指定参数空间中。

原创 P7-13第 7.8 节 · 巩固

同一个后验，均值与 MAP 为何不同

伯努利成功概率 p 的先验为 Beta(2,3)。独立试验 5 次成功 4 次，求归一化后验密度、后验均值、后验方差和 MAP，并与 MLE 比较。

给我一点提示
提示 1

先把成功次数、失败次数分别加到两个形状参数。

提示 2

Beta(6,4) 的归一化常数可以用阶乘计算。

提示 3

均值用 a/(a+b)，内点众数用 (a−1)/(a+b−2)。

带我一步一步做

第 1 / 5 步

  1. 后验为 Beta(2+4,3+1)=Beta(6,4)。

  2. B(6,4)=5!3!/9!=1/504，故后验密度为 504p5(1−p)3（0<p<1）。

  3. 后验均值为 6/10=3/5，是平方损失下的贝叶斯估计。

  4. 后验方差为 6·4/(102·11)=6/275。

  5. 两参数均大于 1，MAP 为 (6−1)/(6+4−2)=5/8；MLE 为 4/5。三者目标不同。

查看完整解答与检验

  1. 后验为 Beta(2+4,3+1)=Beta(6,4)。

  2. B(6,4)=5!3!/9!=1/504，故后验密度为 504p5(1−p)3（0<p<1）。

  3. 后验均值为 6/10=3/5，是平方损失下的贝叶斯估计。

  4. 后验方差为 6·4/(102·11)=6/275。

  5. 两参数均大于 1，MAP 为 (6−1)/(6+4−2)=5/8；MLE 为 4/5。三者目标不同。

答案

密度 504p5(1−p)3（0<p<1），均值 3/5，方差 6/275，MAP=5/8，MLE=4/5。

检验与提醒

后验密度积分应为 1；后验均值 0.6 与 MAP 0.625 不要求相等，也不要求等于样本比例 0.8。

原创 P7-14第 7.8 节 · 巩固

参数可信区间与下一次观测的预测分布

求完后验方差，再计算加权均值。

预测分布还要加入新观测自身的噪声方差 9。

带我一步一步做
