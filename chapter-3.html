3.1Joint distribution理解后再记忆

二维随机变量与联合分布函数

先用一句话理解

一次试验可以同时记录两个数；联合分布描述这两个数如何一起变化。

随机向量 (X,Y) 的两个分量都是同一概率空间上的随机变量。联合分布函数 F(x,y)=P(X≤x,Y≤y) 对每个变量单调不减、右连续，任一坐标趋于负无穷时极限为 0，两坐标同时趋于正无穷时极限为 1。还必须满足矩形增量非负；仅分别单调并不足够。 概率取值还满足 0≤F(x,y)≤1。

P(a<X≤b,c<Y≤d)=F(b,d)−F(a,d)−F(b,c)+F(a,c)
使用条件

a<b,c<d；分布函数包括右端点，不自动排除边界上的概率质量。

展开性质证明 / 推导过程

把事件 {X≤b,Y≤d} 中 X≤a 和 Y≤c 的两块去掉，再把被重复减去的左下交集加回，得到矩形增量公式。该增量是事件概率，所以非负。右连续性由概率对递减事件列的连续性得到；其余极限也由事件列连续性得到。

做一道简单例题

独立公平硬币的两个正面指示变量满足 F(0,0)=1/4,F(0,1)=F(1,0)=1/2,F(1,1)=1。

容易出错的地方

联合分布不是把两个一维分布并排写出；它还包含两变量的依赖关系。

3.1Joint PMF and PDF理解后再记忆

联合分布律与联合密度

先用一句话理解

离散情形按格点相加，连续情形按区域积分。

离散联合分布律 pij=P(X=xi,Y=yj) 非负且总和为 1。连续型随机向量存在非负可积函数 f(x,y)，使任意可测区域的概率等于该区域上的密度二重积分；全平面积分为 1。并非每个随机向量都有二维密度，例如 Y=X 的分布可能集中在一条直线上。

P((X,Y)∈D)=∬Df(x,y)dxdy,F(x,y)=∫−∞x∫−∞yf(u,v)dvdu
使用条件

密度表示要求联合分布对二维面积绝对连续；积分时必须先确定真实支撑区域。

展开性质证明 / 推导过程

全平面事件必然发生，故密度归一化。非负性使任意区域的积分非负；不交区域的可列可加性由积分的可列可加性给出。因此非负、积分为 1 的函数可以定义概率分布。在密度连续的点，可由微积分基本定理恢复 f=∂2F/(∂x∂y)。

做一道简单例题

三角形 0<x<y<1 上取常数密度 c，面积为 1/2，所以 c=2。

容易出错的地方

支撑集是三角形时，不能直接在整个单位正方形积分。

3.1Uniform distribution on a planar region理解后再记忆

二维均匀分布：区域面积与截面法

先用一句话理解

点在一个平面区域内“均匀落下”时，面积决定概率；固定横坐标后，竖直截面的长度决定条件分布。

二维均匀分布：设平面可测区域 D 的面积 A 有限且为正，(X,Y) 在 D 上的联合密度为常数 1/A，在外为 0。因此任意可测子区域 B 的概率为 Area(B∩D)/A。记竖直截面 Dx={y:(x,y)∈D}，其长度为 L(x)。则 fX(x)=L(x)/A；当 L(x)>0，条件于 X=x 时，Y 在截面 Dx 上均匀，密度为 1/L(x)。这指一个条件密度版本，不是把零概率事件 X=x 代入普通条件概率公式。

若 D 为矩形，联合密度可分解为两条区间均匀密度的乘积，故 X,Y 独立；非矩形区域一般不能这样分解。

f(x,y)=ID(x,y)/A
使用条件

区域 D 可测且 0<A<∞；截面长为 0 时条件密度公式不使用。边界面积为 0 时是否把边界计入区域，不影响分布。

展开性质证明 / 推导过程

归一化：∬D(1/A)dxdy=1。边缘化时先固定 x，沿竖直方向积分，fX(x)=∫Dx(1/A)dy=L(x)/A。在 L(x)>0 处，联合密度除以边缘密度，得 fY∣X=x(y)=IDx(y)/L(x)。若 D=(a,b)×(c,d)，则 A=(b−a)(d−c)，且 fX=1/(b−a)、fY=1/(d−c)，所以 f=fXfY。反例：在三角形 D={0<x<y<1} 中，A=1/2、Dx=(x,1)，因此 fX(x)=2(1−x)、fY∣X=x(y)=1/(1−x)（x<y<1）。条件支持随 x 改变，所以两个坐标不独立。

做一道简单例题

例： 点均匀落在 0<x<y<1。事件 Y>2X 的面积为 ∫01/2(1−2x)dx=1/4，占整个三角形面积 1/2 的一半，故概率为 1/2。

容易出错的地方

二维“均匀”是联合密度在区域内为常数，不表示每个边缘分布也均匀；三角形上 fX(x)=2(1−x) 就不是常数。

3.1Random vectors and lower-dimensional marginals理解后再记忆

多维随机向量：联合分布与低维边缘

先用一句话理解

同时记录多个量，先描述它们的整体分布；只关心部分坐标时，把其余坐标消去。

定义在同一概率空间上的随机变量 X1,…,Xn 构成 n 维随机变量（随机向量） X=(X1,…,Xn)。联合分布函数描述所有坐标同时不超过给定阈值的概率。若存在非负函数 f，使联合分布函数等于相应左下区域上的 n 重积分，就称该向量为连续型，f 为联合密度；它在整个 Rn 上积分为 1。

低维边缘保留若干坐标：在联合分布函数中让其余阈值趋于正无穷；有密度时对其余坐标积分。离散情形则对其余坐标的取值求和。例如三维密度的二维边缘为 fX1,X2(x1,x2)=∫Rf(x1,x2,x3)dx3。

F(x)=P(⋂i=1n{Xi≤xi})
使用条件

维数 n 为有限正整数；密度公式须确有联合密度。积分时仍须满足联合支撑区域的全部限制。

展开性质证明 / 推导过程

边缘 CDF：以三维保留前两维为例，事件 {X1≤x1,X2≤x2,X3≤m} 随 m→∞ 递增到 {X1≤x1,X2≤x2}，故由概率连续性得到边缘极限。

边缘密度：对平面区域 B，P((X1,X2)∈B)=∬B[∫Rf(x1,x2,x3)dx3]dx1dx2。内层函数非负，且全平面积分为 1，因而是所求密度。更多维的论证相同；非负积分可用 Tonelli 定理交换次序。

做一道简单例题

单位立方体内 f(x,y,z)=8xyz，其他处为 0。对 z 积分得到 fX,Y(x,y)=4xy；再对 y 积分得到 fX(x)=2x，均在各自单位区间内成立。

容易出错的地方

多维联合分布包含依赖关系；只给出所有一维边缘，通常仍不能恢复联合分布。

3.2Marginal distribution理解后再记忆

边缘分布与联合分布的信息差

先用一句话理解

只看其中一个变量时，把另一个变量的所有可能性加起来。

边缘分布是随机向量各个分量自己的分布。离散边缘概率沿另一指标求和；连续边缘密度沿另一坐标积分。联合分布唯一确定边缘分布，但给定边缘分布通常不能唯一恢复联合分布。

pi·=∑jpij,fX(x)=∫−∞∞f(x,y)dy,FX(x)=limy→∞F(x,y)
使用条件

求边缘时积分上下限可能依赖保留的坐标；支撑区域外密度为 0。

展开性质证明 / 推导过程

离散情形把 {X=xi} 按互斥事件 {Y=yj} 分割，再用可列可加性。连续情形 P(X∈A)=∫A∫Rf(x,y)dydx，据一维密度定义识别内层积分。联合分布函数的极限由递增事件连续性得到。

做一道简单例题

f(x,y)=2 在 0<x<y<1 时，fX(x)=2(1−x)、fY(y)=2y，各自在 (0,1) 外为 0。

容易出错的地方

若两变量边缘均为公平的 0–1 分布，它们既可能独立，也可能完全相同。

条件分布：离散与连续条件分布函数与连续型贝叶斯公式
3.3Conditional distribution理解后再记忆

条件分布：离散与连续

先用一句话理解

观察到一个变量之后，重新描述另一个变量的分布。

离散条件分布直接使用条件概率。连续变量的单点事件通常概率为 0，条件密度不能把 P(Y=y) 当分母；在 fY(y)>0 时用联合密度与边缘密度之比定义一个条件密度版本。条件分布只要求在边缘分布意义下几乎处处确定。

P(X=xi∣Y=yj)=pijp·j,fX∣Y(x∣y)=f(x,y)fY(y)
使用条件

离散分母须大于 0；连续分母密度须大于 0。条件密度必须关于待求变量积分为 1。

展开性质证明 / 推导过程

离散公式来自 P(A∣B)=P(A∩B)/P(B)。连续公式先满足 ∫f(x,y)/fY(y)dx=1，再满足 P(X∈A,Y∈B)=∫B[∫AfX∣Y(x∣y)dx]fY(y)dy，因此确实把联合概率分解为给定 Y 的概率与 Y 的分布。密度连续时也可从窄区间 y<Y≤y+h 的条件概率取极限理解。

做一道简单例题

在 0<x<y<1 上联合密度为 2，给定 Y=y 后 X 在 (0,y) 上均匀，条件密度为 1/y。

容易出错的地方

给定 Y=y 之后，y 是参数；归一化时对 x 积分。

试一题：P3-04 →
3.3Conditional CDF and density Bayes rule理解后再记忆

条件分布函数与连续型贝叶斯公式

先用一句话理解

已知一个量后重新归一化；把观察方向倒过来时，需要用另一边缘密度再归一化。

有联合密度 f(x,y) 时，在 fY(y)>0 的位置，条件分布函数为 FX∣Y(x∣y)=∫−∞xfX∣Y(u∣y)du。离散情形则把条件概率沿 xi≤x 求和。

若先给出 X 的边缘密度和 Y∣X=x 的条件密度，则联合密度由 f(x,y)=fY∣X(y∣x)fX(x) 重建。对 x 积分得到 fY(y)，再反向条件化，得到连续型贝叶斯公式。条件密度是密度，不要求其值不超过 1。 为缩短记号，下面令 q(y∣x)=fY∣X(y∣x)、π(x)=fX(x)、m(y)=fY(y)，并用 p(x∣y) 记反向条件密度。

p(x∣y)=q(y∣x)π(x)m(y)
使用条件

分母 fY(y)=∫RfY∣X(y∣u)fX(u)du 须为正。单点条件通过条件密度定义，不能除以 P(Y=y)=0。等式按所选密度版本几乎处处理解。

展开性质证明 / 推导过程

先把联合密度分解为“给定 x 的条件密度 × x 的边缘密度”。由边缘化，分母正是该乘积关于 x 的积分；故贝叶斯公式右侧非负且关于 x 积分为 1。乘回 fY(y) 恢复联合密度，所以在任意两个区域 A、B 上积分可恢复 P(X∈A,Y∈B)。

固定 y 后，条件密度积分给出的函数随 x 单调不减、连续，左右极限分别为 0 与 1，因此是分布函数。离散情形将积分改为求和即可。

做一道简单例题

先取 X~U(0,1)，再在 (0,X) 内均匀取 Y。联合密度为 1/x（0<y<x<1），所以 fY(y)=∫y1dx/x=−logy。反向条件密度为 1/[−xlogy]（y<x<1）。同一个三角形支撑，也可能对应非常数联合密度。

容易出错的地方

分层“先均匀取 X，再条件均匀取 Y”通常不等于在二维区域上均匀取点；每层区间长度会改变密度。

正文主题已核对 · 第6版第 87–92 页 · 核对明细

随机变量独立性与函数保持独立二维正态分布与零相关随机向量的独立与分组函数独立性
3.4Independence of random variables理解后再记忆

随机变量独立性与函数保持独立

先用一句话理解

知道一个变量的值，不改变另一个变量的分布。

X,Y 独立是指对任意实数 x,y 有 F(x,y)=FX(x)FY(y)；等价地，对任意可测集合 A,B，事件 {X∈A} 与 {Y∈B} 独立。离散时联合概率逐点分解；存在联合密度时联合密度几乎处处分解。多个变量相互独立要求任意有限组的联合分布均分解，而两两独立不足。独立变量各自作可测变换后仍独立。

f(x,y)=fX(x)fY(y)a.e.,pij=pi·p·j
使用条件

密度判据仅用于具有联合密度的情形。分别对 X 和 Y 作变换，不能将混合两者的任意函数都说成独立。

展开性质证明 / 推导过程

独立时矩形概率分解，对矩形积分比较得到密度分解（几乎处处）；反之，密度乘积分解后矩形的二重积分分成两积分乘积，得到联合分布函数分解。若 U=g(X),V=h(Y)，则 {U∈A}={X∈g−1(A)}，两逆像事件独立，因此 U,V 独立。

做一道简单例题

若联合密度为 4xy 在单位正方形上，边缘为 2x,2y，因此独立。三角形上的常数密度通常不独立，支撑形状已经提示依赖。

容易出错的地方

只验证某一对阈值的概率分解不足以证明独立，须验证整个分布。

3.4Bivariate normal distribution理解后再记忆

二维正态分布与零相关

先用一句话理解

二维正态用两个均值、两个标准差与相关系数描述椭圆形的概率密度。

非退化二维正态参数为 μ1,μ2,σ1>0,σ2>0,|ρ|<1；两个边缘均为正态。只有在联合正态的前提下，零相关才等价于独立。两个边缘各自正态并不足以推出联合正态。条件分布也是正态，均值随给定值线性改变，条件方差为 σ12(1−ρ2)。

f(x,y)=exp{−12(1−ρ2)[u2−2ρuv+v2]}2πσ1σ21−ρ2,u=x−μ1σ1, v=y−μ2σ2
使用条件

这里给出非退化密度；|ρ|=1 的情形集中在线上，不能套用此密度。相关系数的定义在第四章进一步解释。

展开性质证明 / 推导过程

配方 u2−2ρuv+v2=(u−ρv)2+(1−ρ2)v2。关于 x 积分时第一部分是归一化正态密度，剩下 Y 的正态边缘。联合密度除以 Y 的边缘得到 X∣Y=y 为 N(μ1+ρσ1(y−μ2)/σ2,σ12(1−ρ2))。当 ρ=0，联合密度直接分成两个边缘之积，故独立；反向由独立且二阶矩有限可推出协方差为 0。

做一道简单例题

标准二维正态且 ρ=1/2 时，给定 Y=2，X 的条件均值为 1，条件方差为 3/4。

容易出错的地方

一般分布中不相关不代表独立；不能删掉“联合正态”这个条件。

3.4Independent random vectors and functions of blocks理解后再记忆

随机向量的独立与分组函数独立性

先用一句话理解

独立的两组数据，各自在组内加工，得到的两个结果仍然独立。

两个随机向量 X=(X1,…,Xm) 与 Y=(Y1,…,Yn) 相互独立，是指它们的联合分布函数对所有阈值都分解为两个向量各自分布函数的乘积。等价地，任意可测集合 A、B 都满足 P(X∈A,Y∈B)=P(X∈A)P(Y∈B)。

分组函数定理：若这两个向量独立，则 h(X) 与 g(Y) 独立。教材给出连续函数情形；可测函数也成立。特别地，有限个相互独立变量按互不重叠的指标分组，各组构成的向量独立，各组的函数也相互独立。

只验证每个 Xi 与每个 Yj 两两独立，还不足以证明两个向量独立。

X⟂⟂Y ⟹ h(X)⟂⟂g(Y)
使用条件

函数须可测；连续函数自动满足。分组保持独立需要整体独立，不能仅凭每对分量独立。两个函数若使用重叠变量，此定理不能直接使用。

展开性质证明 / 推导过程

对任意可测数集 C、D，{h(X)∈C}={X∈h−1(C)}，另一组也有相同形式。逆像都是各自向量的可测事件，由向量独立性，二者交事件的概率分解，故函数独立。

对相互独立的全部分量，先在各组的阈值事件上使用联合 CDF 乘积定义，再把同组乘积收集起来，就得到分组向量的 CDF 分解。CDF 判据与可测集合判据的等价性使用“半无限矩形生成 Borel 集”的标准结论；这里明确把它作为前置结果。

做一道简单例题

四个相互独立的公平 0–1 变量中，X1+X2 与 max(X3,X4) 独立。相反，X1+X2 和 X2+X3 共用 X2，一般不独立。

容易出错的地方

“每个原始变量都独立”不等于“任意两个混合函数都独立”；先检查两组是否使用相互独立的信息。

3.5Convolution理解后再记忆

和的分布与卷积

先用一句话理解

要让两个变量的和等于某个值，先列出所有能拼成这个值的组合。

离散函数 Z=g(X,Y) 的概率由所有映到同一值的联合概率相加。连续和 Z=X+Y 的密度为沿 y=z−x 积分。若独立，可把联合密度替换为边缘密度乘积，这才是常用的卷积公式。独立正态之和仍为正态，其均值、方差分别相加；独立泊松之和仍为泊松，参数相加。

fX+Y(z)=∫−∞∞f(x,z−x)dx,fX+Y(z)=∫−∞∞fX(x)fY(z−x)dx (独立)
使用条件

连续公式要求联合密度存在；独立性是使用边缘乘积的额外条件。

展开性质证明 / 推导过程

从 FZ(z)=∫R∫−∞z−xf(x,y)dydx 出发，对 z 求导（几乎处处）得到公式。也可作变换 (x,y)↦(x,z=x+y)，Jacobian 的绝对值为 1。泊松和的离散证明：P(X+Y=k)=e−(λ+μ)∑j=0kλjμk−j/[j!(k−j)!]=e−(λ+μ)(λ+μ)k/k!，最后一步用二项式定理。正态卷积对指数中的二次式配方积分，得到方差相加的正态密度。

做一道简单例题

独立 U(0,1) 的和呈三角形密度：fZ(z)=z（0<z<1），2−z（1≤z<2），其他为 0。

容易出错的地方

卷积积分的范围应同时满足两个密度非零的条件；不是永远从 0 到 z。

3.5Product and ratio理解后再记忆

乘积与商的密度变换

先用一句话理解

反解变量时，除了替换密度，还要乘上面积缩放因子。

设 (X,Y) 有联合密度。乘积 Z=XY 可保留 X 并反解 Y=Z/X，面积因子为 1/|x|。商 Z=X/Y 可保留 Y 并反解 X=ZY，面积因子为 |y|。有联合密度时坐标轴概率为零，零分母事件不影响商的分布。 若教材记作 Z=Y/X，交换两个坐标可得 fY/X(z)=∫R|x|f(x,xz)dx；先确认分子和分母再代入。

fXY(z)=∫Rf(x,z/x)|x|dx,fX/Y(z)=∫R|y|f(zy,y)dy
使用条件

等式按密度几乎处处理解；积分忽略零分母点。若存在原子或奇异联合分布，应回到分布函数法。

展开性质证明 / 推导过程

乘积变换的逆映射为 (x,z)↦(x,z/x)，Jacobian 行列式为 1/x，取绝对值再对保留变量积分。商变换的逆映射为 (z,y)↦(zy,y)，行列式为 y，同样取绝对值。正负区间都可能有贡献，绝对值保证密度非负。

做一道简单例题

独立 U(0,1) 的乘积密度在 0<z<1 上为 ∫z1dx/x=−logz，其余为 0。

容易出错的地方

Jacobian 必须取绝对值，反解得到多个分支时还须逐支相加。

3.5Maximum and minimum理解后再记忆

最大值与最小值的分布

先用一句话理解

最大值不超过 z，要求所有变量都不超过 z；最小值超过 z，要求所有变量都超过 z。

设 X1,…,Xn 相互独立，M=maxiXi、L=miniXi。用交事件的概率乘积得到分布函数。同分布时简化为幂函数。连续同分布时求导得到最大值与最小值的密度。

FM(z)=∏i=1nFi(z),FL(z)=1−∏i=1n[1−Fi(z)]
使用条件

乘积公式需要相互独立，只有两两独立通常不足；同分布的简化还需要各 F 相同。

展开性质证明 / 推导过程

{M≤z}=∩i{Xi≤z}，由相互独立得到第一式。{L>z}=∩i{Xi>z}，取补即得第二式。若同分布且有密度，链式求导给出 fM(z)=nF(z)n−1f(z) 与 fL(z)=n[1−F(z)]n−1f(z)。这些公式保留了 CDF 的端点约定，也适用于离散 CDF。

做一道简单例题

三个独立 U(0,1) 变量的最大值在 (0,1) 上 CDF 为 z3，密度为 3z2。

容易出错的地方

最小值的分布函数不是各分布函数的乘积。

3.5Distributions under multivariable maps理解后再记忆

一般函数的分布：离散合并与连续区域法

先用一句话理解

先找出哪些原始结果会变成指定的新结果，再把它们的概率合起来。

离散情形，Z=g(X,Y) 的分布由所有满足 g(xi,yj)=z 的联合概率相加；变成两个新变量 U=g1(X,Y),V=g2(X,Y) 时，同时满足两个等式的项一起相加，不能把两个边缘随意相乘。

连续情形先求 CDF：FZ(z)=∬g(x,y)≤zf(x,y)dxdy。若求 (U,V) 的联合分布函数，则积分区域同时满足 g1(x,y)≤u、g2(x,y)≤v。该方法无需映射可逆；常值变换可以产生原子，变换后的两个量也可能集中在曲线上。 这里 Auv={(i,j):g1(xi,yj)=u, g2(xi,yj)=v} 为对应的新值原像指标集合。

P(U=u,V=v)=∑(i,j)∈Auvpij
使用条件

离散式对联合分布的所有格点求和；连续区域法要求原向量有联合密度。求 CDF 后，只有确认新分布具有密度，才能靠求导恢复全部概率。

展开性质证明 / 推导过程

离散等值事件是其各个原像格点事件的不交并，由可列可加性得到求和公式。连续时，事件 {g(X,Y)≤z} 就是原随机点落入集合 {(x,y):g(x,y)≤z}；直接使用联合密度的区域概率公式。两个新坐标同时受限时，将两个原像区域取交即可。

例如把整个平面映射为常数 0，CDF 在 0 有一次大小为 1 的跳跃；若只在其他点求导，会错误得到处处为零的“密度”。

做一道简单例题

若 (X,Y) 只取 (0,0)、(0,1)、(1,0)、(1,1)，概率依次为 1/8,3/8,1/4,1/4，则 (X+Y,XY) 只可能取 (0,0)、(1,0)、(2,1)，概率为 1/8,5/8,1/4。

容易出错的地方

两个原像格点变成同一个新值时必须合并。即使 X、Y 独立，两个混合函数 U、V 也未必独立。

3.5Change of variables and the Jacobian理解后再记忆

二维密度变换定理与雅可比因子

先用一句话理解

换坐标会拉伸或压缩面积，密度必须反向调整，才能保住同一块区域的概率。

设 (U,V)=T(X,Y)。若在所考虑的支撑内部，T 是一一对应的可微变换，逆变换 x=h1(u,v),y=h2(u,v) 连续可微，且逆变换的雅可比行列式不为 0，则新联合密度等于旧密度在逆像处的值，乘逆变换的面积缩放因子。映像区域之外密度为 0。

雅可比行列式为 J=h1uh2v−h1vh2u。若能将原支撑拆成若干不重叠、各自可逆的分支，则各分支的密度贡献相加；边界须不携带概率质量。 下面将整个逆变换记作 h=(h1,h2)，f∘h 表示把逆变换代入原密度。

fU,V=(f∘h)|J|
使用条件

须检查一一对应、可微性、非零雅可比及变换后的支撑。若变换退化为一维（例如 U=V=X），本二维密度公式不能使用。

展开性质证明 / 推导过程

对新坐标中任意区域 B，P((U,V)∈B)=∬T−1(B)f(x,y)dxdy。应用二重积分换元定理，把积分变量换为 u、v，得到 ∬Bf(h1(u,v),h2(u,v))|J|dudv。根据密度定义，识别出新密度。

若分成多个可逆分支，各分支的原像事件互斥，故其区域积分相加。这解释了“雅可比取绝对值”与“多个分支要相加”是两个不同要求。

做一道简单例题

X、Y 独立且均为 U(0,1)，取 U=X+Y,V=X−Y。反解 x=(u+v)/2,y=(u−v)/2，J=−1/2。故联合密度为 1/2，支撑为 0<u<2、|v|<min(u,2−u)，是一个菱形。

容易出错的地方

本式乘的是逆变换的雅可比绝对值；若算了正向雅可比，应在非零处取倒数。支撑区域也必须一起变换。

3.5Gamma distribution and additivity理解后再记忆

Γ 分布的定义、参数约定与可加性

先用一句话理解

同一速率下，独立等待时间相加，会把 Γ 分布的形状参数加起来。

Γ 函数定义为 Γ(a)=∫0∞ta−1e−tdt（a>0），满足 Γ(a+1)=aΓ(a)、Γ(1)=1，故正整数时 Γ(k)=(k−1)!。

Γ 分布采用形状 a、速率 λ 的约定：在 x>0 上密度为 λaxa−1e−λx/Γ(a)，其他处为 0。均值为 a/λ，方差为 a/λ2。a=1 为指数分布；a=ν/2,λ=1/2 为卡方分布。

可加性：独立 X~Γ(a,λ)、Y~Γ(b,λ) 满足 X+Y~Γ(a+b,λ)；可推广至有限多个相互独立变量。

Γ(a,λ)*Γ(b,λ)=Γ(a+b,λ)
使用条件

a、b、λ 均正；可加性同时要求独立、相同速率。若资料使用尺度 θ，则 θ=1/λ，不能把两种约定混用。

展开性质证明 / 推导过程

归一化与矩：令 t=λx，密度积分为 1。对密度乘 xk 后积分，得到 E(Xk)=Γ(a+k)/[Γ(a)λk]（非负整数 k）。取 k=1、2 并使用 Γ 递推式，即得均值与方差；递推式本身由分部积分得到。

卷积：对 z>0，提出 e−λzλa+b/[Γ(a)Γ(b)]，余下积分为 ∫0zxa−1(z−x)b−1dx。令 x=zt，得到 za+b−1B(a,b)，其中 B(a,b)=∫01ta−1(1−t)b−1dt。于是密度恰为形状 a+b、速率 λ 的 Γ 密度。

为何 B(a,b)=Γ(a)Γ(b)/Γ(a+b)：在 Γ(a)Γ(b) 的正象限二重积分中，换元 r=x+y,t=x/(x+y)，逆变换为 x=rt,y=r(1−t)，雅可比绝对值为 r。积分分离为 Γ(a+b)B(a,b)，即得恒等式。

做一道简单例题

三个相互独立的速率为 3 的指数等待时间之和，服从 Γ(3,3)；密度为 27z2e−3z/2（z>0），均值为 1，方差为 1/3。

容易出错的地方

形状可以是任意正实数，不必是整数。不同速率的 Γ 变量之和一般不能直接把形状相加。

3.5Linear combinations of independent normals理解后再记忆

独立正态变量线性组合：配方证明

先用一句话理解

独立正态变量加减缩放后仍是正态；系数在均值中一次出现，在方差中平方出现。

若 X1,…,Xn 相互独立，Xi~N(μi,σi2)，则 Z=b+∑iaiXi 为正态，均值 b+∑iaiμi，方差 ∑iai2σi2。当方差和为 0 时退化为常数。

这是有限样本的精确结论，与中心极限定理的近似用途不同。若只知道每个边缘是正态，既没有独立性也没有联合正态性，则不能保证线性组合为正态。联合正态但相关时仍为正态，方差须加入协方差项。

Z~N(b+∑iaiμi, ∑iai2σi2)
使用条件

本卡主结论要求相互独立；先排除系数为 0 的项，再处理正方差项。允许把退化常数写作方差为 0 的正态。

展开性质证明 / 推导过程

先证两个中心正态之和。设 X~N(0,v1)、Y~N(0,v2) 独立，v1,v2>0。卷积指数含有 q(x)=x2/v1+(z−x)2/v2。令 A=(v1+v2)/(v1v2)、c=v1z/(v1+v2)、d=z2/(v1+v2)。展开右侧可直接核验配方：

q(x)=A(x−c)2+d.

提出 e−d/2 后，关于 x 的积分为 ∫Re−A(x−c)2/2dx=2π/A。与原系数 1/(2πv1v2) 相乘，得到方差为 v1+v2 的正态密度，证明两项可加性。

一般情形先中心化，再用一维仿射变换结论处理每个 aiXi。独立变量的分组函数仍独立，所以可逐项使用两项结论；最后加回均值与常数 b。

做一道简单例题

独立 X~N(1,4),Y~N(−2,9)，令 Z=3X−2Y+1，则均值为 8，方差为 9×4+4×9=72。

容易出错的地方

减去一个独立变量会减去它的均值，但不会减去它的方差；标准差也不能直接相加。

3.5Series, parallel and cold-standby lifetimes理解后再记忆

串联、并联与冷备用：先确定寿命函数

先用一句话理解

同时运行时，一坏就停取最小寿命，全坏才停取最大寿命；理想冷备用依次运行时取寿命之和。

设两个部件的独立工作寿命为 X、Y。可靠度函数 R(t)=P(T>t) 表示系统在时刻 t 后仍工作的概率。固定 t，简记两个部件的可靠度为 r=RX(t)、s=RY(t)。

结构 寿命 T 可靠度
串联 min(X,Y) rs
并联 max(X,Y) r+s−rs
冷备用 X+Y 用卷积

若 X、Y 的指数速率为 λ、μ，则串联寿命为速率 λ+μ 的指数分布；λ≠μ 时冷备用的密度为 λμ(e−λt−e−μt)/(μ−λ)（t>0）。λ=μ 时使用 Γ(2,λ)。

Rseries(t)=e−(λ+μ)t,t≥0
使用条件

部件寿命独立；并联假定两个部件从时刻 0 同时工作。冷备用假定备用期间不老化、切换即时且成功，启用后的寿命服从 Y；这些条件决定能否用 X+Y。

展开性质证明 / 推导过程

串联：系统在 t 后存活等价于 X>t,Y>t 同时发生，独立性给出可靠度乘积。并联：系统失效等价于 X≤t,Y≤t，故可靠度为 1−FX(t)FY(t)，展开即得表中公式。

冷备用：第一只在 X 时失效后，第二只再工作 Y，故总寿命为和。对 t>0，卷积为 λμe−μt∫0te−(λ−μ)xdx，积分得到所列密度；速率相等时直接积分得到 λ2te−λt。

均值可由 max(X,Y)+min(X,Y)=X+Y 求得：指数情形并联平均寿命为 1/λ+1/μ−1/(λ+μ)，冷备用为 1/λ+1/μ。

做一道简单例题

速率为 2、3 的部件在 t=log2 时，串联可靠度为 1/32，并联为 11/32，理想冷备用为 1/2。结构不同，即使部件相同，答案也不同。

容易出错的地方

备用部件若从一开始就在老化，或切换可能失败，寿命之和模型需修改；不要把并联误写成 X+Y。

3.5Rayleigh distribution from a Gaussian radius理解后再记忆

习题中的瑞利分布：二维正态点到原点的距离

先用一句话理解

两个独立同方差的中心正态坐标，合成的距离不再是正态，而是只取非负值的瑞利分布。

若 X、Y 相互独立且均服从 N(0,σ2)，σ>0，则 R=X2+Y2 服从参数为 σ 的 瑞利（Rayleigh）分布。对 r≥0，分布函数为 1−e−r2/(2σ2)；密度在 r>0 为 re−r2/(2σ2)/σ2，其余为 0。

它出现在第六版第三章习题三的分布变换题中；本卡用独立编写的极坐标证明解释该分布，未照录教材习题解答。

P(R>r)=e−r2/(2σ2),r≥0
使用条件

两个坐标均值均为 0、方差相同且独立。均值非零或尺度不同会改变距离分布；不能只因两个坐标正态就套用瑞利公式。

展开性质证明 / 推导过程

联合密度为 e−(x2+y2)/(2σ2)/(2πσ2)。事件 R≤r 是半径为 r 的圆盘。极坐标中 x=scosθ,y=ssinθ，面积元为 sdsdθ，因此

FR(r)=∫0rsσ2e−s2/(2σ2)ds.

积分得到 FR(r)=1−e−r2/(2σ2)（r≥0）。

对 r 求导得到密度。同时 R2/σ2=(X/σ)2+(Y/σ)2~χ2(2)，所以 E(R2)=2σ2。后一式是平方的期望，不能再开平方当成 E(R)。

做一道简单例题

若 σ=2，距离超过 4 的概率为 e−2，且 E(R2)=8。这两个量可分别由瑞利尾公式和两个坐标的二阶矩核验。

容易出错的地方

极坐标积分不能遗漏雅可比 s；R 非负，密度在负半轴必须为 0。
