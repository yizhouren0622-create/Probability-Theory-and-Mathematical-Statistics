原创 P13-01第 13.1 节 · 基础

计算路径概率

两状态链 P=(0.70.30.20.8)，初始分布 (0.6,0.4)。求路径 0→1→1→0 的概率。

给我一点提示
提示 1

先包括初始为 0 的概率。

提示 2

依次使用 0→1、1→1、1→0。

提示 3

不要对不存在的中间路径求和。

带我一步一步做

第 1 / 4 步

  1. 初始为 0 的概率为 0.6。

  2. 第一步 0→1 概率为 0.3。

  3. 第二步 1→1 概率为 0.8，第三步 1→0 概率为 0.2。

  4. 路径概率为 0.6×0.3×0.8×0.2=0.0288。

查看完整解答与检验

  1. 初始为 0 的概率为 0.6。

  2. 第一步 0→1 概率为 0.3。

  3. 第二步 1→1 概率为 0.8，第三步 1→0 概率为 0.2。

  4. 路径概率为 0.6×0.3×0.8×0.2=0.0288。

答案

0.0288。

检验与提醒

若题目条件已经给定 X0=0，则应去掉初始因子 0.6。

原创 P13-02第 13.2 节 · 基础

两步概率与初始分布

P=(0.80.20.40.6)，初始必在状态 0。求两步后的分布。

给我一点提示
提示 1

求 P² 的第一行。

提示 2

到 0 有 0→0→0 与 0→1→0。

提示 3

最后检查两项相加为 1。

带我一步一步做

第 1 / 4 步

  1. p00(2)=0.8×0.8+0.2×0.4=0.72。

  2. p01(2)=0.8×0.2+0.2×0.6=0.28。

  3. 初始分布是 (1,0)，因此只需 P² 的第一行。

  4. 得到 (0.72,0.28)，和为 1。

查看完整解答与检验

  1. p00(2)=0.8×0.8+0.2×0.4=0.72。

  2. p01(2)=0.8×0.2+0.2×0.6=0.28。

  3. 初始分布是 (1,0)，因此只需 P² 的第一行。

  4. 得到 (0.72,0.28)，和为 1。

答案

(0.72,0.28)。

检验与提醒

两步在 0 的事件包含中途到过 1 再返回。

原创 P13-03第 13.3 节 · 进阶

平稳但不收敛的链

对 P=(0110) 求平稳分布、状态周期，并判断从状态 0 出发的 n 步分布是否收敛。

给我一点提示
提示 1

每一步必定切换状态。

提示 2

能返回的步数都是偶数。

提示 3

平稳时两状态概率须相等。

带我一步一步做

第 1 / 4 步

  1. πP=π 给 π0=π1，结合和为 1 得各为 1/2。

  2. 返回步数为 2,4,6,…，最大公约数 2，因此周期为 2。

  3. 从 0 出发，偶数步分布 (1,0)，奇数步分布 (0,1)。

  4. 两个子序列不同，故逐步分布不收敛；平稳分布的存在不构成收敛证明。

查看完整解答与检验

  1. πP=π 给 π0=π1，结合和为 1 得各为 1/2。

  2. 返回步数为 2,4,6,…，最大公约数 2，因此周期为 2。

  3. 从 0 出发，偶数步分布 (1,0)，奇数步分布 (0,1)。

  4. 两个子序列不同，故逐步分布不收敛；平稳分布的存在不构成收敛证明。

答案

平稳分布 (1/2,1/2)，周期 2，单点起步的逐步分布不收敛。

检验与提醒

长期各状态占用比例仍各为 1/2，区分它与逐步分布。
