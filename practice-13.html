原创 P13-01第 13.1 节 · 基础

计算路径概率

两状态链 P=(0.70.30.20.8)，初始分布 (0.6,0.4)。求路径 0→1→1→0 的概率。

给我一点提示
提示 1

先包括初始为 0 的概率。

提示 2

依次使用 0→1、1→1、1→0。

提示 3

不要对不存在的中间路径求和。

带我一步一步做

第 1 / 4 步

  1. 初始为 0 的概率为 0.6。

  2. 第一步 0→1 概率为 0.3。

  3. 第二步 1→1 概率为 0.8，第三步 1→0 概率为 0.2。

  4. 路径概率为 0.6×0.3×0.8×0.2=0.0288。

查看完整解答与检验

  1. 初始为 0 的概率为 0.6。

  2. 第一步 0→1 概率为 0.3。

  3. 第二步 1→1 概率为 0.8，第三步 1→0 概率为 0.2。

  4. 路径概率为 0.6×0.3×0.8×0.2=0.0288。

答案

0.0288。

检验与提醒

若题目条件已经给定 X0=0，则应去掉初始因子 0.6。

原创 P13-02第 13.2 节 · 基础

两步概率与初始分布

P=(0.80.20.40.6)，初始必在状态 0。求两步后的分布。

给我一点提示
提示 1

求 P² 的第一行。

提示 2

到 0 有 0→0→0 与 0→1→0。

提示 3

最后检查两项相加为 1。

带我一步一步做

第 1 / 4 步

  1. p00(2)=0.8×0.8+0.2×0.4=0.72。

  2. p01(2)=0.8×0.2+0.2×0.6=0.28。

  3. 初始分布是 (1,0)，因此只需 P² 的第一行。

  4. 得到 (0.72,0.28)，和为 1。

查看完整解答与检验

  1. p00(2)=0.8×0.8+0.2×0.4=0.72。

  2. p01(2)=0.8×0.2+0.2×0.6=0.28。

  3. 初始分布是 (1,0)，因此只需 P² 的第一行。

  4. 得到 (0.72,0.28)，和为 1。

答案

(0.72,0.28)。

检验与提醒

两步在 0 的事件包含中途到过 1 再返回。

原创 P13-03第 13.3 节 · 进阶

平稳但不收敛的链

对 P=(0110) 求平稳分布、状态周期，并判断从状态 0 出发的 n 步分布是否收敛。

给我一点提示
提示 1

每一步必定切换状态。

提示 2

能返回的步数都是偶数。

提示 3

平稳时两状态概率须相等。

带我一步一步做

第 1 / 4 步

  1. πP=π 给 π0=π1，结合和为 1 得各为 1/2。

  2. 返回步数为 2,4,6,…，最大公约数 2，因此周期为 2。

  3. 从 0 出发，偶数步分布 (1,0)，奇数步分布 (0,1)。

  4. 两个子序列不同，故逐步分布不收敛；平稳分布的存在不构成收敛证明。

查看完整解答与检验

  1. πP=π 给 π0=π1，结合和为 1 得各为 1/2。

  2. 返回步数为 2,4,6,…，最大公约数 2，因此周期为 2。

  3. 从 0 出发，偶数步分布 (1,0)，奇数步分布 (0,1)。

  4. 两个子序列不同，故逐步分布不收敛；平稳分布的存在不构成收敛证明。

答案

平稳分布 (1/2,1/2)，周期 2，单点起步的逐步分布不收敛。

检验与提醒

长期各状态占用比例仍各为 1/2，区分它与逐步分布。

原创 P13-04第 13.1 节 · 进阶

两暂态链的平均吸收步数

状态 3 吸收，转移矩阵 P=(01/21/21/403/4001)。求从状态 1、2 出发直到首次到达 3 的期望步数。

给我一点提示
提示 1

吸收态的剩余步数为 0。

提示 2

对两个暂态分别写“先走一步”方程。

提示 3

联立两个线性方程。

带我一步一步做

第 1 / 4 步

  1. 记期望步数为 t1,t2，则 t1=1+12t2。

  2. 第二状态满足 t2=1+14t1。

  3. 代入得 t1=1+12(1+14t1)，即 (7/8)t1=3/2。

  4. 因此 t1=12/7，再代回得 t2=10/7。

查看完整解答与检验

  1. 记期望步数为 t1,t2，则 t1=1+12t2。

  2. 第二状态满足 t2=1+14t1。

  3. 代入得 t1=1+12(1+14t1)，即 (7/8)t1=3/2。

  4. 因此 t1=12/7，再代回得 t2=10/7。

答案

从状态 1、2 出发分别为 12/7、10/7 步。

检验与提醒

Q2=(1/8)I，所以暂态概率最终趋零；两个有限期望与吸收条件相符。

原创 P13-05第 13.3 节 · 进阶

用细致平衡求三状态平稳分布

对 P=(1/21/201/41/21/401/21/2)，由细致平衡求 π，并判断从任意起点的逐步分布是否收敛到 π。

给我一点提示
提示 1

先用状态 1、2 之间的双向流量相等。

提示 2

再用状态 2、3 的流量相等，并令概率和为 1。

提示 3

收敛还须检查不可约和非周期。

带我一步一步做

第 1 / 4 步

  1. π1/2=π2/4，故 π2=2π1。

  2. π2/4=π3/2，故 π2=2π3。

  3. 归一化得 π=(1/4,1/2,1/4)；非相邻状态之间双向概率均为 0。

  4. 三状态彼此可达，且每个状态有正自环概率，故有限链不可约、非周期；逐步分布从任意起点收敛到 π。

查看完整解答与检验

  1. π1/2=π2/4，故 π2=2π1。

  2. π2/4=π3/2，故 π2=2π3。

  3. 归一化得 π=(1/4,1/2,1/4)；非相邻状态之间双向概率均为 0。

  4. 三状态彼此可达，且每个状态有正自环概率，故有限链不可约、非周期；逐步分布从任意起点收敛到 π。

答案

π=(1/4,1/2,1/4)；逐步分布收敛到它。

检验与提醒

直接核算 πP=π；若把自环删去，就不能不加检查地沿用非周期结论。

原创 P13-06第 13.3 节 · 巩固

首次返回概率与总访问次数

链的矩阵为 P=(1/32/301)，从状态 1 出发。求首次返回概率 f₁、各步回到 1 的概率、计入初始时刻的总访问次数期望，并分类两个状态。状态 1 的首次返回均值无限能否说明它零常返？

给我一点提示
提示 1

若第一步去了 2，以后还能回 1 吗？

提示 2

n 步在 1 要连续 n 次选择自环。

提示 3

先判断是否常返，再讨论正常返与零常返。

带我一步一步做

第 1 / 5 步

  1. 首次返回只有第一步自环这一种可能，故 f1=1/3；从不返回的概率为 2/3。

  2. p11(n)=(1/3)n，n=0 时取 1。

  3. 总访问次数期望为 ∑n=0∞(1/3)n=3/2，也等于 1/(1−f1)。

  4. 状态 1 的 f₁<1，为暂态；状态 2 吸收，首次返回时间恒为 1，为正常返。

  5. 状态 1 的首次返回时间有正概率为 ∞，其均值确为 ∞，但它根本不常返，所以不能称零常返。

查看完整解答与检验

  1. 首次返回只有第一步自环这一种可能，故 f1=1/3；从不返回的概率为 2/3。

  2. p11(n)=(1/3)n，n=0 时取 1。

  3. 总访问次数期望为 ∑n=0∞(1/3)n=3/2，也等于 1/(1−f1)。

  4. 状态 1 的 f₁<1，为暂态；状态 2 吸收，首次返回时间恒为 1，为正常返。

  5. 状态 1 的首次返回时间有正概率为 ∞，其均值确为 ∞，但它根本不常返，所以不能称零常返。

答案

f₁=1/3，n 步回到 1 的概率为 3⁻ⁿ，总访问次数期望 3/2。1 暂态、2 正常返；1 不是零常返。

检验与提醒

n 步在 i 的概率和首次在第 n 步返回的概率不同。此例 n≥2 的首次返回概率为 0，但 n 步仍在 1 的概率为正。

原创 P13-07第 13.3 节 · 推导

保守收缩界与实际误差

P=(.7.3.2.8)，从状态 1 出发。求 π、共同均匀质量 ε 和全变差上界；再解递推求精确距离。若要求误差≤0.01，上界保证的步数和实际最少步数各是多少？

给我一点提示
提示 1

最小条目为 0.2，状态数为 2。

提示 2

令 aₙ=P(Xₙ=1)，则 aₙ₊₁=0.2+0.5aₙ。

提示 3

分别检查 0.6×0.6ⁿ 与 0.6×0.5ⁿ 何时不大于 0.01。

带我一步一步做

第 1 / 5 步

  1. 解 πP=π 得 π=(0.4,0.6)。ε=2×0.2=0.4，收缩系数为 0.6。

  2. 初始分布 (1,0) 距离 π 为 0.6，所以 n 步上界是 0.6×0.6ⁿ。

  3. 递推 aₙ₊₁−0.4=0.5(aₙ−0.4)，a₀=1，所以 aₙ=0.4+0.6×0.5ⁿ；两状态全变差就是第一坐标的绝对差。

  4. 上界在 n=8 时为 0.010077696，仍略大于 0.01；n=9 时小于 0.01，故保证 9 步。

  5. 实际 n=5 时距离 0.01875，n=6 时为 0.009375，因此实际最少 6 步。

查看完整解答与检验

  1. 解 πP=π 得 π=(0.4,0.6)。ε=2×0.2=0.4，收缩系数为 0.6。

  2. 初始分布 (1,0) 距离 π 为 0.6，所以 n 步上界是 0.6×0.6ⁿ。

  3. 递推 aₙ₊₁−0.4=0.5(aₙ−0.4)，a₀=1，所以 aₙ=0.4+0.6×0.5ⁿ；两状态全变差就是第一坐标的绝对差。

  4. 上界在 n=8 时为 0.010077696，仍略大于 0.01；n=9 时小于 0.01，故保证 9 步。

  5. 实际 n=5 时距离 0.01875，n=6 时为 0.009375，因此实际最少 6 步。

答案

π=(.4,.6)，ε=.4；上界 .6×.6ⁿ、精确 .6×.5ⁿ；保证 9 步，实际 6 步。

检验与提醒

充分上界不紧并不说明它错误；不能用“上界尚未小于容差”推断真实误差也超标。

原创 P13-08第 13.3 节 · 综合

按首次返还分布计算平稳概率

P=(.7.3.2.8)，从 1 出发。求首次返还分布 fₙ、总返还概率与平均返还时间，据此求 π₁；再说明确定性交替链为什么不违反平均返还公式。

给我一点提示
提示 1

第一步自环立即返还；若先去 2，必须在 2 停留若干次后才首次回到 1。

提示 2

n≥2 的路径是 1→2、若干自环、2→1。

提示 3

交替链每两步返回，时间占用比例稳定但逐步分布振荡。

带我一步一步做

第 1 / 5 步

  1. f₁=0.7。n≥2 时，fₙ=0.3×0.8ⁿ⁻²×0.2=0.06×0.8ⁿ⁻²。

  2. 总和为 0.7+0.06/(1−0.8)=1，所以常返。

  3. 将 n 写成 (n−2)+2，用几何级数及其一阶加权和，平均为 0.7+0.06[0.8/0.2²+2/0.2]=2.5。

  4. 由 π₁=1/2.5=0.4，归一化得 π₂=0.6，也可直接代回 πP=π 检查。

  5. 确定性交替链的首次返还时间恒为 2，故 π₁=π₂=1/2。周期性阻止逐步收敛，却不阻止正常返或时间占用收敛。

查看完整解答与检验

  1. f₁=0.7。n≥2 时，fₙ=0.3×0.8ⁿ⁻²×0.2=0.06×0.8ⁿ⁻²。

  2. 总和为 0.7+0.06/(1−0.8)=1，所以常返。

  3. 将 n 写成 (n−2)+2，用几何级数及其一阶加权和，平均为 0.7+0.06[0.8/0.2²+2/0.2]=2.5。

  4. 由 π₁=1/2.5=0.4，归一化得 π₂=0.6，也可直接代回 πP=π 检查。

  5. 确定性交替链的首次返还时间恒为 2，故 π₁=π₂=1/2。周期性阻止逐步收敛，却不阻止正常返或时间占用收敛。

答案

f₁=.7，n≥2 时 fₙ=.06×.8ⁿ⁻²；总和 1、均值 2.5，π₁=.4；交替链返还均值 2，公式同样成立。

检验与提醒

p₁₁⁽ⁿ⁾ 允许中途多次返回，不是 fₙ。不要用 Pⁿ 的对角元代替首次返还分布。
