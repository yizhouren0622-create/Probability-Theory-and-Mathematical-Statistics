原创 P4-01第 4.1 节 · 巩固

同一期望，不同平方

X 以相等概率取 −2、0、2。求 E(X)、E(X²)，比较 E(X²) 与 [E(X)]²。

给我一点提示
提示 1

每个值的概率为 1/3。

提示 2

分别加权 X 和 X²。

提示 3

平方与取期望不能交换。

带我一步一步做

第 1 / 4 步

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

查看完整解答与检验

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

答案

E(X)=0, E(X2)=8/3。

检验与提醒

期望位于最小值和最大值之间，平方期望非负。

原创 P4-02第 4.1 节 · 巩固

随机配对的期望

把 6 张不同姓名卡随机发给 6 位对应的人，求拿到自己姓名卡的人数的期望。

给我一点提示
提示 1

给每个人设置一个 0–1 指示变量。

提示 2

每张卡落到某人的概率相同。

提示 3

线性性质不要求独立。

带我一步一步做

第 1 / 4 步

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

查看完整解答与检验

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

答案

E(N)=1。

检验与提醒

交换 6 为任意正整数，期望仍为 1。

原创 P4-03第 4.2 节 · 巩固

均方误差拆分

已知 E(X)=2,D(X)=3，求 E(X2)、D(3X+1)，并求使 E[(X−c)2] 最小的 c。

给我一点提示
提示 1

二阶矩等于方差加均值平方。

提示 2

方差中的倍数要平方。

提示 3

使用均方误差分解。

带我一步一步做

第 1 / 4 步

  1. E(X2)=3+22=7。

  2. D(3X+1)=9D(X)=27。

  3. E[(X−c)2]=3+(2−c)2。

  4. 平方项在 c=2 取 0，最小值为 3。

查看完整解答与检验

  1. E(X2)=3+22=7。

  2. D(3X+1)=9D(X)=27。

  3. E[(X−c)2]=3+(2−c)2。

  4. 平方项在 c=2 取 0，最小值为 3。

答案

7,27；c=2，最小均方误差 3。

检验与提醒

平移不改变波动大小；最优常数预测是均值。

原创 P4-04第 4.3 节 · 巩固

带协方差的方差

D(X)=4,D(Y)=9,ρXY=1/2，求 D(2X−Y)。

给我一点提示
提示 1

先将相关系数还原为协方差。

提示 2

交叉项的系数是 2ab。

提示 3

这里 a=2，b=−1。

带我一步一步做

第 1 / 4 步

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

  4. 代入得 16+9−12=13。

查看完整解答与检验

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

  4. 代入得 16+9−12=13。

答案

13。

检验与提醒

若遗漏协方差会得到 25；正相关使此处的差更稳定。

原创 P4-05第 4.4 节 · 巩固

正态线性组合

联合正态 X、Y 满足均值均为 0，方差均为 1，协方差为 0。求 U=X+Y、V=X−Y 的分布，并判断独立性。

给我一点提示
提示 1

线性组合仍正态。

提示 2

计算 U、V 的方差与协方差。

提示 3

联合正态下零协方差推出独立。

带我一步一步做

第 1 / 4 步

  1. U、V 的均值均为 0，且二者联合正态。

  2. D(U)=1+1=2，D(V)=1+1=2。

  3. Cov(U,V)=D(X)−D(Y)=0。

  4. 因此 U,V 独立，且各服从 N(0,2)。

查看完整解答与检验

  1. U、V 的均值均为 0，且二者联合正态。

  2. D(U)=1+1=2，D(V)=1+1=2。

  3. Cov(U,V)=D(X)−D(Y)=0。

  4. 因此 U,V 独立，且各服从 N(0,2)。

答案

独立的 N(0,2) 变量。

检验与提醒

正态前提用于最后一步，不可删去。

原创 P4-06第 4.5 节 · 巩固

均匀分布的分位数

X~U(2,10)，求中位数、四分位距及偏度。

给我一点提示
提示 1

在区间内部 F(x)=(x−2)/8。

提示 2

分别求 0.25、0.5、0.75 分位数。

提示 3

利用关于中点的对称性。

带我一步一步做

第 1 / 4 步

  1. qp=2+8p。

  2. q0.25=4,q0.5=6,q0.75=8。

  3. 四分位距为 8−4=4。

  4. 关于 6 对称且各阶矩有限，三阶中心矩为 0，故偏度为 0。

查看完整解答与检验

  1. qp=2+8p。

  2. q0.25=4,q0.5=6,q0.75=8。

  3. 四分位距为 8−4=4。

  4. 关于 6 对称且各阶矩有限，三阶中心矩为 0，故偏度为 0。

答案

中位数 6，四分位距 4，偏度 0。

检验与提醒

四分位距覆盖均匀区间的一半长度。

原创 P4-07第 4.1 节 · 提高

两组混合的总体方差

A、B 两组各占一半；条件于 A，X~Bernoulli(0.2)；条件于 B，X~Bernoulli(0.8)。求 E(X)、E[D(X∣G)]、D(E[X∣G]) 和 D(X)，并直接检验最后一个结果。

给我一点提示
提示 1

先写每组的均值和方差。

提示 2

组内方差按组别概率加权。

提示 3

组间方差以总体均值 0.5 为中心计算。

带我一步一步做

第 1 / 4 步

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

查看完整解答与检验

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

答案

E(X)=0.5，组内项 0.16，组间项 0.09，D(X)=0.25。

检验与提醒

若只取组内方差 0.16，就漏掉了两组成功率不同带来的波动。
