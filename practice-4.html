原创 P4-01第 4.1 节 · 巩固

同一期望，不同平方

X 以相等概率取 −2、0、2。求 E(X)、E(X²)，比较 E(X²) 与 [E(X)]²。

给我一点提示
提示 1

每个值的概率为 1/3。

提示 2

分别加权 X 和 X²。

提示 3

平方与取期望不能交换。

带我一步一步做

第 1 / 4 步

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

查看完整解答与检验

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

答案

E(X)=0, E(X2)=8/3。

检验与提醒

期望位于最小值和最大值之间，平方期望非负。

原创 P4-02第 4.1 节 · 巩固

随机配对的期望

把 6 张不同姓名卡随机发给 6 位对应的人，求拿到自己姓名卡的人数的期望。

给我一点提示
提示 1

给每个人设置一个 0–1 指示变量。

提示 2

每张卡落到某人的概率相同。

提示 3

线性性质不要求独立。

带我一步一步做

第 1 / 4 步

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

查看完整解答与检验

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

答案

E(N)=1。

检验与提醒

交换 6 为任意正整数，期望仍为 1。

原创 P4-04第 4.3 节 · 巩固

带协方差的方差

D(X)=4,D(Y)=9,ρXY=1/2，求 D(2X−Y)。

给我一点提示
提示 1

先将相关系数还原为协方差。

提示 2

交叉项的系数是 2ab。

提示 3

这里 a=2，b=−1。

带我一步一步做

第 1 / 4 步

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

查看完整解答与检验

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

  4. 代入得 16+9−12=13。

答案

13。

检验与提醒

若遗漏协方差会得到 25；正相关使此处的差更稳定。

独立的 N(0,2) 变量。

原创 P4-07第 4.1 节 · 提高

两组混合的总体方差

A、B 两组各占一半；条件于 A，X~Bernoulli(0.2)；条件于 B，X~Bernoulli(0.8)。求 E(X)、E[D(X∣G)]、D(E[X∣G]) 和 D(X)，并直接检验最后一个结果。

给我一点提示
提示 1

先写每组的均值和方差。

提示 2

组内方差按组别概率加权。

提示 3

组间方差以总体均值 0.5 为中心计算。

带我一步一步做

第 1 / 4 步

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

查看完整解答与检验

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

答案

E(X)=0.5，组内项 0.16，组间项 0.09，D(X)=0.25。

检验与提醒

若只取组内方差 0.16，就漏掉了两组成功率不同带来的波动。

原创 P4-08第 4.1 节 · 推导

同样均值，二阶与三阶矩未必相同

分别对 X∼b(5,0.4) 和 Y∼Poisson(2)，求二阶阶乘矩、二阶原点矩、方差及三阶原点矩。两者均值相同是否足以令这些数字特征相同？

给我一点提示
提示 1

先求 E[X(X−1)]，再加 E(X)。

提示 2

三阶原点矩用三阶下降阶乘加三倍二阶下降阶乘，再加一阶。

提示 3

方差还需要减去均值平方。

带我一步一步做

第 1 / 5 步

  1. 两变量均值都是 2。对二项，二阶阶乘矩为 5·4·0.42=3.2。

  2. E(X²)=3.2+2=5.2，方差为 5.2−4=1.2。

  3. 三阶阶乘矩为 5·4·3·0.43=3.84，所以 E(X³)=3.84+3×3.2+2=15.44。

  4. 对泊松，二阶阶乘矩为 2²=4，E(Y²)=6，方差为 2，E(Y³)=2³+3×2²+2=22。

  5. 均值只确定一阶矩；高阶矩和方差还依赖分布的其他结构，不能由同样均值推出。

查看完整解答与检验

  1. 两变量均值都是 2。对二项，二阶阶乘矩为 5·4·0.42=3.2。

  2. E(X²)=3.2+2=5.2，方差为 5.2−4=1.2。

  3. 三阶阶乘矩为 5·4·3·0.43=3.84，所以 E(X³)=3.84+3×3.2+2=15.44。

  4. 对泊松，二阶阶乘矩为 2²=4，E(Y²)=6，方差为 2，E(Y³)=2³+3×2²+2=22。

  5. 均值只确定一阶矩；高阶矩和方差还依赖分布的其他结构，不能由同样均值推出。

答案

二项：3.2、5.2、1.2、15.44；泊松：4、6、2、22，按题目顺序。

检验与提醒

也可直接将二项的六个概率加权求矩复核；泊松三阶中心矩为 2，与三阶原点矩 22 不同。

原创 P4-11第 4.5 节 · 辨析

零偏度却不对称，均值也不等于中位数

X在−2、−1、1、3处的概率依次为1/5、1/4、1/2、1/20。求均值、方差、偏度、峰度、中位数和众数，并用具体概率说明零偏度不保证分布对称。

给我一点提示
提示 1

先核查概率和1，再算原点一至四阶矩。

提示 2

若均值为0，原点矩同时是中心矩。

提示 3

有限均值的对称中心必须等于均值；比较−2和2处质量。

带我一步一步做

第 1 / 5 步

  1. 概率和1。EX=−2/5−1/4+1/2+3/20=0；EX²=4/5+1/4+1/2+9/20=2，所以方差2。

  2. EX³=−8/5−1/4+1/2+27/20=0；三阶中心矩也为0，偏度0。

  3. EX⁴=16/5+1/4+1/2+81/20=8，峰度8/2²=2，超额峰度−1。

  4. P(X<1)=.45而P(X≤1)=.95；中位数唯一为1。最大单点质量1/2也在1处，所以众数1。

  5. 分布若对称，其对称中心只能是均值0；但P(X=−2)=1/5、P(X=2)=0，不对称。可见零三阶中心矩只是矩的相消，不是整个分布的镜像条件。

查看完整解答与检验

  1. 概率和1。EX=−2/5−1/4+1/2+3/20=0；EX²=4/5+1/4+1/2+9/20=2，所以方差2。

  2. EX³=−8/5−1/4+1/2+27/20=0；三阶中心矩也为0，偏度0。

  3. EX⁴=16/5+1/4+1/2+81/20=8，峰度8/2²=2，超额峰度−1。

  4. P(X<1)=.45而P(X≤1)=.95；中位数唯一为1。最大单点质量1/2也在1处，所以众数1。

  5. 分布若对称，其对称中心只能是均值0；但P(X=−2)=1/5、P(X=2)=0，不对称。可见零三阶中心矩只是矩的相消，不是整个分布的镜像条件。

答案

均值0、方差2、偏度0、峰度2、超额峰度−1；唯一中位数1、众数1；分布不对称。

检验与提醒

对称且三阶绝对矩有限能推出零偏度；此处否定的是逆命题。

原创 P4-12第 4.1 节 · 辨析

混合分布的期望不能漏掉原子

U∼U(−2,2)，Z=max(0,U)。写出对任意非负可测g的E[g(Z)]，求EZ、EZ²、D(Z)、E[1_{Z=0}]。再解释为什么Z的分布函数导数积分只有1/2，却不能说明其概率总和少了一半。

原创 P4-14第 4.1 节 · 证明

零相关也可能提供有用的非线性预测

Y∼U(−1,1)，ε独立于Y且等概率取−1、1，令X=Y²+ε。求条件均值、条件方差、Cov(X,Y)。证明最佳平方可积预测为Y²，并比较其风险与最佳直线a+bY的风险。

给我一点提示
提示 1

已知Y后，只有ε仍然随机，均值0、方差1。

提示 2

需要EY²=1/3、EY³=0、EY⁴=1/5。

提示 3

对平方损失用条件均值正交分解；对直线再用Cov(X,Y)=0。

带我一步一步做

第 1 / 5 步

  1. E(X|Y)=Y²，D(X|Y)=1；EX=1/3，D(Y²)=1/5−1/9=4/45，故D(X)=49/45。

  2. EY=0，E(XY)=EY³+E(εY)=0，因此Cov(X,Y)=0，但条件均值随Y变化，X与Y不独立。

  3. 任意平方可积a(Y)都有L(a)=1+E[(Y²−a(Y))²]，由正交分解或直接对独立ε展开平方得到。最优规则为Y²，风险1，按Y的分布几乎处处唯一。

  4. 直线预测a+bY的风险为49/45+(a−1/3)²+b²/3，因为中心化交叉项为0。最优a=1/3、b=0，风险49/45。

  5. 非线性预测比最佳直线降低风险4/45；零相关只约束一次线性关系，无法排除Y²携带的信息。

查看完整解答与检验

  1. E(X|Y)=Y²，D(X|Y)=1；EX=1/3，D(Y²)=1/5−1/9=4/45，故D(X)=49/45。

  2. EY=0，E(XY)=EY³+E(εY)=0，因此Cov(X,Y)=0，但条件均值随Y变化，X与Y不独立。

  3. 任意平方可积a(Y)都有L(a)=1+E[(Y²−a(Y))²]，由正交分解或直接对独立ε展开平方得到。最优规则为Y²，风险1，按Y的分布几乎处处唯一。

  4. 直线预测a+bY的风险为49/45+(a−1/3)²+b²/3，因为中心化交叉项为0。最优a=1/3、b=0，风险49/45。

  5. 非线性预测比最佳直线降低风险4/45；零相关只约束一次线性关系，无法排除Y²携带的信息。

答案

条件均值Y²、条件方差1、协方差0；最佳一般预测风险1，最佳直线为常数1/3、风险49/45。

检验与提醒

逐个Y条件下，预测Y²的误差恰为ε，平方恒为1；这是最优风险的直接核验。

原创 P4-15第 4.4 节 · 推导

同一个四阶矩，减去的均值项不同

零均值二维正态X、Y的方差均1、相关系数1/2。求E(X²Y²)、Cov(X²,Y²)、D(XY)和E(X³Y)。再取标准正态Z与独立等概率符号S，令U=Z、V=SZ；解释为什么不能仅根据U、V边缘正态和零协方差重复前面的计算。

给我一点提示
提示 1

四阶矩分别用(X,X,Y,Y)和(X,X,X,Y)配对。

提示 2

D(XY)减(EXY)²；Cov(X²,Y²)减EX²EY²。

提示 3

反例中U²=V²=Z²，直接求E(U²V²)。

带我一步一步做

第 1 / 5 步

  1. c=EXY=1/2；配对得E(X²Y²)=1+2×(1/2)²=3/2。

  2. Cov(X²,Y²)=3/2−1×1=1/2。D(XY)=3/2−(1/2)²=5/4。

  3. E(X³Y)=3×1×(1/2)=3/2。所列四阶矩存在，由联合正态保证。

  4. 反例U、V各自标准正态，EUV=E(SZ²)=0，但E(U²V²)=EZ⁴=3。若误当联合正态会得到1。

  5. 由于U²=V²而Var(U²)=2>0，平方仍完全相同，故不独立；边缘正态不等于联合正态。

查看完整解答与检验

  1. c=EXY=1/2；配对得E(X²Y²)=1+2×(1/2)²=3/2。

  2. Cov(X²,Y²)=3/2−1×1=1/2。D(XY)=3/2−(1/2)²=5/4。

  3. E(X³Y)=3×1×(1/2)=3/2。所列四阶矩存在，由联合正态保证。

  4. 反例U、V各自标准正态，EUV=E(SZ²)=0，但E(U²V²)=EZ⁴=3。若误当联合正态会得到1。

  5. 由于U²=V²而Var(U²)=2>0，平方仍完全相同，故不独立；边缘正态不等于联合正态。

答案

3/2、1/2、5/4、3/2；符号反例的四阶乘积期望3，不能套联合正态公式。

检验与提醒

令X=Z₁、Y=Z₁/2+√3 Z₂/2，独立标准正态Z₁、Z₂，直接展开乘积也得到相同结果。
