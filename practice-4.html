原创 P4-01第 4.1 节 · 巩固

同一期望，不同平方

X 以相等概率取 −2、0、2。求 E(X)、E(X²)，比较 E(X²) 与 [E(X)]²。

给我一点提示
提示 1

每个值的概率为 1/3。

提示 2

分别加权 X 和 X²。

提示 3

平方与取期望不能交换。

带我一步一步做

第 1 / 4 步

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

查看完整解答与检验

  1. E(X)=(−2+0+2)/3=0。

  2. 平方取值为 4、0、4。

  3. E(X2)=(4+0+4)/3=8/3。

  4. [E(X)]2=0，两者不同。

答案

E(X)=0, E(X2)=8/3。

检验与提醒

期望位于最小值和最大值之间，平方期望非负。

原创 P4-02第 4.1 节 · 巩固

随机配对的期望

把 6 张不同姓名卡随机发给 6 位对应的人，求拿到自己姓名卡的人数的期望。

给我一点提示
提示 1

给每个人设置一个 0–1 指示变量。

提示 2

每张卡落到某人的概率相同。

提示 3

线性性质不要求独立。

带我一步一步做

第 1 / 4 步

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

查看完整解答与检验

  1. 令 Ii 表示第 i 人是否拿到自己的卡。

  2. P(Ii=1)=1/6，故 E(Ii)=1/6。

  3. 人数 N=I1+⋯+I6。

  4. E(N)=6×1/6=1。

答案

E(N)=1。

检验与提醒

交换 6 为任意正整数，期望仍为 1。

均方误差拆分

原创 P4-04第 4.3 节 · 巩固

带协方差的方差

D(X)=4,D(Y)=9,ρXY=1/2，求 D(2X−Y)。

给我一点提示
提示 1

先将相关系数还原为协方差。

提示 2

交叉项的系数是 2ab。

提示 3

这里 a=2，b=−1。

带我一步一步做

第 1 / 4 步

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

  4. 代入得 16+9−12=13。

查看完整解答与检验

  1. σX=2,σY=3。

  2. Cov(X,Y)=(1/2)×2×3=3。

  3. D(2X−Y)=4D(X)+D(Y)−4Cov(X,Y)。

  4. 代入得 16+9−12=13。

答案

13。

检验与提醒

若遗漏协方差会得到 25；正相关使此处的差更稳定。

正态线性组合

  3. Cov(U,V)=D(X)−D(Y)=0。

独立的 N(0,2) 变量。

检验与提醒

正态前提用于最后一步，不可删去。

原创 P4-07第 4.1 节 · 提高

两组混合的总体方差

A、B 两组各占一半；条件于 A，X~Bernoulli(0.2)；条件于 B，X~Bernoulli(0.8)。求 E(X)、E[D(X∣G)]、D(E[X∣G]) 和 D(X)，并直接检验最后一个结果。

给我一点提示
提示 1

先写每组的均值和方差。

提示 2

组内方差按组别概率加权。

提示 3

组间方差以总体均值 0.5 为中心计算。

带我一步一步做

第 1 / 4 步

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

查看完整解答与检验

  1. 两组条件均值分别是 0.2、0.8，因此 E(X)=0.5(0.2)+0.5(0.8)=0.5。

  2. 两组条件方差均为 0.2×0.8=0.16，故 E[D(X∣G)]=0.16。

  3. 组间均值方差为 0.5(0.2−0.5)2+0.5(0.8−0.5)2=0.09。

  4. 由全方差公式，D(X)=0.16+0.09=0.25；直接计算总体成功率为 0.5，故 X~Bernoulli(0.5)，其方差也是 0.25。

答案

E(X)=0.5，组内项 0.16，组间项 0.09，D(X)=0.25。

检验与提醒

若只取组内方差 0.16，就漏掉了两组成功率不同带来的波动。

原创 P4-08第 4.1 节 · 推导

同样均值，二阶与三阶矩未必相同

分别对 X∼b(5,0.4) 和 Y∼Poisson(2)，求二阶阶乘矩、二阶原点矩、方差及三阶原点矩。两者均值相同是否足以令这些数字特征相同？

给我一点提示
提示 1

先求 E[X(X−1)]，再加 E(X)。

提示 2

三阶原点矩用三阶下降阶乘加三倍二阶下降阶乘，再加一阶。

提示 3

方差还需要减去均值平方。

带我一步一步做

第 1 / 5 步

  1. 两变量均值都是 2。对二项，二阶阶乘矩为 5·4·0.42=3.2。

  2. E(X²)=3.2+2=5.2，方差为 5.2−4=1.2。

  3. 三阶阶乘矩为 5·4·3·0.43=3.84，所以 E(X³)=3.84+3×3.2+2=15.44。

  4. 对泊松，二阶阶乘矩为 2²=4，E(Y²)=6，方差为 2，E(Y³)=2³+3×2²+2=22。

  5. 均值只确定一阶矩；高阶矩和方差还依赖分布的其他结构，不能由同样均值推出。

查看完整解答与检验

  1. 两变量均值都是 2。对二项，二阶阶乘矩为 5·4·0.42=3.2。

  2. E(X²)=3.2+2=5.2，方差为 5.2−4=1.2。

  3. 三阶阶乘矩为 5·4·3·0.43=3.84，所以 E(X³)=3.84+3×3.2+2=15.44。

  4. 对泊松，二阶阶乘矩为 2²=4，E(Y²)=6，方差为 2，E(Y³)=2³+3×2²+2=22。

  5. 均值只确定一阶矩；高阶矩和方差还依赖分布的其他结构，不能由同样均值推出。

答案

二项：3.2、5.2、1.2、15.44；泊松：4、6、2、22，按题目顺序。

检验与提醒

也可直接将二项的六个概率加权求矩复核；泊松三阶中心矩为 2，与三阶原点矩 22 不同。

原创 P4-10第 4.5 节 · 辨析

同一分布的两种最佳常数

提示 1

在每个跳点同时检查 F(m−) 与 F(m)。

平方损失在均值最小，绝对损失在中位数最小。

第 1 / 5 步

  1. CDF 在 0、2、5 处依次达到 0.4、0.6、1；只有 m=2 满足两侧概率各至少 1/2，因此中位数唯一为 2。

  2. 均值为 0×0.4+2×0.2+5×0.4=2.4。

  3. 绝对损失在 m=2 为 0.8+0+1.2=2；在 m=2.4 为 0.96+0.08+1.04=2.08。

  4. 平方损失在 c=2 为 1.6+0+3.6=5.2；在 c=2.4 为 2.304+0.032+2.704=5.04。

  5. 两种损失对偏离距离的惩罚不同，故其最小点由不同数字特征刻画。此例绝对损失在中位数 2 最小，平方损失在均值 2.4 最小。

m=2 处左右导数为 −0.2、0.2，g 在此不可微但达到最小；不能要求导数必须等于零。

原创 P4-11第 4.5 节 · 辨析

零偏度却不对称，均值也不等于中位数

X在−2、−1、1、3处的概率依次为1/5、1/4、1/2、1/20。求均值、方差、偏度、峰度、中位数和众数，并用具体概率说明零偏度不保证分布对称。

给我一点提示
提示 1

先核查概率和1，再算原点一至四阶矩。

提示 2

若均值为0，原点矩同时是中心矩。

提示 3

有限均值的对称中心必须等于均值；比较−2和2处质量。

带我一步一步做

第 1 / 5 步

  1. 概率和1。EX=−2/5−1/4+1/2+3/20=0；EX²=4/5+1/4+1/2+9/20=2，所以方差2。

  2. EX³=−8/5−1/4+1/2+27/20=0；三阶中心矩也为0，偏度0。

  3. EX⁴=16/5+1/4+1/2+81/20=8，峰度8/2²=2，超额峰度−1。

  4. P(X<1)=.45而P(X≤1)=.95；中位数唯一为1。最大单点质量1/2也在1处，所以众数1。

  5. 分布若对称，其对称中心只能是均值0；但P(X=−2)=1/5、P(X=2)=0，不对称。可见零三阶中心矩只是矩的相消，不是整个分布的镜像条件。

查看完整解答与检验

  1. 概率和1。EX=−2/5−1/4+1/2+3/20=0；EX²=4/5+1/4+1/2+9/20=2，所以方差2。

  2. EX³=−8/5−1/4+1/2+27/20=0；三阶中心矩也为0，偏度0。

  3. EX⁴=16/5+1/4+1/2+81/20=8，峰度8/2²=2，超额峰度−1。

  4. P(X<1)=.45而P(X≤1)=.95；中位数唯一为1。最大单点质量1/2也在1处，所以众数1。

  5. 分布若对称，其对称中心只能是均值0；但P(X=−2)=1/5、P(X=2)=0，不对称。可见零三阶中心矩只是矩的相消，不是整个分布的镜像条件。

答案

均值0、方差2、偏度0、峰度2、超额峰度−1；唯一中位数1、众数1；分布不对称。

检验与提醒

对称且三阶绝对矩有限能推出零偏度；此处否定的是逆命题。

最佳直线、非线性规则与残差正交

X在−1、0、1处概率为1/5、3/5、1/5，η独立于X且等概率取±1。令Y=2+3X+X²+η。求最佳常数、最佳直线、最佳可测规则的均方误差，求ρ²，并判断直线残差是否与X独立。

给我一点提示
提示 1

先求EX²、EX³、EX⁴，再利用独立噪声的均值0、方差1。

提示 2

直线系数用Cov(X,Y)/Var(X)，非线性最优用E(Y|X)。

提示 3

若残差独立于X且均值0，它与X²的乘积期望也必须为0。

带我一步一步做

第 1 / 6 步

  1. EX=0，EX²=EX⁴=2/5，EX³=0；因此EY=12/5、Var(X²)=6/25。

  2. Cov(X,Y)=3Var(X)=6/5。3X与X²不相关，故Var(Y)=9×2/5+6/25+1=121/25。

  3. 最佳常数为12/5，误差121/25。最佳直线斜率3、截距12/5，误差121/25−(6/5)²/(2/5)=31/25。

  4. ρ²=(6/5)²/[(2/5)(121/25)]=90/121，代回Var(Y)(1−ρ²)也得31/25。

  5. 给定X后η仍均值0，所以E(Y|X)=2+3X+X²，最佳可测规则误差为Var(η)=1，严格小于31/25。

  6. 直线残差ε=X²−2/5+η有Eε=E(εX)=0；但E(εX²)=Var(X²)=6/25。它不与X独立，也不满足条件均值为0。

查看完整解答与检验

  1. EX=0，EX²=EX⁴=2/5，EX³=0；因此EY=12/5、Var(X²)=6/25。

  2. Cov(X,Y)=3Var(X)=6/5。3X与X²不相关，故Var(Y)=9×2/5+6/25+1=121/25。

  3. 最佳常数为12/5，误差121/25。最佳直线斜率3、截距12/5，误差121/25−(6/5)²/(2/5)=31/25。

  4. ρ²=(6/5)²/[(2/5)(121/25)]=90/121，代回Var(Y)(1−ρ²)也得31/25。

  5. 给定X后η仍均值0，所以E(Y|X)=2+3X+X²，最佳可测规则误差为Var(η)=1，严格小于31/25。

  6. 直线残差ε=X²−2/5+η有Eε=E(εX)=0；但E(εX²)=Var(X²)=6/25。它不与X独立，也不满足条件均值为0。

答案

三种最小误差依次121/25、31/25、1；最佳直线12/5+3X，ρ²=90/121；直线残差与X不独立。

检验与提醒

各误差对应不同的规则集合；不能将总体最佳直线的误差，误说成已经在所有非线性规则中最小。

原创 P4-22第 4.5 节 · 推导

单位换算和平移对变异系数的影响

总体X等概率取1、3，定义Y=10X、Z=X+8。求三个总体的均值、标准差、变异系数CV=σ/μ、偏度和峰度。Z的CV较小，是否说明它的绝对波动较小？

给我一点提示
提示 1

先算X的均值和中心化取值±1。

提示 2

正比例缩放使均值和标准差同比例变，平移仅改变均值。

提示 3

标准化后的两点仍为±1，故三、四阶标准化矩很简单。

带我一步一步做

第 1 / 5 步

  1. X均值2、方差1、标准差1，所以CV_X=1/2。

  2. Y均值20、标准差10，CV_Y=10/20=1/2；正比例换单位不变。

  3. Z均值10、标准差1，CV_Z=1/10；平移后的CV改变。

  4. 三者的标准化变量都等概率取±1，所以偏度均0、未减3的峰度均1，超额峰度均−2。

  5. X和Z的标准差同为1，绝对波动相同；Z的CV较小反映分母均值改变，不能替代绝对波动的比较。

查看完整解答与检验

  1. X均值2、方差1、标准差1，所以CV_X=1/2。

  2. Y均值20、标准差10，CV_Y=10/20=1/2；正比例换单位不变。

  3. Z均值10、标准差1，CV_Z=1/10；平移后的CV改变。

  4. 三者的标准化变量都等概率取±1，所以偏度均0、未减3的峰度均1，超额峰度均−2。

  5. X和Z的标准差同为1，绝对波动相同；Z的CV较小反映分母均值改变，不能替代绝对波动的比较。

答案

(均值,标准差,CV)：X为(2,1,1/2)，Y为(20,10,1/2)，Z为(10,1,1/10)；偏度均0、峰度均1。X与Z绝对波动相同。

检验与提醒

CV只对约定的正均值使用；标准差和CV分别描述绝对、相对波动，单位和自然零点改变时应说明比较基准。
