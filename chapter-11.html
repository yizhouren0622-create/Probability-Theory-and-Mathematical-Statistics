11.1R basics理解后再记忆

R 数据对象、缺失值与可重复计算

先用一句话理解

先核对输入是什么，再解释软件算出的数字。

R 中向量保存同类元素，data.frame 按列保存变量，factor 表示分类水平，NA 表示缺失。mean 求均值，var 与 sd 使用分母 n−1 的样本方差和标准差。set.seed 控制伪随机流的起点；记录 R 版本、包版本、数据与代码比仅记录一个种子更完整。

示例代码（教学代码，未在本页宣称已运行）：

x <- c(2, 4, NA, 6)
ok <- !is.na(x)
c(n = sum(ok), mean = mean(x[ok]), variance = var(x[ok]))
set.seed(2026)
sample.int(3, size = 3, replace = TRUE)
sessionInfo()

直接删除缺失值是计算选择，也需要统计上解释缺失机制；它不自动消除偏差。

s2=1n−1∑i=1n(xi−x¯)2
使用条件

方差至少要两个有效观测；样本数量应按有效值而非原向量长度计算。种子可复现的前提还包括兼容的算法版本和相同调用顺序。

方法依据 / 软件参数说明

将离差平方和展开得到 ∑(xi−x¯)2=∑xi2−nx¯2。在 iid 有限方差模型下，期望为 n(σ2+μ2)−n(σ2/n+μ2)=(n−1)σ2，因此分母 n−1 给出总体方差的无偏估计。这也解释 var 为何不使用经验分布方差的分母 n。

做一道简单例题

有效数据 (2,4,6) 的均值为 4，样本方差为 4；将 NA 当作 0 会改变数据含义和计算结果。

容易出错的地方

sample(x) 默认不放回；对长度为 1 的正整数 x，sample 有抽取 1:x 的特殊行为。使用 sample.int(length(x),...) 抽索引更明确。

11.2Box plots理解后再记忆

箱线图：铰链、须与潜在离群点

先用一句话理解

箱体概括中间一半数据；须和散点帮助发现尾部与异常。

箱线图以中位数和上下铰链概括位置与离散程度；默认须延至距箱体端点不超过 1.5 倍箱宽的最远实际观测，超出者画成散点。R 的 boxplot.stats 使用 Tukey 风格铰链，小样本时不保证与默认 quantile 算出的四分位数完全一致。离群标记是探索线索，不是自动删点规则。

x <- c(1, 2, 3, 4, 20)
boxplot(x, horizontal = TRUE)
boxplot.stats(x)$stats
boxplot.stats(x)$out
下围栏=QL−1.5(QU−QL),上围栏=QU+1.5(QU−QL)
使用条件

这里 QL、QU 指绘图实际使用的上下铰链。比较组间箱线图时还需查看样本量；箱体重叠与否不直接等于显著性检验结论。

方法依据 / 软件参数说明

对严格正的线性变换 y=a+bx,b>0，所有次序统计量及其平均形成的铰链都变为 a+bQ，箱宽乘 b，围栏也作同样变换；因此哪些观测越界保持不变。可见箱线图标记对改变原点和正比例单位不变。但非线性变换会改变相对间距，可能改变标记。

做一道简单例题

数据 (1,2,3,4,20) 的铰链为 2 与 4，中位数 3，箱宽 2，上围栏 7。上须止于 4，20 单独标记；上须不是直接画到 7。

容易出错的地方

围栏是阈值，须端通常是某个实际观测；潜在离群点既可能是错误，也可能是真实且有价值的结果。

SECTION 11.3

假设检验

t.test 的默认值与检验设计
11.3R hypothesis tests理解后再记忆

t.test 的默认值与检验设计

先用一句话理解

软件函数同名，独立样本、配对样本与等方差设定却对应不同模型。

t.test(x, mu=...) 是单总体均值检验；t.test(x,y) 默认双侧 Welch 两独立样本检验，并不默认合并方差。paired=TRUE 对差值执行单样本 t 检验；var.equal=TRUE 才使用两组共同方差估计。alternative="greater" 对两样本表示 x 的总体均值较大。

x <- c(7, 8, 10, 11, 14)
y <- c(6, 9, 9, 10, 12)
t.test(x, y)                 # 独立样本 Welch
t.test(x, y, paired = TRUE)  # 仅当逐项确为配对观测

以上两行展示不同设计的语法，不表示同一数据应任选较小的 p 值。

TWelch=X¯−Y¯−Δ0SX2/nX+SY2/nY
使用条件

选择检验前确定抽样设计与单双侧假设。Welch 的 t 自由度为近似值；配对要求每一对有实际对应，且不同对之间独立。

方法依据 / 软件参数说明

独立样本下均值差方差为 σX2/nX+σY2/nY，以两组样本方差代替得到 Welch 分母，其自由度用 Satterthwaite 近似。配对时令 Di=Xi−Yi，则 Var(D)=σX2+σY2−2Cov(X,Y)，应由差值样本方差估计；忽略协方差将得到不同标准误。若差值 iid 正态，则 (D¯−Δ0)/(SD/n) 精确服从 t(n−1)。

做一道简单例题

上面示例差值为 (1,−1,1,1,2)，均值为 0.8；配对模型只分析这五个差值。两向量长度相同本身不足以证明配对成立。

容易出错的地方

p 值不是“原假设为真的概率”；未拒绝也不等于证明两个总体相同。

SECTION 11.4

方差分析

在 R 中表达因素、主效应与交互
11.4ANOVA in R理解后再记忆

在 R 中表达因素、主效应与交互

先用一句话理解

公式写法决定模型空间，分类变量必须明确编码。

aov(y ~ A, data=d) 拟合单因素模型；A+B 仅主效应，A*B 展开为 A+B+A:B，包含交互。分类水平若用数字录入，应显式转为 factor。aov 基于线性模型；平衡设计的正交解释最清楚。非平衡设计中的顺序平方和可能随公式项顺序变化，不能把任意输出都当成唯一的“因素贡献”。

d <- data.frame(y = c(1,2,3,4,5,6),
                A = factor(rep(c("低", "高"), each = 3)))
fit <- aov(y ~ A, data = d)
summary(fit)
plot(fitted(fit), residuals(fit))
F 值=因素平方和/因素自由度残差平方和/残差自由度
使用条件

示例只提供可审阅代码，未声称在当前环境运行 R。残差图用于发现问题，不能证明独立、正态或等方差；独立性首先来自实验设计。

方法依据 / 软件参数说明

a 水平因素在含截距模型中需要 a−1 个独立对比列；与截距共同张成“每组均值可独立变化”的 a 维空间。所以把数字 1、2、3 当一个数值预测量，只增加一维线性趋势，不能表示三个任意组均值。A*B 增加的交互空间有 (a−1)(b−1) 维，平衡设计时与主效应空间正交，对应第九章的平方和分解。

做一道简单例题

三个剂量水平 1、2、3 若目标是任意组均值比较，用 factor；若目标明确是每单位剂量的线性趋势，可用数值变量。两者回答的问题不同。

容易出错的地方

每格只有一次观测却拟合 A*B，残差自由度可能为 0；不能依靠更换函数名解决设计缺少重复的问题。

SECTION 11.5

线性回归

lm、残差诊断与 predict 的区间类型
11.5Regression in R理解后再记忆

lm、残差诊断与 predict 的区间类型

先用一句话理解

拟合、诊断、区间预测应围绕同一个统计模型进行。

lm(y ~ x1 + x2, data=d) 拟合含截距的加性回归。coef 提取系数，residuals 提取残差，summary 提供模型依赖的标准误与检验。predict(...,interval="confidence") 为条件均值区间，interval="prediction" 为新观测预测区间。

d <- data.frame(x = 0:2, y = c(1,2,2))
fit <- lm(y ~ x, data = d)
coef(fit)
predict(fit, newdata = data.frame(x = 1), interval = "confidence")
predict(fit, newdata = data.frame(x = 1), interval = "prediction")

应检查残差与拟合值关系、异常影响点、设计范围；不能因输出了 p 值便认为模型成立。

m^(x0)±t1−α/2,n−psx0T(XTX)−1x0
使用条件

此 x0 为含截距分量的列向量。区间公式要求满秩设计及正态同方差独立误差；新个体预测还加一个独立误差方差。

方法依据 / 软件参数说明

m^(x0)=x0Tβ^，由协方差矩阵得到 Var(m^)=σ2x0T(XTX)−1x0。新观测 Y0=x0Tβ+ε0 与估计误差独立，因此 Y0−m^ 的方差再增加 σ2。这从数学上解释了 predict 两种 interval 选项的宽度差异。

做一道简单例题

当 x=1 为样本中心时，均值区间围绕预测均值 5/3；新个体区间中心相同，但比均值区间更宽。

容易出错的地方

训练集拟合好不保证新数据预测好；若新数据因子出现训练集中没有的水平，也不能假装其系数已被估计。

用索引重抽样，实现可核对的 bootstrap
11.6Bootstrap in R理解后再记忆

用索引重抽样，实现可核对的 bootstrap

先用一句话理解

每次重抽样必须重复同一套统计量计算流程，不能只复制最终数字。

boot::boot 的普通非参数模式常将数据与重抽样索引传给统计函数；也可用基础 R 写出索引抽样。多列数据应整行抽样以保留观测内配对关系。

x <- c(1, 3, 5, 7)
set.seed(2026)
B <- 2000
tb <- replicate(B, {
  ix <- sample.int(length(x), length(x), replace = TRUE)
  mean(x[ix])
})
c(boot_mean = mean(tb), boot_se = sd(tb))
quantile(tb, c(0.025, 0.975))
# 包版本的等价统计函数：
# boot::boot(x, statistic = function(d, i) mean(d[i]), R = B)

末行分位数为百分位区间示例，不自动保证准确的 95% 覆盖率。以上代码尚未在本任务环境执行 R。

Var*(X¯*)=1n2∑i(xi−x¯)2
使用条件

本代码用于 iid 数据均值标准误估计，不是原假设检验代码。模拟次数 B 应与精度目标相称，并报告种子、样本量和失败重抽样情况。

方法依据 / 软件参数说明

给定数据，索引 I1,…,In 独立均匀取自 1 到 n，因此 Xj*=xIj 的分布恰为经验分布。均值条件方差用独立性相加并除以 n2，得上式。数据 (1,3,5,7) 的均值为 4、离差平方和 20，因此 bootstrap 均值条件方差为 20/16=1.25；大量模拟的标准差应趋近 1.25。

做一道简单例题

模拟得到的 boot_se 不要求精确等于 1.25；有限 B 有随机误差。若误写 replace=FALSE，所有 tb 都为 4，标准误错误地变为 0。

容易出错的地方

回归的“抽行 pairs bootstrap”与固定设计下“抽残差 residual bootstrap”依赖不同模型；不能混淆。
