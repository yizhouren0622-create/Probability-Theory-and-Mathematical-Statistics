原创 P10-01第 10.1 节 · 进阶

枚举重抽样分布

原样本 (1,3)，每次有放回抽 2 个。列出 bootstrap 均值分布，并求条件均值和方差。

给我一点提示
提示 1

将重抽样视为两个独立位置。

提示 2

四个有序样本等可能。

提示 3

重复的统计量取值需合并。

带我一步一步做

第 1 / 4 步

  1. 四个样本是 (1,1),(1,3),(3,1),(3,3)。

  2. 均值分别为 1,2,2,3。

  3. 均值分布为 1、2、3 对应概率 1/4、1/2、1/4，条件期望为 2。

  4. 方差为 (1−2)2/4+(3−2)2/4=1/2。

查看完整解答与检验

  1. 四个样本是 (1,1),(1,3),(3,1),(3,3)。

  2. 均值分别为 1,2,2,3。

  3. 均值分布为 1、2、3 对应概率 1/4、1/2、1/4，条件期望为 2。

  4. 方差为 (1−2)2/4+(3−2)2/4=1/2。

答案

均值分布 (1,2,3) 对应 (1/4,1/2,1/4)，期望 2、方差 1/2。

检验与提醒

条件均值应等于原样本均值。

原创 P10-02第 10.2 节 · 进阶

参数 bootstrap 的条件方差

独立指数分布样本以均值参数 θ 表示，n=16，θ^=X¯=2。从均值 2 的指数分布做参数 bootstrap，求重抽样均值条件方差和标准差。

给我一点提示
提示 1

均值参数 θ 的指数分布方差是 θ²。

提示 2

重抽样中 θ 暂固定为估计值。

提示 3

n 个独立值的均值方差需除以 n。

带我一步一步做

第 1 / 4 步

  1. 拟合模型中单个重抽样值均值为 2。

  2. 单个值方差为 22=4。

  3. 重抽样均值方差为 4/16=1/4。

  4. 条件标准差为 1/2，不是单个观测的标准差 2。

查看完整解答与检验

  1. 拟合模型中单个重抽样值均值为 2。

  2. 单个值方差为 22=4。

  3. 重抽样均值方差为 4/16=1/4。

  4. 条件标准差为 1/2，不是单个观测的标准差 2。

答案

方差 1/4，标准差 1/2。

检验与提醒

在固定拟合参数下，n 扩大四倍，均值标准差应减半。

原创 P10-03第 10.3 节 · 进阶

构造零假设重抽样

原样本 (3,4,5)，检验均值等于 2。写出中心化到零假设的数据；若 999 次模拟有 24 次绝对统计量不小于观测值，求加一修正比例。

给我一点提示
提示 1

原样本均值为 4。

提示 2

每个观测减 4 加 2。

提示 3

分子与分母都要加 1。

带我一步一步做

第 1 / 4 步

  1. 原样本均值为 4。

  2. 零假设重抽样数据为 (1,2,3)，均值为 2。

  3. 每次从这三个值有放回抽 3 个，并按与原数据相同规则重新计算统计量。

  4. 修正尾部比例为 (24+1)/(999+1)=0.025。

查看完整解答与检验

  1. 原样本均值为 4。

  2. 零假设重抽样数据为 (1,2,3)，均值为 2。

  3. 每次从这三个值有放回抽 3 个，并按与原数据相同规则重新计算统计量。

  4. 修正尾部比例为 (24+1)/(999+1)=0.025。

答案

零假设数据 (1,2,3)，修正比例 0.025。

检验与提醒

本题样本很小，学生化重抽样可能出现零方差；这个比例只作计数示例，实际检验需处理退化。

原创 P10-04第 10.1 节 · 进阶

两种 bootstrap 区间为何不同

原估计 θ^=10，八个重抽样估计排序为 (8,9,9,10,11,12,12,13)。用经验逆 CDF 分位数 qu*=inf{t:FB*(t)≥u}，分别计算名义 50% 的百分位区间与基本区间，并说明端点为何反向。

给我一点提示
提示 1

50% 中央区间使用 25% 与 75% 分位数。

提示 2

经验逆 CDF 下，八个数的第 2、6 个顺序统计量分别对应这两个分位数。

提示 3

基本区间反解 θ^−θ 的误差。

带我一步一步做

第 1 / 4 步

  1. 按定义读出 q.25*=9，q.75*=12。

  2. 百分位区间直接取 [9,12]。

  3. 基本区间取 [2(10)−12,2(10)−9]=[8,11]。

  4. 由于 θ=θ^−e，误差上分位数对应参数下界；有限 B=8 的示例不意味着实际覆盖率精确为 50%。

查看完整解答与检验

  1. 按定义读出 q.25*=9，q.75*=12。

  2. 百分位区间直接取 [9,12]。

  3. 基本区间取 [2(10)−12,2(10)−9]=[8,11]。

  4. 由于 θ=θ^−e，误差上分位数对应参数下界；有限 B=8 的示例不意味着实际覆盖率精确为 50%。

答案

百分位区间 [9,12]；基本区间 [8,11]。

检验与提醒

基本区间左右端点都等于 20 减去百分位区间的相反端点。

原创 P10-05第 10.1 节 · 辨析

数清最大值重抽样的原子

观测为 (0.2,0.5,0.8)，从三个位置等概率有放回抽 3 次。精确求重抽样最大值 M 的分布；说明对未知 U(0,θ) 的上端点，直接用这些 M 的分位数构造百分位区间为什么失败。

给我一点提示
提示 1

按最大值最多落在前几个位置计数。

提示 2

最大值的 CDF 为“每次都不超过该值”的概率。

提示 3

原最大值小于真实上端点，几乎必然成立。

带我一步一步做

第 1 / 5 步

  1. 最大值为 0.2 时三个位置都选第一个，概率 1/27。

  2. 不超过 0.5 的概率为 (2/3)³=8/27，因此恰为 0.5 的概率为 7/27。

  3. 最大值为 0.8 的概率为 1−8/27=19/27；三项相加为 1。

  4. 任何 M* 分位数都≤0.8，所以相应百分位区间的上端点≤原最大值。

  5. 在真正的连续 U(0,θ) 重复抽样下，原最大值始终小于 θ（几乎必然），所以这种百分位区间的频率学覆盖率是 0；不是仅仅“略有低估”。

查看完整解答与检验

  1. 最大值为 0.2 时三个位置都选第一个，概率 1/27。

  2. 不超过 0.5 的概率为 (2/3)³=8/27，因此恰为 0.5 的概率为 7/27。

  3. 最大值为 0.8 的概率为 1−8/27=19/27；三项相加为 1。

  4. 任何 M* 分位数都≤0.8，所以相应百分位区间的上端点≤原最大值。

  5. 在真正的连续 U(0,θ) 重复抽样下，原最大值始终小于 θ（几乎必然），所以这种百分位区间的频率学覆盖率是 0；不是仅仅“略有低估”。

答案

M* 在 0.2、0.5、0.8 的概率分别为 1/27、7/27、19/27；直接百分位端点区间的覆盖率为 0。

检验与提醒

穷举 27 个有序重抽样即可复核分布；将 B 调大不会扩展经验分布的支撑。

原创 P10-06第 10.1 节 · 证明

27次完整枚举背后的权重和两种偏差

原样本为(1,2,5)，普通bootstrap每次有放回抽3个观测。求标签计数(2,1,0)的概率、两个不同标签计数的协方差、重抽样均值的条件均值和方差。若统计量为 n−1 分母的样本方差S²，求 ES²−S²，并说明这是否等于真实总体偏差。

给我一点提示
提示 1

每个有序标签序列概率1/27，计数(2,1,0)对应3种排列。

提示 2

原均值8/3、S²=13/3，使用均值条件方差公式。

提示 3

原始S²无偏，但经验总体的方差并不等于原S²。

带我一步一步做

第 1 / 5 步

  1. P*(W=(2,1,0))=3!/(2!1!0!)×3⁻³=1/9。不同标签计数的协方差为−1/n=−1/3，不是0，因为计数总和固定。

  2. 原均值8/3，离差平方和26/3，原S²=(26/3)/2=13/3。EX̄=8/3，VarX̄=(26/3)/9=26/27。

  3. 经验总体方差为 (26/3)/3=26/9。S²在这个经验总体下无偏，所以 ES*²=26/9。

  4. 常用bootstrap偏差差值为26/9−13/3=−13/9。但原S²在真实iid总体中已无偏，真实偏差0，所以两者不能视作有限样本精确相等。

  5. 若机械减去差值，得到52/9；一般n下该修正是(1+1/n)S²，其原始抽样偏差为σ²/n。更多B只会更精确地估计这个经验模型差值，不会将其自动变为真实偏差。

查看完整解答与检验

  1. P*(W=(2,1,0))=3!/(2!1!0!)×3⁻³=1/9。不同标签计数的协方差为−1/n=−1/3，不是0，因为计数总和固定。

  2. 原均值8/3，离差平方和26/3，原S²=(26/3)/2=13/3。EX̄=8/3，VarX̄=(26/3)/9=26/27。

  3. 经验总体方差为 (26/3)/3=26/9。S²在这个经验总体下无偏，所以 ES*²=26/9。

  4. 常用bootstrap偏差差值为26/9−13/3=−13/9。但原S²在真实iid总体中已无偏，真实偏差0，所以两者不能视作有限样本精确相等。

  5. 若机械减去差值，得到52/9；一般n下该修正是(1+1/n)S²，其原始抽样偏差为σ²/n。更多B只会更精确地估计这个经验模型差值，不会将其自动变为真实偏差。

答案

计数概率1/9，协方差−1/3；均值条件均值8/3、方差26/27；方差统计量的bootstrap差值−13/9，真实总体偏差0。

检验与提醒

同一次重抽样的标签计数相关，跨次模拟可以独立；理想条件分布与有限B模拟、与未知总体抽样分布都需区分。
