原创 P8-01第 8.1 节 · 巩固

辨别两类错误

检验新工艺的均值是否超过旧标准 μ₀，设 H₀:μ≤μ₀，H₁:μ>μ₀。解释两类错误，说明功效 0.8 对应什么。

给我一点提示
提示 1

第一类错误是假阳性结论。

提示 2

第二类错误针对具体备择值。

提示 3

功效为 1−β。

带我一步一步做

第 1 / 4 步

  1. 第一类：真实均值不超过标准，却判定有超过标准的证据。

  2. 第二类：真实均值超过标准，却未能拒绝 H₀。

  3. 某个 μ₁>μ₀ 下功效 0.8 表示以 80% 概率检出该提升。

  4. 同一 μ₁ 下 β=0.2；其他备择值的功效可以不同。

查看完整解答与检验

  1. 第一类：真实均值不超过标准，却判定有超过标准的证据。

  2. 第二类：真实均值超过标准，却未能拒绝 H₀。

  3. 某个 μ₁>μ₀ 下功效 0.8 表示以 80% 概率检出该提升。

  4. 同一 μ₁ 下 β=0.2；其他备择值的功效可以不同。

答案

功效 0.8 对应指定备择下第二类错误率 0.2。

检验与提醒

不能把功效解释为结论正确的后验概率。

原创 P8-02第 8.2 节 · 巩固

一次 t 检验

正态总体方差未知，n=25、均值 5.6、s=1.5。检验 H₀:μ=5 对 H₁:μ≠5，α=0.05，给定 t₀.₉₇₅,₂₄=2.064。

给我一点提示
提示 1

标准误为 1.5/5。

提示 2

双侧比较绝对 t 值。

提示 3

严格区分未拒绝与接受为真。

带我一步一步做

第 1 / 4 步

  1. 标准误为 0.3。

  2. t=(5.6−5)/0.3=2。

  3. 自由度为 24，双侧临界值 2.064。

  4. 2<2.064，因此在 5% 水平未拒绝 H₀。

查看完整解答与检验

  1. 标准误为 0.3。

  2. t=(5.6−5)/0.3=2。

  3. 自由度为 24，双侧临界值 2.064。

  4. 2<2.064，因此在 5% 水平未拒绝 H₀。

答案

未拒绝 H0。

检验与提醒

同一数据若误用 1.96 会改变结论，表明分布选择有实际影响。

原创 P8-03第 8.2 节 · 巩固

配对后的差值检验

5 位对象前后差值为 1、2、3、4、5。假设差值独立正态，检验均值差是否为 0，写出 t 值和自由度。

给我一点提示
提示 1

只对 5 个差值做一组统计。

提示 2

差值均值为 3。

提示 3

差值样本方差分母为 4。

带我一步一步做

第 1 / 4 步

  1. 差值均值为 3。

  2. 平方离差和 4+1+0+1+4=10，故 sD2=10/4=2.5。

  3. 标准误为 2.5/5=0.5。

  4. t=3/0.5=32≈4.243，自由度 4。

查看完整解答与检验

  1. 差值均值为 3。

  2. 平方离差和 4+1+0+1+4=10，故 sD2=10/4=2.5。

  3. 标准误为 2.5/5=0.5。

  4. t=3/0.5=32≈4.243，自由度 4。

答案

t≈4.243, ν=4。

检验与提醒

样本容量是配对数 5，不是把前后数据加成 10。

原创 P8-04第 8.3 节 · 巩固

单侧方差检验

正态样本 n=11，s²=3。检验 H₀:σ²≤2 对 H₁:σ²>2，α=0.05；χ²(10) 下侧 0.95 分位数为 18.307。

给我一点提示
提示 1

用边界方差 2 构造统计量。

提示 2

备择是增大，使用右尾。

提示 3

分子是 10 乘 3。

带我一步一步做

第 1 / 4 步

  1. V=(11−1)×3/2=15。

  2. 原假设边界对应 χ²(10)。

  3. 右尾拒绝域为 V>18.307。

  4. 15 未超过临界值，未拒绝 H₀。

查看完整解答与检验

  1. V=(11−1)×3/2=15。

  2. 原假设边界对应 χ²(10)。

  3. 右尾拒绝域为 V>18.307。

  4. 15 未超过临界值，未拒绝 H₀。

答案

未拒绝方差不超过 2 的原假设。

检验与提醒

观察到 s²>2 本身不够；还需考虑抽样波动。

原创 P8-05第 8.4 节 · 巩固

从区间读检验结论

某正态均值的双侧 95% t 区间是 [4.2,5.8]。同一数据的双侧 5% t 检验，对 μ=4 与 μ=5 分别如何判断？

给我一点提示
提示 1

使用同一置信系数对应的水平。

提示 2

区间外被拒绝。

提示 3

区间内只意味着未拒绝。

带我一步一步做

第 1 / 4 步

  1. 95% 区间对应 α=0.05 双侧检验。

  2. 4<4.2，所以 μ=4 不在区间内。

  3. 拒绝 H₀:μ=4。

  4. 5 在区间内，因此未拒绝 H₀:μ=5。

查看完整解答与检验

  1. 95% 区间对应 α=0.05 双侧检验。

  2. 4<4.2，所以 μ=4 不在区间内。

  3. 拒绝 H₀:μ=4。

  4. 5 在区间内，因此未拒绝 H₀:μ=5。

答案

拒绝 μ=4；未拒绝 μ=5。

检验与提醒

未拒绝 μ=5 不意味着它是唯一可能参数。

规划单侧检验样本量

给我一点提示
提示 1

代入 σ/δ=2。

提示 2

把两个分位数相加。

提示 3

最后向上取整。

带我一步一步做

  2. 平方前为 2imes2.487=4.974。

  3. n≥4.9742=24.740676。

  4. 因此取最小整数 n=25。

查看完整解答与检验

  1. 分位数和为 2.487。

  2. 平方前为 2imes2.487=4.974。

  3. n≥4.9742=24.740676。

  4. 因此取最小整数 n=25。

答案

n=25。

检验与提醒

24 不满足给定充分条件；公式依赖已知标准差。

原创 P8-07第 8.6 节 · 巩固

四类别拟合检验

80 次独立观察分入四类，理论各占 1/4，实际频数为 16、24、20、20。求 Pearson 统计量与自由度。

给我一点提示
提示 1

理论频数均为 20。

提示 2

两个非零差值为 −4、4。

提示 3

概率完全给定，扣一个总数约束。

带我一步一步做

第 1 / 4 步

  1. 每类期望频数为 20。

  2. 各项贡献为 16/20、16/20、0、0。

  3. X2=1.6。

  4. 自由度为 4−1=3，各期望频数均不稀少。

查看完整解答与检验

  1. 每类期望频数为 20。

  2. 各项贡献为 16/20、16/20、0、0。

  3. X2=1.6。

  4. 自由度为 4−1=3，各期望频数均不稀少。

答案

X2=1.6, ν=3。

检验与提醒

不能使用自由度 4；四类计数总和固定为 80。

原创 P8-08第 8.7 节 · 巩固

2×2 表的期望频数

观测表两行为 (18,12) 与 (12,18)。计算独立性原假设下的期望频数、χ²统计量和自由度。

给我一点提示
提示 1

各行各列合计均为 30，总数 60。

提示 2

每格期望为 30×30/60。

提示 3

四格偏差绝对值相同。

带我一步一步做

第 1 / 4 步

  1. 每格期望频数为 15。

  2. 四格偏差分别为 3、−3、−3、3。

  3. X2=4×9/15=2.4。

  4. 自由度为 (2−1)(2−1)=1。

查看完整解答与检验

  1. 每格期望频数为 15。

  2. 四格偏差分别为 3、−3、−3、3。

  3. X2=4×9/15=2.4。

  4. 自由度为 (2−1)(2−1)=1。

答案

期望各 15，X2=2.4,ν=1。

检验与提醒

期望频数的行列和应与原表一致。

原创 P8-09第 8.8 节 · 巩固

单侧与双侧 p 值

观察到 z=1.5，已知 Φ(1.5)=0.9332。分别计算右侧、左侧、双侧 Z 检验的 p 值，并判断双侧 α=0.05 的结果。

给我一点提示
提示 1

右尾为 1−Φ。

提示 2

左尾直接取 Φ。

提示 3

双侧对称时把较小单尾乘 2。

带我一步一步做

第 1 / 4 步

  1. 右侧 p=1−0.9332=0.0668。

  2. 左侧 p=0.9332。

  3. 双侧 p=2×0.0668=0.1336。

  4. 0.1336>0.05，所以双侧未拒绝 H₀。

查看完整解答与检验

  1. 右侧 p=1−0.9332=0.0668。

  2. 左侧 p=0.9332。

  3. 双侧 p=2×0.0668=0.1336。

  4. 0.1336>0.05，所以双侧未拒绝 H₀。

答案

右侧 0.0668，左侧 0.9332，双侧 0.1336；双侧未拒绝。

检验与提醒

三个数对应不同预设问题，不能挑最小值事后汇报。
