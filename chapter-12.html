随机过程、状态空间与样本函数
12.1Stochastic processes理解后再记忆

随机过程、状态空间与样本函数

先用一句话理解

固定时间看随机变量，固定一次试验结果看一条时间轨迹。

随机过程 {X(t):t∈T} 是定义在同一概率空间上的一族随机变量；T 为指标集（常是时间），每个变量的可能取值构成状态空间。固定 t 得到随机变量 X(t)；固定样本点 ω 得到样本函数/轨道 t↦X(t,ω)。时间与状态都可各自离散或连续，这是两种独立的分类维度。

X:T×Ω⟶R,(t,ω)⟼X(t,ω)
使用条件

讨论均值、方差需对应矩存在；时间连续不意味着每条样本函数连续。给定单时刻分布仍不足以唯一确定过程。

展开性质证明 / 推导过程

反例说明联合结构不可缺：令 A 为等概率 ±1。过程一 Xn=A 对所有 n 共用一个随机符号；过程二 Yn 为独立等概率 ±1。每个时刻它们的分布完全相同，但 P(X0=X1)=1，而 P(Y0=Y1)=1/2。所以必须用多时刻联合分布才能描述时间依赖。

做一道简单例题

泊松计数过程：时间连续、状态为非负整数、轨道是阶梯函数。布朗运动：时间连续、状态连续，并具有几乎处处连续的轨道。

容易出错的地方

“连续时间过程”与“轨道连续过程”不是同一概念；只画一条轨道不能读出完整概率规律。

12.2Statistical description of processes理解后再记忆

有限维分布、均值、相关与协方差

先用一句话理解

均值描述平均轨迹，协方差描述不同时刻共同偏离均值的方式。

一维分布 Ft(x)=P{X(t)≤x}；n 维分布记录 P{X(t1)≤x1,…,X(tn)≤xn}。二阶描述包括均值 m(t)=EX(t)、相关函数 R(s,t)=E[X(s)X(t)]、协方差函数 C(s,t)=E[(X(s)−m(s))(X(t)−m(t))]。方差是 C(t,t)。这里“相关函数”没有除以标准差，不等于相关系数。

C(s,t)=R(s,t)−m(s)m(t)
使用条件

本节讨论实值、有限二阶矩过程。相关系数还需两时刻方差非零；零协方差通常不等于独立，联合高斯时例外。

展开性质证明 / 推导过程

展开乘积并用 EX(s)=m(s)，即得 C 与 R 的关系。任取实系数 ai 与时刻 ti，∑ijaiajC(ti,tj)=Var(∑iaiX(ti))≥0，因此协方差矩阵必半正定。特别取两个时刻，二阶主子式非负，得 |C(s,t)|≤C(s,s)C(t,t)。

做一道简单例题

若 X(t)=A+Bt，A、B 独立，均值均 0、方差分别 1、4，则 m(t)=0,C(s,t)=1+4st，方差为 1+4t2。

容易出错的地方

随意写一个对称函数不一定能作协方差；还必须满足任意有限时刻构成的矩阵半正定。

12.3Poisson process理解后再记忆

泊松过程：独立平稳增量与等待时间

先用一句话理解

把小概率到达累计成一条随时间增加的计数轨迹。

强度 λ>0 的齐次泊松过程满足 N(0)=0，非重叠区间增量相互独立，且 N(t+h)−N(t)~Poisson(λh)。增量分布只依赖区间长度称平稳增量。相邻到达的等待时间独立且服从 rate 为 λ 的指数分布；第 k 次到达时间为其和，服从形状 k、rate λ 的 Erlang 分布。

计数均值和方差都是 λt，Cov(N(s),N(t))=λmin(s,t)；因此它的增量平稳，但过程本身不是宽平稳过程。

P{N(t)=k}=e−λt(λt)kk!,P{T1>t}=e−λt
使用条件

齐次模型要求强度不随时间变化。区间增量独立不意味着 N(s) 与 N(t) 独立，因为累计计数共享过去。

展开性质证明 / 推导过程

第一等待时间超过 t 当且仅当时长 t 内没有到达，故 P(T1>t)=P(N(t)=0)=e−λt。由独立平稳增量和指数无记忆性可构造独立同分布等待时间；其和的密度为 λktk−1e−λt/(k−1)!。对于 s≤t，写 N(t)=N(s)+[N(t)−N(s)]，第二项与 N(s) 独立，因此协方差等于 VarN(s)=λs。也可由小区间关系 pk(t+h)=pk(t)(1−λh)+pk−1(t)λh+o(h) 得 pk′=−λpk+λpk−1，递推得到泊松概率式。

做一道简单例题

每小时平均 3 次到达，则半小时计数均值为 1.5，半小时没有到达的概率为 e−1.5；首个到达的平均等待时间为 1/3 小时。

容易出错的地方

独立的是不重叠时间段内的新增计数；不要把累计计数当作独立样本。

12.3Wiener process理解后再记忆

维纳过程：连续轨道与独立高斯增量

先用一句话理解

噪声沿时间累积，增量方差与时间长度成正比。

标准维纳过程（布朗运动） W(t)，t≥0，满足 W(0)=0，独立增量，W(t)−W(s)~N(0,t−s)（t>s），且轨道几乎必然连续。由此 EW(t)=0,VarW(t)=t，Cov(W(s),W(t))=min(s,t)。带漂移扩散模型 X(t)=μt+σW(t) 的均值为 μt、协方差为 σ2min(s,t)。

W(t+h)−W(t)~N(0,h),C(s,t)=min(s,t)
使用条件

“轨道连续”不是可微。维纳过程有平稳增量，但方差随 t 改变，所以本身不宽平稳。

展开性质证明 / 推导过程

对 s≤t，将 W(t) 写为 W(s) 加独立零均值增量；协方差立即为 Var(W(s))=s。任意有限时刻的 W 值是独立正态增量的线性组合，因此构成联合正态向量。考察差商 [W(t+h)−W(t)]/h：其二阶矩为 h/h2=1/h，当 h→0 发散，故不可能在均方意义下收敛到有限二阶矩导数。更强的“轨道几乎处处不可微”是另一条定理，此处这个计算只证明无均方导数。

做一道简单例题

W(3)−W(1)~N(0,2)，独立于 W(1)；但 W(3) 不独立于 W(1)，其协方差为 1。

容易出错的地方

正态分布第二个参数在本站表示方差；把长度 h 当成标准差会把尺度写错。

12.3Poisson bridge and uniform arrivals理解后再记忆

已知总到达数：前段计数为何变成二项分布

先用一句话理解

知道整段时间一共到了 n 次后，每次到达落在前 s/t 比例时段的机会相同；前段次数因此像 n 次独立伯努利试验。

对于强度恒定的泊松过程及 0<s<t，给定 N(t)=n，前段计数 N(s) 服从 Bin(n,s/t)。更细地说，给定总到达 n 次，各到达时刻的有序列表与 n 个独立 U(0,t) 样本排序后的分布相同；这是条件分布，不是说未给定总数时到达时刻独立均匀。

N(s)∣N(t)=n~Bin(n,s/t)
使用条件

需要齐次泊松过程、0<s<t，且所条件化的 N(t)=n 事件有正概率。非齐次情形要把 s/t 换成前段累计强度占全段的比例；普通相关到达过程不能照搬。

由独立增量推条件概率，并解释均匀到达

令 A=N(s)、B=N(t)−N(s)。独立增量给出 A~Poisson(λs)、B~Poisson(λ(t−s))，且 A、B 独立。求 P(A=k∣A+B=n) 时，分子为两段泊松质量函数之积，分母为 N(t) 取 n 的质量函数。指数因子 e−λt 约去，阶乘比化为 (nk)，其余两项化为 (s/t)k 和 (1−s/t)n−k。因此恰得 Bin(n,s/t) 的质量函数。把整段切成多个小段，同法得到给定总数后的多项分布，类别概率等于各段长度占比；细分极限说明有序到达时刻是 n 个独立均匀点的顺序统计量。

做一道简单例题

若 N(3)=4，则 N(1)∣N(3)=4~Bin(4,1/3)，其条件期望为 4/3。无须知道 λ；未条件化的 N(1) 仍为 Poisson(λ)。

容易出错的地方

不要把 N(1) 与 N(3) 当作独立：N(3) 已包含前 1 小时计数。条件二项分布的成功概率是时长比例，不是泊松参数 λ。

12.3Poisson thinning and superposition理解后再记忆

随机分流与合并：为什么仍是泊松过程

先用一句话理解

独立地给每次到达贴 A 或 B 标签，两个分类计数各自仍是泊松过程，而且彼此独立；反向把独立到达流合并，速率会相加。

对强度 λ 的齐次泊松过程，各次到达独立地以固定概率 p 标 A、以 1−p 标 B，且标签与到达过程独立。则两类分别是强度 pλ 与 (1−p)λ 的相互独立泊松过程。反之，两个相互独立泊松过程合并后的强度是 λ1+λ2。

(λA,λB)=(pλ,(1−p)λ)
使用条件

标签必须逐次独立、概率 p 固定并与原过程独立；若所有到达共享同一个随机环境或标签概率随历史变化，两类计数一般不再独立泊松。合并结论同样要求原过程独立。

联合概率母函数分解与独立增量

在任意长度 h 的区间，记两类数为 A、B，总数 N~Poisson(λh)。给定 N，每个标签独立，故 E(uAvB∣N)=(pu+(1−p)v)N。Poisson 母函数为 GN(z)=eλh(z−1)。代入 z=pu+(1−p)v，令 a=λph、b=λ(1−p)h，联合母函数化为 ea(u−1)eb(v−1)。两个因子分别是参数 a、b 的泊松母函数，故 A、B 独立且各服从相应泊松分布。不同区间的原增量及标签集合也独立，所以结论对整个计数过程成立。合并时独立增量相加，泊松母函数相乘，得到速率之和。

做一道简单例题

每小时平均 6 次到达，每次独立地以 1/3 概率属于 A，则 A、B 速率分别是 2 与 4 次/小时；一小时内恰有 A=2、B=1 的联合概率为 8e−6。

容易出错的地方

给定总数 N 时两类计数 A+B=N，因而条件下不独立；它们在未给定 N 的总体分布下独立。不要把这两个层次混为一谈。
